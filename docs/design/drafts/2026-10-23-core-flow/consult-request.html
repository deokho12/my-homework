상담 신청 시안

병원 상세에서 들어오는 /consult/:hospitalId 화면의 네 가지 방향이에요. 모두 375px 모바일 기준이고, 샘플 병원은 서울바른치과, 로그인한 사람은 김민지예요. 칩의 선택·비선택, 제출 버튼의 활성·비활성, 오류와 완료 화면이 모두 실제 문구로 들어 있어요.

시안 A · 정돈 한 페이지

지금의 필드와 순서를 그대로 두고, 흩어져 있던 칸을 세 개의 섹션 카드로 묶었어요. 제출은 하단 고정 바에서 해요.

  • •폼을 상담 내용 / 연락받을 정보 / 동의 세 섹션 카드로 묶었어요. 무엇을 몇 개 답해야 하는지가 한눈에 보여요
  • •제출 버튼을 하단 고정 바로 옮겼어요. 긴 폼에서 끝까지 스크롤하지 않아도 보여요. 비활성 안내 문구는 버튼 위로 올라와요
  • •힌트·안내 글자색을 neutral-400 → neutral-500으로 올렸어요 (흰 바탕 대비 2.5:1은 읽기 어려워요)
  • •동의 체크박스를 20px로 키우고 카드 전체를 rounded-2xl로 맞췄어요
  • •제출 실패를 브라우저 알림창 대신 화면 안 배너로 (A-3). 알림창은 문구가 잘리고 다시 시도 버튼을 둘 수 없어요

새 데이터 필요: 없음 — 지금 화면이 쓰는 값(병원, 시술 목록, 계정 이름, 지난 신청 연락처)만 써요.

  • •연락 시간을 2열 버튼 대신 칩 한 줄로 줄였어요

시안 D · 확인하고 바로 신청

이미 아는 이름·연락처는 입력칸이 아니라 확인 카드로 보여줘요. 고칠 게 없으면 시술과 시간만 고르고 바로 신청해요.

  • •이름·연락처가 읽는 카드로 바뀌었어요. 수정을 눌러야 입력칸이 열려요 (D-2). 빈 칸 두 개가 사라져 화면이 짧아져요
  • •자동 채움이 없는 계정(첫 신청)은 처음부터 D-2 모양으로 열려요

  • •하단 바에 제출하면 이름·연락처가 서울바른치과에 전달돼요를 적어 되돌릴 수 없는 행동을 알려요
