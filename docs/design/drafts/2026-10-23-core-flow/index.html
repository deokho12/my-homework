모든 시안이 지킨 규칙과 공통으로 고친 것

  • 색은 brand 청록 + neutral, 오류·찜·할인은 rose, amber/sky 는 상태 배지에서만. 새 색 없음
  • 면은 그림자 대신 neutral-100 테두리, 모서리는 버튼·입력 12px · 카드 16px · 칩·배지 원형
  • 이모지 아이콘(🏠🦷💬👤🔥🌟⚡)을 전부 lucide 로 바꿈
  • 읽어야 하는 글자의 neutral-400(대비 약 2.5:1)을 neutral-500 으로 올림
  • 이름이 실제 동작과 다르던 인기순 → 평점순, 진료시간 → 야간상담
  • 뒤로 가기 버튼은 화면마다 하나, 병원 상세 목차에 현재 위치 표시

결정이 필요한 것

시안을 그리며 규칙과 지금 코드가 부딪힌 곳이에요. 고른 시안을 구현하기 전에 정해야 해요.

  1. 별점 색 — 지금 코드는 후기 별을 amber-500 으로 칠하지만 규칙은 amber 를 배지에서만 써요. 시안은 neutral-900 별 + 숫자로 그렸어요. 별만 예외로 amber 를 허용할지 정해 주세요
  2. 화면 안 오류 배너 — 토스트가 없어서 상담 신청 실패를 rose 배너(rose-400 테두리)로 그렸어요. rose-400 은 원래 입력 오류 테두리 전용이에요
  3. 준비중 표시 — 지금 앱은 11px 회색 글자인데 홈 B·D 와 병원 상세 D 는 amber 배지로 그렸어요. 회색 글자와 amber 배지 중 하나로 통일해 주세요
  4. 새 패턴 — 병원 탐색 B 의 "설명 달린 선택 행"(시트 안 조건마다 한 줄 설명), 가로형 카드·목록 행의 15px 제목(규칙의 작은 카드는 14px), 흰 카드 위에서 흰 원 없이 그린 하트
  5. 새 데이터가 필요한 시안 — 홈 C(반경 질의, 야간상담·주차 목록 필터), 홈 D(이벤트 종료일), 병원 상세 C(doctorId), 병원 상세 D(시술별 금액), 병원 탐색 B(미리보기 건수). 고르면 db-master → interface-master 순서로 계약부터 정해야 해요
  6. 상담 신청 C 의 주소 — 시트로 바꾸면 /consult/:hospitalId 를 직접 열거나 공유했을 때의 동작을 다시 정해야 해요
