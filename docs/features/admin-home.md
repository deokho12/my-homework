# 병원 관리자 홈

> 병원 관리자가 처음 들어오는 화면입니다. 상담 현황 숫자를 보고, 등록된 병원 목록에서 고칠 병원을 골라 들어가고, 상담 관리·전문의 검수·알림함으로 갈 수 있습니다.

| | |
|---|---|
| **주소** | `/admin` |
| **누가 보나요** | 병원 관리자용 화면입니다. 다만 **지금은 로그인 검사가 없어서 주소만 알면 누구나 볼 수 있습니다** |
| **어디서 들어오나요** | 마이페이지 맨 아래 `병원 담당자이신가요? 관리자 페이지` 링크. 그 외에는 주소를 직접 입력 (상단 메뉴·하단 탭에는 관리자 입구가 없습니다) |
| **소스 파일** | `frontend/src/screens/admin/index.tsx` |

## 여기서 할 수 있는 일

상태 표시: ✅ 실제로 동작함 · 🟡 화면은 되지만 데이터가 샘플 · 🚧 아직 아무 일도 안 일어남 · 🔒 로그인 필요

| 할 수 있는 일 | 상태 | 지금 어떻게 동작하나요 |
|---|---|---|
| `이번 달 신규 상담` 숫자 보기 | 🟡 | 접수된 상담 중 **오늘이 속한 달**에 신청된 건수를 셉니다. 샘플 상담은 모두 2026년 6~7월 날짜라서, 8월에 보면 `0` 으로 나옵니다 |
| `처리 대기 중인 상담` 숫자 보기 | 🟡 | 상태가 `신규` 인 상담 건수를 셉니다. 샘플 데이터에서는 3건 |
| 알림함 열기 | ✅ | 우측 상단 🔔. 읽지 않은 관리자 알림이 있으면 종 위에 빨간 숫자가 붙습니다 (10건 이상이면 `9+`) |
| 상담 관리로 가기 | ✅ | `상담 관리` 버튼 |
| 새 병원 등록하기 | ✅ | `새 병원 등록` 버튼 |
| 전문의 인증 검수로 가기 | ✅ | `전문의 인증 검수` 버튼 |
| 등록된 병원 목록 보기 | 🟡 | 등록된 병원 전부가 카드로 쭉 나옵니다. 샘플 병원 11곳이 들어 있습니다 |
| 병원 눌러서 정보 수정하기 | ✅ | 병원 카드를 누르면 그 병원의 `병원 정보 수정` 화면으로 갑니다 |
| 병원 목록 검색·정렬·필터 | 🚧 | **없습니다.** 등록된 순서대로만 나오고, 새로 등록한 병원은 목록 맨 아래에 붙습니다 |
| 병원 삭제하기 | 🚧 | **없습니다.** 등록한 병원을 지우는 방법이 화면에 없습니다 |

## 화면에 보이는 정보

- **제목 영역** — `병원 프로필 관리` + 설명 문구 `등록된 병원 정보를 수정하거나 새 병원을 등록할 수 있어요`, 오른쪽에 알림 종
- **숫자 카드 2개** — `이번 달 신규 상담` / `처리 대기 중인 상담`. 값은 큰 숫자로 표시됩니다
- **버튼** — `상담 관리` (테두리 버튼) / `새 병원 등록` (채워진 버튼) · `전문의 인증 검수` (테두리 버튼)
- **병원 카드** — 병원명, 그 아래 작은 글씨로 지역. 원데이 진료가 가능한 병원은 카드 오른쪽에 `⚡ 원데이` 표시
- **병원이 하나도 없을 때** — 목록 자리가 **그냥 빈 채로** 남습니다. `병원이 없어요` 같은 안내 문구가 없습니다

## 알아두실 것

- **⚠️ 지금 관리자 화면에는 로그인 검사가 전혀 없습니다.** `/admin` 주소만 알면 로그인하지 않은 누구나 들어와서 병원 정보를 보고 고칠 수 있고, 여기서 이어지는 상담 관리 화면에서는 **고객 실명과 전화번호**까지 그대로 볼 수 있습니다. 이미 확인된 문제이고 리팩터링 계획 **8단계**에서 막을 예정입니다. 그때까지 **이 화면 주소를 외부에 공유하지 마세요.**
- **관리자 화면은 병원별로 나뉘어 있지 않습니다.** 들어오면 등록된 모든 병원이 보이고 전부 수정할 수 있습니다. "내 병원만 보기" 같은 구분이 없습니다.
- **데이터는 서버가 아니라 보고 있는 브라우저에 저장됩니다.** 그래서 다른 컴퓨터·다른 브라우저·시크릿 창에서는 숫자와 목록이 다르게 보입니다.
- **`이번 달 신규 상담`은 "오늘이 속한 달" 기준입니다.** 달이 바뀌면 0부터 다시 셉니다. 샘플 상담이 7월 날짜라서 8월 이후에 보면 0으로 보이는 게 정상입니다.
- **알림 종의 빨간 숫자는 이 화면에만 있습니다.** 상담 관리·병원 수정 같은 다른 관리자 화면에는 종 자체가 없습니다.
- 주소를 직접 입력해서 이 화면에 바로 들어온 경우, 상단 `<` 를 눌러도 돌아갈 이전 화면이 없어서 아무 일도 일어나지 않을 수 있습니다. (확인 필요 — 브라우저 방문 기록에 따라 달라집니다)

## 이 화면을 바꾸고 싶을 때

`docs/features/requests/_TEMPLATE.md` 를 복사해서 `docs/features/requests/` 에 요청서를 만들거나,
채팅창에 `/feature-request` 를 입력하세요.

이 화면에서 손대면 함께 확인해야 하는 것:

- **병원 목록**은 일반 사용자 화면(홈·병원 탐색·검색)과 **같은 병원 데이터**를 씁니다. 여기서 병원을 등록하면 사용자 화면에도 바로 나타납니다.
- **숫자 카드 2개**는 상담 관리 화면과 같은 상담 데이터를 셉니다. 상담 상태를 바꾸면 `처리 대기 중인 상담` 숫자도 함께 움직입니다.
- **알림 종의 읽지 않은 개수**는 관리자 알림함에서 `모두 읽음` 을 누르면 0이 됩니다.
