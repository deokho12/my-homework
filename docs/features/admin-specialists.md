# 전문의 인증 검수

> 병원이 등록한 전문의의 자격증 이미지를 확인하고, 승인하거나 사유를 적어 반려하는 화면입니다. 승인해야 사용자 화면에 전문의 배지가 붙습니다.

| | |
|---|---|
| **주소** | `/admin/specialists` |
| **누가 보나요** | 운영자용 화면입니다. 다만 **지금은 로그인 검사가 없어서 주소만 알면 누구나 들어와 승인·반려를 누를 수 있습니다** |
| **어디서 들어오나요** | 병원 관리자 홈(`/admin`)의 `전문의 인증 검수` 버튼 |
| **소스 파일** | `frontend/src/screens/admin/specialists.tsx` |

## 여기서 할 수 있는 일

상태 표시: ✅ 실제로 동작함 · 🟡 화면은 되지만 데이터가 샘플 · 🚧 아직 아무 일도 안 일어남 · 🔒 로그인 필요

| 할 수 있는 일 | 상태 | 지금 어떻게 동작하나요 |
|---|---|---|
| 검수 대기 목록 보기 | 🟡 | 등록된 전문의 전원이 나옵니다. 샘플 데이터는 14명(`승인` 9 · `대기` 3 · `반려` 2)입니다 |
| 대기 건을 먼저 보기 | ✅ | 목록이 항상 `대기` → `반려` → `승인` 순서로 정렬됩니다. 같은 상태 안에서의 순서는 등록 순입니다 |
| 자격증 이미지 확인 | 🟡 | 카드 왼쪽에 작은 이미지로 보입니다. 샘플 이미지입니다. 크게 보거나 새 창으로 여는 기능은 없습니다 |
| 자격증 미제출 확인 | ✅ | 자격증 URL이 없으면 이미지 자리에 회색 상자와 `미제출` 글씨가 나옵니다 |
| 승인하기 | ✅ | `승인` 버튼. 확인창 없이 즉시 상태가 `승인` 으로 바뀌고 배지 색이 바뀝니다. 이전에 적힌 반려 사유는 함께 지워집니다 |
| 반려하기 | ✅ | `반려` 버튼 → 사유 입력칸과 `취소` / `반려 확정` 버튼으로 바뀝니다. 사유를 한 글자라도 적어야 `반려 확정` 이 눌립니다 |
| 반려 취소하기 (입력 중) | ✅ | `취소` 를 누르면 적던 사유가 지워지고 원래 버튼으로 돌아갑니다 |
| 이미 처리한 건 다시 바꾸기 | ✅ | `승인`/`반려` 버튼은 상태와 상관없이 항상 보입니다. 승인된 사람을 다시 반려하거나 그 반대도 가능합니다 |
| 상태별 필터 · 검색 | 🚧 | **없습니다.** 전체 목록에서 정렬만 됩니다 |
| 전문의 정보 고치기 · 삭제하기 | 🚧 | 이 화면에서는 안 됩니다. `병원 정보 수정` 화면에서 합니다 |
| 병원·전문의에게 결과 알리기 | 🚧 | **아무 알림도 가지 않습니다.** 승인/반려를 눌러도 알림함에 아무것도 생기지 않습니다 |

## 화면에 보이는 정보

- **제목 영역** — `전문의 인증 검수` + 설명 문구 `업로드된 자격증을 확인하고 승인 또는 반려해주세요`
- **전문의 카드** (한 명당 하나)
  - 왼쪽: 자격증 이미지 (없으면 `미제출` 회색 상자)
  - 이름과 직함 — `김민준 · 대표원장` 처럼 가운뎃점으로 이어 붙여 표시
  - 전문 분야 — 예: `치과보철전문의`
  - 소속 병원 이름. 병원을 찾지 못하면 `알 수 없는 병원`
  - 오른쪽 배지 — `대기` / `승인` / `반려`. **`승인` 만 색이 있는 배지**이고 나머지는 회색입니다
  - 반려된 경우: 그 아래 붉은 글씨로 `반려 사유: (적어둔 사유)`
  - 아래: `승인` (색 버튼) · `반려` (테두리 버튼)
- **반려 사유를 적는 중일 때** — 여러 줄 입력칸(`반려 사유를 입력해주세요`) + `취소` · `반려 확정` 버튼. 사유가 비어 있으면 `반려 확정` 이 회색으로 비활성
- **목록이 비었을 때** — 목록 자리가 **그냥 빈 채로** 남습니다. 안내 문구가 없습니다

## 알아두실 것

- **⚠️ 지금 관리자 화면에는 로그인 검사가 전혀 없습니다.** `/admin/specialists` 주소만 알면 로그인하지 않은 누구나 들어와서 아무 전문의나 승인하거나 반려할 수 있고, 제출된 자격증 이미지도 볼 수 있습니다. 이미 확인된 문제이고 리팩터링 계획 **8단계**에서 막을 예정입니다. 그때까지 **이 화면 주소를 외부에 공유하지 마세요.**
- **승인·반려 결과가 아무에게도 통보되지 않습니다.** 병원 담당자도 전문의도 알림을 받지 못합니다. 결과는 병원이 직접 화면을 확인해야 압니다.
- **`승인` 은 확인창 없이 즉시 처리됩니다.** 잘못 눌렀으면 다시 `반려` 로 바꿔야 합니다.
- **이미 처리된 건도 목록에서 사라지지 않습니다.** 승인된 사람도 계속 `승인`/`반려` 버튼과 함께 목록 아래쪽에 남아 있습니다. 처리 완료 항목을 감추는 기능이 없습니다.
- **`일반의` 로 등록된 사람도 이 목록에 함께 나옵니다.** `일반의` 는 검수할 자격증이 없어도 사용자 화면에 그대로 표시되는 값이라, 여기서 승인하거나 반려해도 사용자 화면 표시는 달라지지 않습니다.
- **자격증 이미지가 작게만 보입니다.** 확대해서 확인하는 기능이 없어서 실제 검수용으로는 부족합니다.
- **`미제출` 인 사람도 `승인` 을 누를 수 있습니다.** 자격증이 없어도 막지 않습니다.
- **승인/반려는 검수 기록을 남기지 않습니다.** 누가 언제 처리했는지는 저장되지 않고, 반려 사유만 남습니다. 승인하면 그 사유도 지워집니다.
- 이 화면에는 전문의를 추가하거나 지우는 기능이 없습니다. 목록에 사람을 추가하려면 `병원 등록`/`병원 정보 수정` 화면에서 전문의를 추가해야 합니다.
- 데이터는 서버가 아니라 **보고 있는 브라우저에 저장**됩니다. 다른 컴퓨터에서는 검수 결과가 보이지 않습니다.

## 이 화면을 바꾸고 싶을 때

`docs/features/requests/_TEMPLATE.md` 를 복사해서 `docs/features/requests/` 에 요청서를 만들거나,
채팅창에 `/feature-request` 를 입력하세요.

이 화면에서 손대면 함께 확인해야 하는 것:

- 여기서 `승인` 하면 **병원 상세 화면의 의료진 카드**와 **전문의 상세 화면**에 전문의 배지가 붙습니다. 승인 전에는 전문 분야 표시가 감춰집니다. (`docs/features/hospital-detail.md`)
- 병원 목록 카드의 `OO전문의 상주` 같은 표시도 승인 여부에 따라 달라집니다.
- 검수 대상 목록은 `병원 등록`·`병원 정보 수정` 화면에서 추가한 전문의와 **같은 데이터**입니다. (`docs/features/admin-hospital-edit.md`)
