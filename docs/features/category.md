# 시술 카테고리

> 시술 한 분야(예: 충치치료)를 하는 병원만 모아 보는 화면입니다. 홈의 `시술로 찾기` 격자나 검색에서 시술 이름을 치면 여기로 옵니다. 분야 안에서 **세부 시술**(레진·인레이·크라운…)로 한 번 더 좁힐 수 있습니다.

| | |
|---|---|
| **주소** | `/category/충치치료같은분야id` (세부 시술까지 고르면 `/category/cavity?sub=crown` 처럼 뒤가 붙습니다) |
| **누가 보나요** | 누구나 (상담 신청만 로그인 필요) |
| **어디서 들어오나요** | 홈의 `시술로 찾기` 격자 카드, 검색의 **추천 목록 `시술` 줄**(또는 시술·세부 시술 이름을 검색했을 때), 홈·검색의 인기 검색어 중 시술 항목, 시술 꿀팁 상세의 `관련 시술 병원 상담받기` |
| **소스 파일** | `frontend/src/pages/CategoryPage.tsx` + `frontend/src/features/procedure/taxonomy.ts` (분야·세부 시술 목록) + `frontend/src/features/procedure/availability.ts` (`준비중` 판정) + `frontend/src/components/ListMoreFooter.tsx` (`더 보기`) |

## 여기서 할 수 있는 일

상태 표시: ✅ 실제로 동작함 · 🟡 화면은 되지만 데이터가 샘플 · 🚧 아직 아무 일도 안 일어남 · 🔒 로그인 필요

| 할 수 있는 일 | 상태 | 지금 어떻게 동작하나요 |
|---|---|---|
| 세부 시술로 좁히기 | ✅ | 분야 이름 아래 알약 줄. `전체` + 그 분야의 세부 시술들 중 **하나만** 선택됩니다. 누르면 목록이 실제로 그 세부 시술을 하는 병원만으로 줄고, 주소창에도 `?sub=crown` 처럼 남습니다. `· 준비중` 이 붙은 알약도 누를 수 있습니다 (아래 "특별한 상황" 참고) |
| 주소를 공유하거나 새로고침하기 | ✅ | 고른 세부 시술이 주소에 들어가므로, 그 주소를 그대로 보내면 상대도 같은 목록을 봅니다. 새로고침·뒤로 가기도 같은 목록으로 돌아옵니다 |
| 정렬 바꾸기 | ✅ | `인기순`(= 평점 순) / `후기순` / `상담많은순` 중 하나 |
| 조건으로 걸러내기 | ✅ | `상담가능` `원데이` 두 개. 동시에 켤 수 있고, 다시 누르면 꺼집니다 |
| 결과 개수 확인 | ✅ | 목록 위에 `"충치치료" 병원` + `총 3곳` 처럼 표시됩니다. 세부 시술을 고르면 제목이 그 세부 시술 이름(`"크라운" 병원`)으로 바뀝니다 |
| 더 보기 | ✅ | 목록은 **20곳씩** 나옵니다. 20곳을 넘으면 맨 아래에 `57곳 중 20곳 보는 중` 과 `병원 20곳 더 보기` 버튼이 나오고, 누르면 다음 20곳이 아래에 이어 붙습니다(마지막 묶음은 남은 수만큼, 예: `병원 17곳 더 보기`). 다 보면 버튼이 사라지고 `57곳을 모두 봤어요` 만 남습니다. **20곳 이하면 아무것도 나오지 않습니다** — 지금 샘플 병원은 11곳이라 보이지 않습니다. (2026-10-21 전에는 `총 N곳` 이 20을 넘어도 나머지를 볼 방법이 없었습니다) |
| 병원 카드 누르기 | 🟡 | 병원 상세 화면으로 이동합니다 |
| 카드의 `상담신청` 누르기 | ✅ 🔒 | 상담 신청 화면으로 이동합니다. 로그인하지 않았으면 로그인 화면을 거쳐 돌아옵니다. 상담을 받지 않는 병원은 회색 `상담 마감` 으로 바뀌고 눌리지 않습니다 |
| 병원 찜하기 | ✅ 🔒 | 병원 카드 사진 **오른쪽 위 하트**. 병원 탐색·병원 상세·마이페이지 찜 목록과 같은 상태입니다. 하트를 눌러도 병원 상세로 넘어가지 않고, 로그인하지 않았으면 로그인 화면으로 보냅니다 |
| 카드에서 거리 보기 | ✅ | 위치를 **허용**하면 지역 줄 끝에 `강남구 · 0.4km` 처럼 거리가 붙습니다. 거부하거나 위치를 못 받으면 지역명만 보입니다 |
| 뒤로 가기 | ✅ | 화면 왼쪽 위 동그란 `‹` 버튼 |
| 의사 목록·지도·가격 비교표 보기 | 🚧 | **이 화면에는 없습니다.** 병원 목록 한 가지만 보여줍니다. 의사·지도·가격 비교가 필요하면 병원 탐색 화면을 쓰세요 |

## 시술 분야 9개와 세부 시술 31개

★ 표시는 **그 시술을 등록한 병원이 있어 지금 병원을 찾을 수 있는** 세부 시술입니다 (샘플 병원
기준, 2026-10-21). 표시가 없는 것은 아직 등록한 병원이 없어 **준비중**으로 보입니다 — 알약에
`· 준비중` 이 붙지만 누를 수 있고, 누르면 `등록된 병원이 아직 없어요` 가 나옵니다.

**이 표는 고정이 아닙니다.** `준비중` 은 서버가 그때그때 셉니다 — 앱에 보이는 병원 중 그 시술을
등록한 곳이 **1곳이라도 있으면 열리고, 0곳이면 준비중**입니다. 병원 관리자가
[병원 정보](admin-hospital-edit.md)에서 시술을 체크하고 저장하면 그 시술은 바로 열리고, 마지막
병원이 체크를 풀면 다시 `준비중` 이 됩니다. 분야는 속한 세부 시술이 **전부** 준비중일 때만
준비중입니다.

| 분야 | 세부 시술 |
|---|---|
| 임플란트 | ★일반 임플란트 · 뼈이식 · 상악동거상술 · 임플란트 틀니 |
| 스케일링·예방 | 스케일링 · 불소도포 · 실란트 · 구취관리 — **4개 모두 아직 등록한 병원이 없어 분야 전체가 준비중** |
| 교정 | 투명교정 · 설측교정 · ★일반(브라켓)교정 · 부분교정 |
| 충치치료 | ★레진 · ★인레이 · 온레이 · ★크라운 · 신경치료 |
| 심미 | ★라미네이트 · ★치아미백 · 잇몸성형 |
| 잇몸치료 | ★잇몸치료 · 치주수술 · 잇몸이식 |
| 턱관절·스플린트 | ★턱관절장애 치료 · ★스플린트 · 이갈이장치 · ★코골이장치 |
| 보톡스 | ★이갈이 보톡스 · 사각턱(교근) 보톡스 |
| 사랑니·발치 | ★사랑니 발치 · 일반 발치 |

**서버도 31개를 모두 압니다** (2026-10-21 부터. 그 전에는 13개만 알았습니다). 병원 관리자는
31개 중 무엇이든 등록할 수 있고, ★ 가 없는 18개는 아직 등록한 병원이 없을 뿐입니다.

### `전체` 와 세부 시술 알약의 차이

| 고른 것 | 목록에 나오는 병원 |
|---|---|
| `전체` | 그 분야의 세부 시술을 **하나라도** 한다고 등록한 병원 (충치치료 `전체` = 레진·인레이·온레이·크라운·신경치료 중 하나라도 하는 곳) |
| 세부 시술 하나 | 그 시술을 한다고 등록한 병원만 |

## 화면에 보이는 정보

위에서 아래 순서대로입니다.

- **헤더** — 왼쪽에 동그란 `‹` 뒤로 가기, 그 옆에 분야 아이콘(홈 `시술로 찾기` 와 같은 그림)과 분야 이름(큰 글씨), 아래 한 줄 설명(예: `초기 충치부터 신경치료·보철까지`)
- **세부 시술 알약 줄** — `전체` 로 시작하고 그 분야의 세부 시술이 이어집니다. 준비중인 것은 `신경치료 · 준비중` 처럼 이름 뒤에 붙어 보이지만 **누를 수 있습니다** (2026-10-21 전에는 회색으로 눌리지 않았습니다). 시술 목록을 불러오는 중이거나 불러오지 못했으면 `준비중` 이 어디에도 붙지 않습니다. 좌우 스크롤
- **정렬 알약 줄** — `인기순` `후기순` `상담많은순`
- **조건 알약 줄** — `상담가능` `원데이`
- **결과 머리글** — `"충치치료" 병원` + 그 아래 `총 3곳`
- **병원 카드** — 병원 사진(오른쪽 위에 찜 하트), 이름 줄(병원 이름 + 작은 `광고` 표시 + `🌟 추천`), 전문 분야, `지역 · 거리`(위치를 허용했을 때만 거리), 배지 줄(`⚡ 원데이 가능` → `OO전문의 상주` → 시술 이름 최대 3개 순서), `후기 N` `상담 N` `★ 4.8`, 아래에 `상담신청` 버튼. 넓은 화면(768px 이상)에서는 2열, 더 넓은 화면(1024px 이상)에서는 3열
- **목록 맨 아래** — 병원이 20곳을 넘을 때만: `57곳 중 20곳 보는 중` + 테두리만 있는 `병원 20곳 더 보기` 버튼. 다 보면 `57곳을 모두 봤어요` 한 줄

### 특별한 상황에서 보이는 화면

| 상황 | 화면 |
|---|---|
| 준비중인 분야로 들어왔을 때 (지금은 스케일링·예방) | `등록된 병원이 아직 없어요` + `이 분야는 준비중이에요`. 서버에 실제로 물어본 결과가 0곳이라 이렇게 보입니다 — 병원이 그 분야의 시술을 등록하면 그 병원이 나옵니다 |
| 준비중인 세부 시술 알약을 누르거나 그 주소로 들어왔을 때 (`?sub=root-canal`) | 그 알약(`신경치료 · 준비중`)이 골라진 채로 `등록된 병원이 아직 없어요` + `이 시술은 준비중이에요` 가 나옵니다. **분야 전체로 넓혀 보여주지 않습니다** — 2026-10-21 전에는 `신경치료은(는) 준비중이에요 — 충치치료 전체를 보여드려요` 안내와 함께 분야 전체를 보여줬지만, 그 안내도 그 동작도 없어졌습니다 |
| 2026-10-21 이전의 시술 이름이 든 주소 (`/category/gum?sub=gum-disease`) | 지금 이름의 세부 시술(`잇몸치료`)이 골라진 채로 열립니다. 북마크해 둔 옛 주소도 그대로 쓸 수 있습니다 |
| 다른 분야의 세부 시술 주소 (`/category/implant?sub=crown`) | `sub` 를 조용히 무시하고 임플란트 전체를 보여줍니다 |
| 없는 분야 주소 (`/category/bogus`) | `없는 카테고리예요` + `병원 탐색으로` 버튼 |
| 시술 목록(준비중 여부)을 아직 받지 못했거나 받는 데 실패했을 때 | `준비중` 표시가 어디에도 붙지 않습니다. 이때 병원이 0곳이면 `조건에 맞는 병원이 없어요` 로 보입니다 |
| 조건에 맞는 병원이 없음 | `조건에 맞는 병원이 없어요` |
| `더 보기` 를 누르고 기다리는 중 | 버튼이 돌아가는 표시 + `불러오는 중` 으로 바뀌고 눌리지 않습니다 |
| `더 보기` 로 다음 묶음을 불러오지 못했을 때 | 버튼 위에 빨간 `더 불러오지 못했어요` 가 나오고 버튼이 `다시 시도` 로 바뀝니다. **이미 보이던 카드는 그대로 남습니다** |

## 알아두실 것

- **이 화면에는 병원 목록만 있습니다.** 의사 목록·지도·가격 비교표는 병원 탐색 화면에만 있습니다. 홈과 검색이 보내는 "이 시술 하는 병원 보여줘" 한 가지 의도만 처리하려고 일부러 단순하게 만든 화면입니다.
- **광고 병원은 모든 분야에서 맨 위로 올라갑니다** (광고 기간 중이고 평점이 3.5 이상인 병원). `전체` 를 보든 세부 시술을 고르든 같습니다. 2026-10-21 전에는 `충치치료` `심미` `턱관절·스플린트` 의 `전체` 에서만 광고 병원이 올라가지 않고 병원도 100곳까지만 나왔는데, 둘 다 없어졌습니다.
- **목록은 20곳씩 보여줍니다.** 맨 아래 `병원 20곳 더 보기` 로 이어서 봅니다. 세부 시술·정렬·조건을 바꾸면 다시 **처음 20곳부터, 목록 맨 위에서** 시작합니다 (보던 자리에 남으면 다른 목록의 중간을 보게 되기 때문입니다).
- **스케일링·예방은 지금 병원이 0곳입니다.** 그 분야의 시술(스케일링·불소도포·실란트·구취관리)을 등록한 병원이 아직 없어서입니다. 고장이 아닙니다 — 병원 관리자가 `스케일링` 등을 체크하고 저장하면 `준비중` 이 바로 사라지고 그 병원이 나옵니다.
- **`준비중` 은 화면이 아니라 서버가 정합니다.** 저장한 관리자 본인의 화면에는 곧바로 반영되고, 다른 사람의 화면에는 그 화면을 다시 열거나 새로고침할 때 반영됩니다.
- **화면에 보이는 시술 이름과 서버에 저장된 이름이 같습니다** (2026-10-21 부터). 그 전에는 서버의 `충치치료` 가 화면에서 `레진` 으로 보이는 식으로 여섯 개가 달랐습니다.
- **정렬·조건 선택은 저장되지 않습니다.** 분야를 바꿔 들어오거나 새로고침하면 `인기순` + 조건 전부 꺼짐으로 돌아갑니다. 세부 시술만 주소에 남습니다.
- **커뮤니티 질문하기의 시술 선택도 같은 세부 시술 31개 이름을 씁니다** (2026-10-21 부터). 다만 분야로 묶지 않고 31개를 한꺼번에 늘어놓습니다. 상담 신청·문의·마이페이지·관리자 상담 화면은 `충치치료 · 레진` 처럼 `분야 · 세부 시술` 로 보입니다.
- **위치 권한은 이 화면에 들어올 때 물어봅니다.** 카드가 거리를 보여주기 때문입니다(병원 탐색 화면과 같은 시점). 거부하면 거리 없이 지역명만 보이고, 한 번 거부하면 브라우저가 다시 묻지 않습니다 — 주소창 자물쇠 아이콘에서 바꿀 수 있습니다.
- **거리는 직선 거리이고 `0.4km` 처럼 항상 km 로 씁니다.** 100m 미만은 `0.1km 이내`, 100km 이상은 소수점 없이 표시합니다. 병원 좌표가 등록되지 않았으면 거리가 나오지 않습니다.
- **병원 정보는 샘플입니다.** 실제 병원이 아닙니다.
