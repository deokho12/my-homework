## Claude Code 에 시키는 법

1. Claude Code 에서 `/feature-request` 를 입력합니다 (뒤에 아무것도 안 붙임). 그러면 대기 목록이 나오고, 거기서 번호를 고르면 됩니다. 번호를 바로 지정하려면 `/feature-request 12번 요청서 진행해줘` 처럼 씁니다
2. Claude 가 "이렇게 이해했다"고 정리해 주면 확인하고 진행합니다
3. "QA 통과" 가 나오면 `main 에 커밋하고 push 해줘` 라고 합니다
4. **다음 요청서로 넘어가기 전에 `/clear` 로 대화를 비웁니다.** 대화가 길어지면 앞 내용을 잊고 실수가 늘어납니다
5. 중간에 막히면 요청서 번호와 화면 캡처를 들고 Claude(Cowork)에 물어보세요
