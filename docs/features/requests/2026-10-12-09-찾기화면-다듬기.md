## 무엇을 하고 싶으신가요

이미 잘 동작하는 찾기 화면에서 "눌러도 반응 없는 곳"과 "비교에 필요한데 빠진 정보"를 채우고 싶어요.

---

## 왜 필요한가요

치과는 주로 가까운 곳으로 가서 거리가 중요한데, 카드에 거리가 없습니다. 홈 배너는 눌러도 반응이 없어 막힌 느낌을 줍니다.

---

## 지금은 어떻게 되어 있나요

- 홈 배너 3장: 넘기기는 되지만 눌러도 반응 없음
- 시술 카테고리 카드: 거리 표시 없음
- 병원 탐색 카드: 찜 하트 없음. 지도는 카카오맵 키가 없어 안내 문구만 보임
- 전문의 배지 기준이 화면마다 같은 함수를 쓰는지 확인 필요 (AGENTS.md "같은 판정을 두 곳에 두지 않는다")

---

## 이렇게 되면 좋겠어요

- 홈 배너를 누르면 꿀팁 상세 또는 이벤트로 이동 (배너마다 연결 대상 지정)
- 시술 카테고리·병원 탐색 카드에 **거리**(`0.4km`) 표시. 위치 권한이 없으면 지역명만
- 병원 탐색 카드 오른쪽 위에 **찜 하트** (병원 상세·마이 찜과 같은 상태)
- 카드 배지 순서: 원데이 → `OO전문의 상주` → 나머지 시술 태그
- 광고 병원은 이름 옆에 작은 `광고` 표시 (지금 규칙 유지)
- 상담 받지 않는 병원은 회색 `상담 마감` (지금 동작 유지)
- 전문의 상세: 승인된 경우에만 **`전문의 인증`** 배지 + 아래 "몰라몰라가 자격증을 확인한 의료진에게만 인증 배지가 붙어요"
- 카카오맵 키 연결 (`frontend/.env` 의 `VITE_` 키). 키는 제가 발급해서 전달합니다

---

## 이것만은 지켜주세요 / 건드리지 말아주세요

- 세부 시술 칩, 정렬, 조건 필터의 지금 동작은 그대로
- `준비중` 세부 시술은 병원이 등록하기 시작하면 순서대로 열기 (이번에는 표시 유지)
- 거리 계산은 백엔드 `hospital/distance.ts` 와 같은 규칙을 쓰기

---

## 확인하고 싶은 것

- 홈 배너를 누르면 지정한 화면으로 간다
- 위치를 허용하면 카드에 거리가 보이고, 거부하면 지역명만 보인다
- 탐색 카드에서 하트를 누르면 마이 > 찜에 나타난다
- 승인 안 된 전문의 상세에는 `전문의 인증` 배지가 없다

## 검토 결과

- **상태**: 완료 (2026-10-13, QA 통과 — 확인 항목 4개를 실제 브라우저에서 위치 허용·거부·위치 불가 각각으로 확인. 지도 위 카드만 카카오맵 키가 없어 화면으로는 확인하지 못함)
- **영향 범위**:
  - 홈 배너 3장이 링크가 됐습니다 (`/explore`, `/explore?specialist=1`, `/community`). 끌어 넘긴 뒤 손을 떼면 이동하지 않고, 키보드·낭독기로도 열립니다
  - 병원 탐색·시술 카테고리 카드: 사진 오른쪽 위 **찜 하트**(병원 상세·마이 찜과 같은 상태), 지역 줄 끝의 **거리**, 배지 재배치(`광고`·`🌟 추천` 은 이름 줄로 / `⚡ 원데이 가능` 은 사진 오버레이에서 배지 줄로)
  - 위치 권한을 **화면에 들어올 때** 묻습니다(전에는 지도 보기로 바꿀 때). 허용하지 않으면 거리를 **아예 그리지 않습니다** — 지도 아래 카드에 있던 "서울시청 기준 거짓 거리"도 같은 규칙으로 함께 닫았습니다
  - 거리 표기가 `0.4km` 로 통일됐습니다. 지도 아래 카드도 같은 함수를 쓰므로 전에 `400m` 로 보이던 것이 함께 바뀝니다 (의도된 변화)
  - 전문의 상세: 승인된 경우에만 `전문의 인증` 배지 + `몰라몰라가 자격증을 확인한 의료진에게만 인증 배지가 붙어요`
  - 세부 시술 칩·정렬·조건 필터·`준비중` 표시는 **변경 없음**
- **판단**:
  - 거리 계산 규칙은 서버 `hospital/distance.ts` 와 **같은 식 하나**(`frontend/src/utils/geo.ts`)이고, 서버 함수로 뽑은 숫자와 일치하는지 테스트가 고정합니다. 서버가 거리를 주면 서버 값이 우선입니다
  - 전문의 승인 판정은 **새로 만들지 않았습니다** — 서버 `isVerifiedSpecialist` 를 읽기만 합니다. 탐색 카드의 배지는 조건 칩 이름과 맞추기 위해 `전문의` 그대로 둡니다
  - 카카오맵 키는 아직 없어 **코드 변경 없음**입니다. 키를 `frontend/.env` 의 `VITE_KAKAO_MAP_JS_KEY` 에 넣고 재시작하면 지도가 뜹니다
  - **카카오맵 키를 받으면 할 일**: 키를 넣은 뒤 지도 마커를 눌렀을 때 아래 카드의 거리(`0.4km` 표기, 위치를 허용하지 않으면 거리 없음)를 다시 확인 — 지금은 키가 없어 마커가 생기지 않아 확인하지 못했습니다
  - 좁은 화면(360px)의 전문의 상세에서는 `전문의 인증` 배지가 이름 아래 줄로 내려갑니다(이름이 두 줄로 쪼개지지 않게 — QA 에서 발견해 고침)
  - 위치를 허용하지 않은 사람에게 "위치를 켜면 거리를 볼 수 있어요" 같은 안내는 넣지 않았습니다 — 지역명만 보입니다
  - 남은 것(기존 문제, 이번 범위 밖): 카드의 회색 `상담 마감` 을 누르면 병원 상세로 넘어갑니다(상담 신청은 열리지 않음 — 카드 안 버튼 구조의 기존 문제, 알려진 문제에 기록), 탐색 화면 위쪽의 `스케일링·예방 · 준비중` 탭은 눌립니다(목록은 비어 보임). 시드 광고 기간이 7~9월이라 오늘은 `광고` 표시가 화면에 나오지 않습니다(QA 는 응답을 바꿔 확인)
