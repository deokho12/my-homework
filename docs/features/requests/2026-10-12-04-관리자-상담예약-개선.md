# 관리자 상담 관리 개선 (상태 5단계 · 확정 일시 · 취소 사유 · 전화 걸기 · 검색)

**작성자**: 안덕호
**작성일**: 2026-10-12
**대상 화면**: 상담 관리 — `docs/features/admin-consultations.md`, 상담 상세 — `docs/features/admin-consultation-detail.md`
**급한가요**: 급함 (화면기획 P0)

> 화면기획: https://claude.ai/artifact/BYpaxGQsLrLyYsA7sgqvKV → "병원 관리자" 페이지의 **03 상담 예약 관리**

---

## 무엇을 하고 싶으신가요

병원 실장님이 들어온 상담을 보고 바로 전화하고, 내원 날짜를 확정해 두고, 실제로 왔는지까지 한 화면에서 처리하게 하고 싶어요.

---

## 왜 필요한가요

- 지금은 `예약완료` 로만 표시되고 **언제 오기로 했는지** 적을 곳이 없어서 메모에 적어야 합니다.
- 예약한 사람이 실제로 왔는지(내원) 구분이 안 돼서, 나중에 상담 → 내원 전환을 셀 수 없습니다.
- 연락처가 글자로만 있어서 전화를 바로 걸 수 없습니다.

---

## 지금은 어떻게 되어 있나요

- 상태 4개: `신규` `연락중` `예약완료` `취소`, 확인창 없이 바로 바뀜
- 목록과 상세가 별도 화면, 목록에서 연락처 전체가 보임
- 검색·기간 필터·전화 걸기 없음, 예약 날짜·시간 입력 없음
- 메모 추가·처리 이력은 있음

---

## 이렇게 되면 좋겠어요

- **상태 5개**: `신규` → `연락중` → `예약확정` → `내원완료`, 어느 단계에서든 `취소`
  - 화면 이름도 "상담 예약"으로 (사이드 메뉴 포함)
- `예약확정` 을 고르면 **확정 날짜·시간 입력이 필수**. 없으면 저장되지 않음
- `취소` 를 고르면 **사유 선택 필수**: 연락이 안 됨 / 환자 요청 / 진료 불가 시술 / 중복 신청 / 기타
- 목록 상단 상태 탭에 건수 표시: `전체 42` `신규 5` …
- 목록에서는 연락처 가운데를 가림(`010-****-4411`), 상세에서만 전체 번호 + **`전화 걸기` 버튼(tel 링크)**
- 검색(이름, 연락처 뒷자리), 기간(오늘 / 이번 주 / 최근 30일), 시술(9개 대분류) 필터
- 신규 상태로 **24시간이 지나면 `지연`** 표시(빨강)
- 넓은 화면에서는 왼쪽 목록 + 오른쪽 상세 패널로 한 화면에서 처리 (좁으면 지금처럼 화면 이동)
- 상세에 `유입`(어느 화면에서 신청했는지) 표시 — 데이터가 없으면 빼도 됩니다
- 처리 이력에 "누가 언제 무엇으로 바꿨는지 · 환자 알림 발송" 기록

---

## 이것만은 지켜주세요 / 건드리지 말아주세요

- **상태 값이 바뀌는 것은 서버 계약 변경입니다** (`예약완료` → `예약확정` + `내원완료`, 확정 일시·취소 사유 필드). interface-master가 계약을 먼저 정하고, 백엔드는 협업자와 확인 후 진행해 주세요
- 개인정보 규칙(`docs/decisions/0001-roles-and-pii.md`)대로: 담당 병원 관리자만 전체 번호, 운영자는 마스킹
- 상태 변경 시 환자 알림은 서버가 생성 (프론트 임시 코드 정리 계획과 맞추기)
- 메모·처리 이력 기능은 그대로 유지

---

## 확인하고 싶은 것

- `예약확정` 을 누르고 날짜를 비워 두면 저장되지 않고 안내가 나온다
- 날짜·시간을 넣고 저장하면 목록과 사용자 마이페이지에 확정 일시가 보인다
- `취소` 는 사유를 골라야 저장된다
- 목록에서는 번호 가운데가 가려지고, 상세의 `전화 걸기` 는 전화 앱을 연다
- 이름으로 검색하면 목록이 실제로 줄어든다
- 26시간 전 신규 건에 `지연` 이 붙는다

## 검토 결과

- **상태**: 완료 (2026-10-13, QA 통과 — 확인 항목 6개 전부 실제 브라우저에서 확인)
- **영향 범위**:
  - 화면: 관리자 상담 관리 → **상담 예약** 으로 개편(`/admin/consultations`, 넓은 화면은 목록+상세 두 칸, 좁은 화면은 목록 → 상세 이동). 관리자 홈 버튼 이름도 `상담 예약`
  - 상태 5단계(`신규 → 연락중 → 예약확정 → 내원완료`, 어디서든 `취소`), 확정 날짜·시간, 취소 사유, 예약확정 상태의 일시 변경, 상태별 건수 탭, 기간·시술·검색, `지연` 표시, 목록 연락처 가림, 상세의 `전화 걸기`, 처리 이력(누가·언제·무엇으로·환자 알림 발송)
  - 환자 마이페이지: 예약확정 건에 `10/9(목) 14:00 방문` 강조 (요청서 02 에서 준비한 자리)
  - 함께 고친 것: 관리자 문의 목록의 선택 표시가 화면 낭독기에 전달되지 않던 문제(요청서 03)
  - 서버 계약·데이터 설계(`docs/api/openapi.yaml`, `docs/api/README.md`, `docs/database/README.md`) 갱신. **서버(협업자 영역)는 손대지 않음** — 서버에 상담 기능이 아직 없어 지금은 브라우저 저장소로 동작. 인계 목록은 데이터 설계 문서 §12
  - 문서: `admin-consultations.md`·`admin-consultation-detail.md` 전면 갱신, `admin-home.md`, `mypage.md`, `notifications.md`, `consult-request.md`, `known-issues.md`, `README.md`
- **판단**:
  - 기존 `예약완료` 건은 이름만 `예약확정` 으로 보이고 데이터는 그대로(바꾸지 않음). `내원완료` 만 새로 생김
  - 상태는 **자유롭게** 옮길 수 있고(잘못 누른 것 되돌리기, 예약 없이 온 환자 바로 내원완료), 예약확정은 날짜·시간, 취소는 사유만 꼭 받음
  - 상태 5개 모두 **고른 뒤 `저장` 을 눌러야** 바뀜 — 바뀌면 환자에게 알림이 나가 되돌릴 수 없어서, 스크롤 중 잘못 누르는 일을 막음
  - 예약확정 상태에서는 날짜만 고칠 수 있고(`일시 변경`), 이력과 환자 알림이 남음. 취소·연락중으로 되돌리면 확정 일시는 지워짐(환자 화면에 지난 약속이 남지 않게), 내원완료는 유지
  - 목록 연락처는 **병원 관리자에게도** 가운데를 가림 — 전체 번호는 열람이 기록되는 상세에서만. 운영자는 상세에서도 가려지고 전화 걸기·상태 변경·메모가 없음. 운영자 검색은 연락처 뒤 4자리로만
  - 병원 관리자는 **담당 병원 상담만** 봄(이전에는 모든 병원이 섞여 보였음)
  - 기본으로 `신규` 탭과 `최근 30일` 이 열림. 빈 화면이면 "최근 30일 기준" 안내와 `전체 기간 보기` 를 보여줘 오래된 미처리 건이 가려지지 않게 함
  - `유입`(어느 화면에서 신청했는지)은 기록된 데이터가 없어, 화면기획의 `엑셀로 내려받기` 는 요청서에 없어 만들지 않음(알려진 문제에 기록)
  - 남은 한계(알려진 문제에 기록): 브라우저 저장·가짜 권한, 목록 100건 상한, 관리자 홈 숫자 카드는 병원별로 나뉘지 않음, 샘플 상담 날짜가 6~7월이라 기본 화면에서는 안 보임
