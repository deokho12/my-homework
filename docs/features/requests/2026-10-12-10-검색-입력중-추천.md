## 무엇을 하고 싶으신가요

"인레"까지만 쳐도 아래에 `인레이 (충치치료 › 인레이)`, 인레이 하는 병원, 원장님이 묶여서 보이고, 골라서 바로 이동하게 하고 싶어요.

---

## 왜 필요한가요

지금은 Enter를 쳐야 어디론가 바로 이동해서, 무엇을 찾게 될지 미리 알 수 없습니다. 시술 이름을 정확히 모르는 사람(예: "금니", "때우기")도 찾을 수 있어야 합니다.

---

## 지금은 어떻게 되어 있나요

검색하면 결과 목록 없이 시술 카테고리 · 병원 상세 · 전문의 상세로 바로 이동합니다. 추천 검색어(광고) 알약과 인기 검색어 탭이 있습니다.

---

## 이렇게 되면 좋겠어요

- 입력이 있으면 인기 검색어 자리에 **추천 목록**을 그룹으로 표시: `시술` / `병원` / `원장님`
  - 시술: 이름 + `대분류 › 세부`, 준비중이면 `(준비중)` 표시
  - 병원: 이름 + 지역 · 관련 시술
  - 원장님: 이름 + 소속 병원 · 전문 분야
- 항목을 누르면 해당 화면으로 이동
- 시술 동의어(`taxonomy.ts` 의 `keywords`)로도 찾음: "금니" → 크라운, "때우기" → 레진
- 결과가 없으면 지금 문구 유지
- 입력이 비면 지금처럼 추천 검색어 + 인기 검색어

---

## 이것만은 지켜주세요 / 건드리지 말아주세요

- Enter로 바로 이동하는 지금 동작은 유지 (추천 목록의 첫 항목으로 이동)
- 인기 검색어·추천 검색어(광고) 영역은 그대로

---

## 확인하고 싶은 것

- "인레"를 치면 시술 그룹에 인레이가 보이고, 누르면 충치치료 카테고리에 인레이가 골라진 채로 열린다
- "금니"를 치면 크라운이 보인다
- 글자를 지우면 인기 검색어 화면으로 돌아온다

## 검토 결과

- **상태**: 완료 (2026-10-13, QA 통과 — 확인 항목 3개 + 받아들임 조건 28개 중 25개 실제 화면 확인. 2개는 "인터넷이 완전히 끊긴 경우" 에 한해 앱 전체 공통 동작 때문에 실패 안내가 뜨지 않음 — 알려진 문제에 기록. 1개는 화면 낭독기 실청취라 확인 불가)
- **영향 범위**:
  - 검색 화면(`/search`): 글자를 치면 인기 검색어 자리에 **추천 목록** `시술` / `병원` / `원장님` (그룹마다 최대 3개). 글자를 모두 지우면 추천 검색어(광고)·인기 검색어가 **그대로** 돌아옴
  - 시술: 이름 + `충치치료 › 인레이`, 동의어로 찾으면 `‘금니’ 로 찾았어요`, 준비중이면 회색 `준비중`
  - 병원: 이름 + 지역 · 관련 시술 / 원장님: 이름 + 소속 병원 · 전문 분야(인증된 경우만)
  - 항목을 누르면 시술 → 카테고리(그 세부 시술이 골라진 채), 병원 → 병원 상세, 원장님 → **전문의 상세**
  - 키보드 ↑↓·Enter·Esc, 화면 낭독기용 콤보박스 구조와 결과 수 안내
  - 함께 고친 것: 한글 조합 중 Enter 가 검색을 실행하던 문제, 서버 검색이 실패해도 아무 표시가 없던 문제
  - 문서: `search.md`, `category.md`, `known-issues.md`. 서버는 바뀌지 않음
- **판단**:
  - **병원·원장님 = 이름이 맞는 곳 먼저 + 입력이 시술에 걸리면 그 시술을 하는 곳** (요청자 결정). 시술로 걸린 병원은 카테고리 화면과 **같은 순서**(같은 조회를 함께 씀) — QA 에서 추천 3곳과 카테고리 화면 상위 3곳이 같은 것을 확인
  - **Enter 는 추천 목록의 첫 항목으로** — 지금까지의 Enter 와 같은 곳으로 감. 유일하게 바뀐 것은 **원장님 이름**으로 찾을 때: 예전에는 소속 병원으로 갔고 이제는 전문의 상세로 감(추천 줄·인기 검색어·홈 알약 네 경로 모두 같은 곳)
  - 준비중 표시는 앱 전체와 같은 회색 `준비중` 칩(요청서의 `(준비중)` 괄호 대신)
  - 서버 부담을 줄이려고 한 글자일 때는 시술만 보여주고(`두 글자부터 병원·원장님도 찾아드려요`), 두 글자부터 입력이 0.25초 멈출 때 병원·원장님을 물어봄. 같은 글자로 돌아오면 다시 묻지 않음
  - 알려진 한계(근거와 함께 기록): 한 번 멈출 때 서버에 최대 7번 물음(통합 검색 기능이 서버에 생기면 1번으로 줄일 수 있음 — 협업자 인계), 인터넷이 완전히 끊기면 실패 안내 대신 불러오는 중 표시가 계속됨(앱 전체 공통), Tab 키로는 추천이 접히지 않음
  - 두 글자째를 치고 결과가 나오기 전 약 0.25초 동안 추천 자리가 비어 보임 — 서버에 너무 자주 묻지 않으려고 기다리는 시간이라 그대로 둠(QA 판단: 거슬림 약함)
