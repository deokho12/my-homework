**대상 화면**: 상담 신청 `consult-request.md`, 마이페이지 `mypage.md`, 관리자 상담 예약 `admin-consultations.md`·`admin-consultation-detail.md`, 알림 `notifications.md`·`admin-notifications.md`

**먼저 끝나야 하는 요청**: 12

---

## 무엇을 하고 싶으신가요

지금 브라우저 안에만 저장되는 상담 신청, 상담 예약 처리, 알림을 서버에 저장하고 싶어요. 환자가 신청하면 병원 관리자가 다른 컴퓨터에서 실제로 보고 처리할 수 있어야 해요.

---

## 왜 필요한가요

- 지금은 환자가 신청한 상담이 그 환자의 브라우저에만 있습니다. 병원이 실제로 받을 수 없어서, 서비스의 핵심이 동작하지 않는 상태입니다
- 제3자 제공 동의 기록이 브라우저에만 남아 법적 기록이 되지 않습니다 (`known-issues.md`)
- 🔴 **다른 사람의 알림이 보입니다** (`known-issues.md` 맨 위). 알림이 계정별로 나뉘지 않기 때문입니다

---

## 지금은 어떻게 되어 있나요

- 화면과 규칙은 다 만들어져 있고, 계약도 앞서 있습니다
  - 계약: `docs/api/openapi.yaml` 의 상담·알림 부분
  - 데이터 설계: `docs/database/README.md` §12(상담 예약), §15(알림 상태 칸)
  - 계약 설명: `docs/api/README.md` §9(알림 책임)
- 프론트의 `features/consult/api/consultApi.ts` 와 `features/notification/api/notificationApi.ts` 가 계약을 흉내 내서 `lib/localCollection.ts` 에 씁니다
- 원칙은 "서버가 생기면 함수 본문만 바꾸고, 화면과 테스트는 그대로" 입니다 (`known-issues.md` 개발자용 메모)

---

## 이렇게 되면 좋겠어요

- 서버에 상담 기능을 만들어 주세요
  - 상담 신청: 동의 기록(시각, 안내문 버전) 포함
  - 내 상담 목록
  - 관리자 목록과 상세: 목록의 연락처는 가리고, 상세를 열면 열람 기록을 남깁니다
  - 상태 5단계 변경, 확정 일시, 취소 사유, 처리 이력, 메모
- 상태가 바뀌면 **같은 저장 안에서** 환자 알림을 만들어 주세요
  - 문구는 요청서 08 그대로입니다. 지금 화면의 `features/consult/consultNotificationText.ts` 문구를 서버로 옮기면 됩니다
- 알림은 **계정별로** 나눠 주세요. 환자는 자기 알림만, 관리자는 담당 병원 알림만 봅니다
- 상태 판정과 `지연`(24시간) 같은 규칙은 순수 함수로 만들어 주세요
  - 프론트 `features/consult/lib/transition.ts` 와 판정이 갈리면 안 됩니다 (AGENTS.md "같은 판정을 두 곳에 두지 않는다")
- 프론트 api 함수 본문을 서버 호출로 바꾸고, `localCollection.ts` 에서 상담·알림 부분을 지워 주세요
- 브라우저에 남아 있는 예전 샘플 상담·알림은 옮기지 않습니다. 대신 서버 시드로 샘플을 몇 건 만들어 주세요
  - 날짜는 오늘 기준으로 잡아서, 대시보드 숫자가 0 이 아니게 해 주세요

- 화면 모양, 문구, 동작은 지금과 같게 둡니다. 이번에는 저장 위치만 바뀝니다
- 개인정보
  - 서버 로그에 연락처와 이름을 찍지 않습니다 (AGENTS.md dev 로그 규칙)
  - 운영자에게는 연락처를 가립니다 (결정 0001 결정 3)
- 동의 안내문의 보유기간 `[확정 필요]` 는 그대로 둡니다. 요청서 20 에서 확정합니다

## 확인하고 싶은 것

- 브라우저 A 에서 환자로 상담을 신청하면, 브라우저 B 에서 병원 관리자로 로그인했을 때 그 신청이 `신규` 로 보인다
- 관리자가 `예약확정` + 일시로 저장하면, 환자 계정의 알림함과 마이페이지 상담 내역에 그 일시가 보인다
- 환자 A 의 알림이 환자 B 에게 보이지 않는다
- 서버를 껐다 켜도 상담과 알림이 남아 있다
- 동의 기록(시각, 버전)이 서버에 남는다. 관리자 화면에 보여주는 것은 이번 범위가 아니다
