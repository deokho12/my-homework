# 상담 신청 화면 개선 (자동 채움 · 형식 검사 · 제3자 제공 동의 · 완료 화면)

---

## 무엇을 하고 싶으신가요

환자가 상담을 신청할 때 이미 아는 정보는 다시 쓰지 않게 하고, 신청이 끝나면 "다음에 무슨 일이 일어나는지"를 화면으로 보여주고 싶어요.

---

## 왜 필요한가요

- 상담 신청은 플랫폼 수익의 기준이 되는 핵심 동선이라, 여기서 이탈하면 안 됩니다.
- 환자의 이름과 연락처를 병원에 넘기는 구조라서 **개인정보 제3자 제공 동의**를 받아야 합니다. 지금은 이 동의가 없습니다.

---

## 지금은 어떻게 되어 있나요

`docs/features/consult-request.md` 기준:

- 이름이 로그인한 계정에서 자동으로 채워지지 않습니다.
- 연락처 형식을 전혀 검사하지 않습니다 (`abc`, `1` 도 통과).
- 희망 시간은 `평일 오전` `평일 오후` `주말` 3개입니다.
- 신청하면 브라우저 알림창만 뜨고 직전 화면으로 돌아갑니다.
- 제3자 제공 동의가 없습니다.

---

## 이렇게 되면 좋겠어요

- 이름·연락처를 계정 정보로 **자동 채움** (고칠 수는 있게). 칸 아래에 "계정 정보에서 자동으로 채웠어요" 안내
- 연락처 **형식 검사** (휴대폰 번호 형식이 아니면 신청 버튼이 눌리지 않고 안내 문구)
- 희망 시간에 **`평일 저녁` 추가** → `평일 오전` `평일 오후` `평일 저녁` `주말` 4개 (2열 버튼)
- 희망 시술 목록에 **`잘 모르겠어요`** 선택지 추가
- 맨 아래 **`[필수] 개인정보 제3자 제공 동의`** 체크박스: "상담 연락을 위해 이름과 연락처를 ○○치과에 제공해요" + `자세히` 링크. 체크해야만 신청 버튼이 활성화
- 신청 후 브라우저 알림창 대신 **완료 화면**: "상담 신청이 접수되었어요", 병원·시술·연락 시간·상태(신규 접수) 요약, `내 상담 내역 보기` 버튼(마이페이지 상담 내역으로)

---

## 이것만은 지켜주세요 / 건드리지 말아주세요

- 로그인하지 않으면 로그인 화면을 거쳐 돌아오는 지금 동작은 그대로
- 동의는 **신청할 때마다** 받는 것으로 시작합니다 (가입 때 한 번 받는 방식은 추후 검토)
- 동의 여부와 시각을 상담 데이터에 같이 저장할 수 있게 해 주세요. 서버 계약(`docs/api/openapi.yaml`)에 필드가 필요하면 interface-master가 먼저 계약을 정하고, 백엔드 작업은 협업자와 확인 후 진행

---

## 확인하고 싶은 것

- 로그인한 상태로 상담 신청에 들어오면 이름·연락처가 이미 채워져 있다
- 연락처에 `abc` 를 넣으면 신청 버튼이 눌리지 않고 안내 문구가 보인다
- 동의 체크를 안 하면 신청 버튼이 회색이고 눌리지 않는다
- 신청하면 완료 화면이 나오고, `내 상담 내역 보기` 를 누르면 방금 신청한 건이 `신규` 로 보인다
- 관리자 상담 목록에도 같은 건이 신규로 들어와 있다

## 검토 결과

- **상태**: 완료 (2026-10-12, QA 통과). "확인하고 싶은 것" 4번 뒷부분("내 상담 내역에서 방금 신청한 건이 `신규` 로 보인다")도 요청서 02 완료와 함께 실제 브라우저에서 확인됨
- **영향 범위**:
  - 화면: 상담 신청(`/consult/:hospitalId`) 전면 개편 — 자동 채움·연락처 형식 검사·`평일 저녁`·`잘 모르겠어요`(기본 선택)·제3자 제공 동의(+`자세히` 팝업)·완료 화면
  - 서버 계약(`docs/api/openapi.yaml`): 희망 시간 4개, 동의 필드(`thirdPartyConsent`)와 `422 THIRD_PARTY_CONSENT_REQUIRED`, 연락처 오류 문구 통일. **서버(협업자 영역)는 손대지 않음** — 서버에 상담 기능이 아직 없어 충돌 없음, 인계 목록은 `docs/api/README.md` 미결 26번
  - 함께 바뀐 것: 회원가입 시에도 이전 계정의 임시 데이터를 비움(다른 계정 전화번호가 채워지는 경로 차단), 로그인·회원가입 입력 칸 부품을 공용으로 옮김
  - 문서: `consult-request.md`, `known-issues.md`, `mypage.md`, `notifications.md`
- **판단**:
  - 계정에 전화번호가 없어(회원가입이 번호를 받지 않음) 연락처는 **내가 지난번 상담 신청에 쓴 번호**로 채우기로 결정. 계정별로 구분해 다른 계정의 번호는 절대 채워지지 않음
  - 희망 시술 기본값은 `잘 모르겠어요` — 예전처럼 첫 시술이 미리 골라져 관리자에게 틀린 시술이 가던 문제도 함께 해소
  - 동의 안내문 5개 항목은 초안이며 **법무 검토 전**. 4번 보유·이용 기간은 회사 결정 전이라 화면에 `[확정 필요]` 가 그대로 보임 → **출시 전 반드시 교체**
  - 동의 기록(시각·안내문 버전)은 지금은 이 브라우저에만 저장됨. 법적 기록이 되려면 서버 상담 기능이 필요(협업자 인계)
  - 관리자 화면에 동의 기록을 보여주는 것은 이번 범위 밖(필요하면 별도 요청)
