## 무엇을 하고 싶으신가요

병원이 예약을 확정하면 "언제 오면 되는지"가 알림 한 줄에 바로 보이고, 문의에 답이 오면 알림으로 알려주고 싶어요.

---

## 왜 필요한가요

지금 상담 알림은 "상담 상태가 '예약완료'(으)로 변경되었어요" 한 가지라, 환자가 날짜를 보려면 다시 들어가야 합니다.

---

## 지금은 어떻게 되어 있나요

상담 상태 변경 · 이벤트 · 안내 알림, 읽음 처리, 모두 읽음이 있습니다. 상담 알림을 누르면 병원 상세로 갑니다.

---

## 이렇게 되면 좋겠어요

- 알림 종류별 문구:
  - 예약확정: **"상담 예약이 확정됐어요"** / "○○치과의원 · 10/9(목) 14:00 방문. 변경이 필요하면 병원에 전화해 주세요" → 누르면 **마이페이지 상담 내역**
  - 연락중: "병원이 연락 중이에요" / "○○치과의원이 상담 신청을 확인했어요. 곧 전화가 올 거예요"
  - 취소: "상담이 취소됐어요" / 취소 사유 포함
  - 문의 답변: **"문의에 답변이 왔어요"** / 답변 앞부분 → 누르면 **마이페이지 '내 문의'** (그 문의가 펼쳐진 채로 — 비공개 답변은 병원 상세에 없어서, 2026-10-13 요청자 확인)
  - 찜한 병원의 새 이벤트 (이벤트 기능 생기면)
- 왼쪽에 종류 아이콘(예약/문의/상담/이벤트/안내), 안 읽음은 배경색 + 굵은 글씨

- 앱 푸시·문자는 이번 범위가 아닙니다 (앱 내 알림함만)
- 사용자 알림과 관리자 알림이 섞이지 않는 지금 규칙 유지

## 검토 결과

- **상태**: 완료 (2026-10-13, QA 통과 — 확인 항목 3개 + 상태별 문구 전부를 실제 화면에서 관리자 저장 → 사용자 알림함 순서로 확인)
- **영향 범위**:
  - 화면: 사용자 알림함(`/notifications`) — 종류 아이콘(예약·상담·문의·이벤트·안내), 상태별 문구, 안 읽음 표시(배경·굵은 글씨·점 + 화면 낭독기에 `안 읽음`), 시각 표기 `10/9 14:02`
  - 상담 알림을 누르면 **마이페이지 상담 내역**으로 가고 그 상담 줄이 강조됨(예전에는 병원 상세로 갔고, 샘플 상담 알림은 눌러도 이동하지 않았음 — 함께 해결)
  - 문의 답변 알림(요청서 03 에서 만든 것)은 그대로 — 누르면 마이페이지 `내 문의` 에서 그 문의가 펼쳐짐
  - 관리자 알림함은 **바뀌지 않음** (사용자 알림과 섞이지 않는 규칙 유지)
  - 서버 계약·데이터 설계: 알림에 `어떤 상태로 바뀌었는지` 칸 하나 추가(`consultStatus` — 아이콘을 가르는 데만 씀), 문구 표를 계약에 고정. **서버(협업자 영역)는 손대지 않음** — 알림은 아직 브라우저 저장이라 지금은 화면 쪽이 같은 문구를 만듦. 인계 목록은 데이터 설계 문서 §15
  - 문서: `notifications.md`, `mypage.md`, `known-issues.md`
- **판단**:
  - 문구는 요청서 그대로: 예약확정 `상담 예약이 확정됐어요` / `○○치과의원 · 10/16(금) 14:00 방문. 변경이 필요하면 병원에 전화해 주세요`, 연락중 `병원이 연락 중이에요` / `○○치과의원이 상담 신청을 확인했어요…`(병원 이름 끝 글자에 맞춰 `이`/`가`), 취소 `상담이 취소됐어요`
  - **취소 사유는 환자용 문장으로** (요청자 결정): `연락이 닿지 않아 취소됐어요` / `요청하신 대로 취소했어요` / `이 병원에서 진료하지 않는 시술이에요` / `같은 신청이 있어 하나로 정리했어요` / 기타는 `자세한 사유는 병원에 문의해 주세요`. 관리자 화면의 말(`중복 신청` 등)은 환자에게 가지 않음
  - **상담 알림은 전부 상담 내역으로** (요청자 결정 — 예약확정뿐 아니라 연락중·취소도)
  - **예약 일시 변경 알림도 같은 형식으로 맞춤**(`예약 일시가 바뀌었어요` / `○○치과의원 · 10/17(토) 15:30 방문…`) — 한 알림함 안에서 두 말투·두 날짜 표기가 섞이지 않게. 날짜는 전부 `10/16(금) 14:00` 형식
  - 내원완료·신규로 되돌림은 요청서에 문구가 없어 **지금 문구 유지**
  - 이미 보낸 알림은 나중에 날짜가 바뀌어도 고쳐 쓰지 않음(그때 보낸 소식의 기록). 최신 일시는 마이페이지 상담 내역에서 보임
  - 미룬 것(알려진 문제에 근거와 함께): **찜한 병원의 새 이벤트** 알림(이벤트 기능이 아직 없음), 예전에 받은 예약 알림은 상담 아이콘으로 보임(그때 상태를 적어 두지 않았음), 알림 문구의 병원 이름은 상태를 바꾼 관리자 화면이 넘겨줌(서버가 생기면 사라짐)
  - ⚠️ **예약 알림이 "병원에 전화해 주세요" 라고 하는데 앱에 병원 전화번호가 없습니다.** 병원 데이터에 전화번호 칸이 아직 없어서입니다. 요청서 06 설계에서 처음 생기고, 환자 화면에도 보여줄지는 협업자 확인 질문으로 올려 둠
