## 무엇을 하고 싶으신가요

치과 원장님이나 실장님이 운영자에게 연락하지 않고 직접 가입하게 하고 싶어요. 가입할 때는 공공데이터에 이미 있는 자기 치과를 찾아서 연결하면 됩니다.

## 이렇게 되면 좋겠어요

### 가입

- 회원가입에 **`치과 관계자이신가요?` 토글**을 둡니다 (기본 꺼짐). 로그인 화면 아래에는 `치과 관계자이신가요? 병원 파트너로 가입하기` 입구를 둡니다. 둘 다 구 06 그대로입니다
- 토글을 켜면 **우리 치과 찾기**가 열립니다
  - 치과 이름과 지역으로 공공데이터 목록을 검색해서 고릅니다
  - 이미 입점했거나 승인 대기 중인 치과는 고를 수 없고, "이미 신청된 치과예요. 운영자에게 문의해 주세요" 를 보여줍니다
  - 목록에 없는 치과(새로 개원 등)는 `직접 입력` 으로 넣습니다: 치과명, 대표번호(형식 검사), 주소 검색(카카오, 고르면 좌표 자동), 상세 주소
- 담당자 직책(대표원장 / 실장 / 코디네이터 / 기타)을 받습니다
- 토글을 켰을 때만 `[필수] 병원 파트너 이용약관` 동의를 받습니다

### 승인

- 가입하면 **`승인 대기`** 상태가 되고 완료 화면에 아래를 보여줍니다
  - "관리자 화면에서 사업자등록증을 올려 주세요. 확인한 뒤 승인 결과를 알림으로 알려드려요. 승인 전에도 병원 정보를 미리 입력해 둘 수 있어요"
  - 버튼: `사업자등록증 올리기` / `병원 정보 입력하기`
- 관리자 화면에서 **사업자등록증을 올립니다.** 올리지 않으면 계속 승인 대기입니다
- 승인 전에는
  - 관리자 화면을 쓸 수 있고, 병원 정보를 미리 입력해 둘 수 있습니다
  - 환자 앱에서는 그 치과가 **미입점(공공데이터 정보)으로 계속 보입니다.** 직접 입력한 새 치과는 보이지 않습니다
- 승인되면 환자 앱에서 그 치과가 `입점` 으로 바뀌고 상담 신청이 열립니다. 병원이 미리 입력한 정보도 이때 반영됩니다
- **운영자 검수 화면**(간단히)
  - 승인 대기 목록
  - 사업자등록증 보기 (열람 기록을 남깁니다)
  - 승인 / 반려 (반려할 때는 사유를 받습니다)
- 승인·반려 결과는 병원 관리자에게 알림으로 보냅니다
- 개발 단계에서는 자동 승인 설정을 둡니다 (구 06 그대로)

### 열린 질문에 대한 제 답 (§20.7)

| # | 질문 | 답 |
|---|---|---|
| 1 | 반려 상태와 사유를 지금 만들까 | **만든다.** 반려되면 사유를 보여주고 `서류 다시 올리기` 를 누르면 다시 승인 대기가 된다 |
| 2 | 가입 전 업로드는 어떻게 받나 | **ⓒ 계정을 먼저 만들고, 가입 뒤 관리자 화면에서 올린다.** 로그인하지 않은 업로드는 만들지 않는다 (보안상 열어 두는 곳을 줄이기 위해) |
| 3 | 사업자등록증을 바꾸면 승인이 풀리나 | **풀리지 않는다.** 운영자 목록에 `서류 바뀜` 표시만 한다 |
| 4 | 주소 검색의 지역 값 | 우리 치과 찾기로 고르면 공공데이터의 지역을 쓴다. 직접 입력하면 카카오 결과를 쓰고, 거기에 없으면 서버가 주소에서 계산한다 |
| 5 | 파일 보존 기간 | 반려 30일 후, 입점 해지 30일 후 삭제 (기본값 — 개인정보처리방침과 함께 요청서 20 에서 확정) |
| 6 | 입점 문의 화면을 남길까 | **없앤다.** `/partner-inquiry` 는 `병원 파트너로 가입하기` 안내로 바꾼다 (입구 하나, 운영자 대기열 하나) |
| 7 | 승인 결과 "문자" | 문자를 보낼 수단이 없다 → 화면 문구에서 "문자"를 빼고 알림으로만 알린다 |
| 8 | 비밀번호 찾기 | 요청서 20 에서 만든다. 그 전까지는 운영자가 서버 명령으로 재설정한다 |
| 9 | 병원 전화번호를 공개하나 | **공개한다** (요청서 17 과 같음) |

## 이것만은 지켜주세요 / 건드리지 말아주세요

- 토글을 끈 상태의 일반 사용자 가입은 지금과 똑같이 동작해야 합니다
- 사업자등록증
  - 저장과 열람은 운영자만 합니다
  - 열람할 때마다 기록을 남깁니다
  - 서버 로그에 파일 내용과 사업자번호를 찍지 않습니다
- 한 치과에 담당자를 여러 명 둘 수 있는 구조(결정 0001 결정 1)는 유지합니다. 두 번째 담당자는 가입이 아니라 운영자가 지정합니다
- 파일은 일단 서버 디스크 폴더에 저장합니다. 단 저장 위치는 설정 한 곳에서 바꿀 수 있게 해 주세요 (요청서 21 에서 클라우드 저장소로 옮깁니다)

## 확인하고 싶은 것

- 토글을 켜고 "강남 ○○치과"를 검색해서 고르면 주소와 전화번호가 채워진다
- 이미 입점했거나 승인 대기 중인 치과는 고를 수 없다
- 가입 직후 `/admin` 사이드 메뉴 아래에 `승인 대기` 와 사업자등록증 올리기 안내가 보인다
- 승인 전에 환자 앱에서 그 치과는 미입점(상담 신청 없음)으로 보인다
- 운영자가 승인하면 환자 앱에 상담 신청 버튼이 생긴다
- 반려하면 관리자 화면에 사유와 `서류 다시 올리기` 가 보인다
- 운영자가 아닌 계정으로 사업자등록증 주소를 열면 막힌다
- 토글을 끈 일반 가입이 예전과 똑같이 된다
