# 운영 서버 올리기 (인터넷 주소로 접속되게)

**작성자**: 안덕호
**작성일**: 2026-10-21
**대상 화면**: 화면 변화 없음 — 저장소 전체와 배포
**급한가요**: 보통 — 목표는 모두의창업 2라운드 데모 전
**먼저 끝나야 하는 요청**: 15, 16, 17 (18·19·20 은 올린 뒤에 이어서 배포해도 됩니다)

---

## 무엇을 하고 싶으신가요

지금은 제 컴퓨터에서만 열리는 앱을, 휴대폰에서도 인터넷 주소로 열 수 있게 하고 싶어요.

---

## 왜 필요한가요

- 치과와 환자에게 보여주고 실제로 쓰게 하려면 인터넷 주소가 있어야 합니다
- 2라운드 심사에 "동작하는 MVP 링크"를 내야 합니다

---

## 지금은 어떻게 되어 있나요

- DB 는 SQLite 입니다. PostgreSQL 로 옮기는 절차는 `docs/database/README.md` §7 에 있습니다
- `backend/.env.example` 에 예시 키가 들어 있습니다
- 첫 운영자 계정은 서버 명령으로 만듭니다 (결정 0001 결정 4, `backend/README.md` "운영자 부트스트랩")

---

## 이렇게 되면 좋겠어요

- **DB**: `docs/database/README.md` §7 절차대로 PostgreSQL 로 옮깁니다
- **서버와 화면 배포**
  - 국내 리전 클라우드에 올립니다. 개인정보가 국내에 있어야 국외 이전 고지가 필요 없습니다
  - 어느 회사를 쓸지 비용과 난이도를 비교해서 2~3곳 제안해 주세요. 모두의창업 AI 솔루션의 `온팟` 도 후보에 넣어 주세요
- **도메인 + HTTPS**: 서버 주소는 설정으로 둡니다
- **파일 저장소**: 18 의 서류와 19 의 사진을 클라우드 저장소로 옮깁니다 (설정만 바꾸면 되게)
- **비밀값**
  - 운영 키는 클라우드의 비밀값 설정에만 넣습니다
  - `backend/.env.example` 의 예시 키가 그대로 쓰이면 **서버가 켜지지 않게** 해 주세요
- **정기 작업**: 17 의 공공데이터 동기화를 정기적으로 돌립니다
- **백업과 알림**
  - DB 를 매일 백업하고, 복구를 한 번 실제로 해 봅니다
  - 서버가 죽으면 메일로 알림을 받습니다
- **운영 데이터**
  - 운영에는 샘플 병원, 샘플 계정, 시드 데이터를 넣지 않습니다
  - 첫 운영자 계정은 결정 0001 결정 4 방식(서버 명령)으로 만듭니다
- **이메일 발송**: 20 의 비밀번호 찾기에 쓸 이메일 발송 서비스를 연결합니다
- **배포 안내서**: `docs/deploy.md` 에 비개발자용으로 써 주세요. 다음 배포 때 제가 혼자 따라 할 수 있어야 합니다

---

## 이것만은 지켜주세요 / 건드리지 말아주세요

- 개발 환경(`npm run dev`)은 지금처럼 쉽게 켜져야 합니다. 필요하면 PostgreSQL 을 Docker 로 띄우는 방법을 안내해 주세요
- 저장소에 운영 키, 비밀번호, 서비스키를 절대 넣지 않습니다
- 비용이 드는 서비스는 가입하거나 결제하기 전에 저에게 먼저 물어봐 주세요

---

## 확인하고 싶은 것

- 휴대폰으로 `https://(도메인)` 에 들어가서 병원을 찾고 상담을 신청하면, 관리자로 로그인했을 때 그 신청이 보인다
- 서버를 다시 시작해도 데이터가 남는다
- 백업 파일로 다른 DB 에 복구하면 같은 데이터가 나온다
- 저장소 어디에도 운영 키가 없다
- `docs/deploy.md` 만 보고 다시 배포할 수 있다
