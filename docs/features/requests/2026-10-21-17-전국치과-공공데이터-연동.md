# 전국 치과 정보와 비급여 가격을 공공데이터(심평원)로 채우기

**작성자**: 안덕호
**작성일**: 2026-10-21
**대상 화면**: 병원 탐색 `explore.md`, 시술 카테고리 `category.md`, 병원 상세 `hospital-detail.md`, 검색 `search.md`, 운영자 관리자 홈 `admin-home.md`
**급한가요**: 급함 — 목표는 "실제 데이터로 동작하는 앱" (모두의창업 2라운드 전)
**먼저 끝나야 하는 요청**: 14 — 비급여 항목을 세부 시술에 연결하려면 서버에 31개 세부 시술이 있어야 합니다

---

## 무엇을 하고 싶으신가요

굿닥처럼 건강보험심사평가원(심평원)이 공개하는 데이터로 전국 치과를 앱에 보여주고 싶어요.

- 입점하지 않은 치과는 정보만 보여줍니다
- 입점한 치과는 지금처럼 상담 신청까지 받습니다

---

## 왜 필요한가요

- 지금 앱에는 샘플 병원 11곳뿐이라, 입점 병원이 생길 때까지 앱이 비어 보입니다
- 굿닥도 같은 구조입니다. 전국 병원 목록은 심평원 공공데이터로 채우고, 실제로 계약한 제휴 병원(약 6,000곳)에서만 접수·예약이 됩니다
- 벤처박스 심사 의견의 "정보 신뢰성"에 "공공데이터 기반"이라고 답할 수 있습니다
- 심평원이 공개하는 시술별 비급여 가격을 시술 기준으로 비교할 수 있습니다. 몰라몰라의 "시술로 찾기"와 딱 맞습니다
- 미입점 치과의 조회수가 쌓이면 입점 영업 자료가 됩니다 ("이번 달 몰라몰라에서 이 치과를 본 사람 N명")

---

## 지금은 어떻게 되어 있나요

- 병원은 운영자가 직접 등록한 것만 있습니다
- 병원 데이터에 **전화번호 칸이 없습니다.** 그래서 요청서 08 의 알림이 "병원에 전화해 주세요" 라고 하는데 앱 어디에도 번호가 없습니다

---

## 이렇게 되면 좋겠어요

### 쓰는 API

모두 공공데이터포털(data.go.kr)에 있고, 심평원 제공이며 무료입니다. 신청하면 자동 승인되고, 이용 조건은 공공누리 1유형(출처 표시)입니다.

| API | 쓰는 것 |
|---|---|
| 건강보험심사평가원_병원정보서비스 (병원기본목록) | 이름, 주소, 전화, 좌표, 종별. **종별코드 치과병원 41, 치과의원 51** 만 받습니다. 병원 고유 키는 `ykiho`(암호화된 요양기호)입니다 |
| 건강보험심사평가원_의료기관별상세정보서비스 | 진료과목, 전문과목별 전문의 수, 시설·장비, 교통, 세부정보. 진료시간이 어느 항목에 있는지는 명세서에서 확인해 주세요 |
| 건강보험심사평가원_비급여진료비정보조회서비스 (비급여항목병원목록상세) | `ykiho` 로 조회하면 항목명, 현재 금액(`curAmt`), 적용 기간이 나옵니다 |

### 가져오는 방식

- **화면에서 API 를 직접 부르지 않습니다.** 서버가 정기적으로 받아서(예: 매주 1회 새벽) DB 에 저장하고, 화면은 DB 만 봅니다
- 개발계정 한도가 API 별로 하루 1만 건입니다. 그래서 **처음에는 서울만** 받아 주세요. 지역은 설정값으로 정합니다. 전국으로 넓히는 건 활용사례를 등록하고 운영계정 한도를 늘린 뒤에 합니다
- 손으로 돌리는 명령도 만들어 주세요 (예: `npm run sync:public -- --sido 서울`). 결과로 새로 생긴 곳, 바뀐 곳, 없어진 곳의 건수를 보여 주세요
- 동기화 기록(언제, 몇 건, 실패)을 저장해 주세요
- **서비스키는 `backend/.env` 에만 넣습니다** (예: `DATA_GO_KR_SERVICE_KEY`). `.env.example` 에는 빈 값만 둡니다. 저장소가 Public 이라 절대 커밋하면 안 됩니다

### 데이터

- 병원에 다음 칸을 추가해 주세요
  - `출처`: 공공데이터 / 직접 등록
  - `ykiho`: 같은 병원이 두 번 들어오지 않게 하는 키
  - `전화번호`
  - `마지막 동기화 시각`
- **`입점 여부`**: 공공데이터로 들어온 병원은 처음에 `미입점` 입니다. 요청서 18 의 가입이 승인되면 `입점` 이 됩니다
  - 지금 있는 샘플 병원 11곳(직접 등록)은 `입점` 으로 둡니다
- 입점 병원이 직접 고친 정보는 동기화가 **덮어쓰지 않습니다.** 입점 병원에게 공공데이터는 참고값입니다. 이름이나 주소가 공공데이터와 다르면 운영자 화면에 표시만 해 주세요
- 공공데이터에서 사라진 병원(폐업 등)은 지우지 말고 `숨김` 으로 둡니다
- 비급여 가격은 병원별로 항목, 금액, 적용 기간, 기준일을 따로 저장합니다
- **비급여 항목 ↔ 세부 시술 연결표**
  - 심평원 항목 코드를 14 의 세부 시술(임플란트, 크라운, 인레이, 레진, 치아미백, 교정 등)에 연결하는 표를 하나 만들어 주세요
  - 연결되지 않는 항목은 병원 상세의 "기타 비급여"에만 보여줍니다
  - 처음에는 어느 항목을 어느 시술에 붙였는지 **제가 검토할 수 있게 목록으로 뽑아 주세요**
- 비급여 가격이 있는 시술은 그 병원이 "하는 시술"로 봅니다. 14 의 `준비중` 판정에도 반영해 주세요. 단, 입점 병원은 병원이 직접 체크한 시술이 우선입니다

### 화면

- **탐색·카테고리·검색**
  - 입점 병원과 미입점 병원이 함께 나옵니다
  - 기본 정렬은 **입점 병원 먼저**입니다. 그 안에서는 지금처럼 광고 우선입니다. 그다음이 미입점 병원(가까운 순)입니다
- **미입점 카드**: `상담 신청` 대신 `전화` 버튼을 둡니다. 회색 `상담 마감` 과는 다른 모양이어야 합니다. 찜은 됩니다
- **병원 상세(미입점)**
  - 보여줄 것: 기본 정보, 진료과목, 전문의 수, 진료시간, **비급여 진료비** 섹션
  - 아래에 안내 두 줄:
    - "건강보험심사평가원 공개 정보예요 (기준일 2026-10-20). 실제와 다를 수 있으니 방문 전 병원에 확인하세요"
    - "이 치과는 아직 몰라몰라 입점 전이라 상담 신청은 받지 않아요"
- **병원 상세(입점)**: 지금 화면에 **비급여 진료비 (심평원 공개)** 섹션을 더합니다. 요청서 19 의 "병원 등록 가격"과는 다른 섹션으로 구분합니다
- **시술 카테고리**: 세부 시술을 고르면 카드에 그 시술의 비급여 금액을 보여줍니다 (예: `임플란트 120만원 · 심평원 공개`)
- **전문의 수**
  - 공공데이터의 전문의 수는 글자로만 보여줍니다 (예: `치과보철과 전문의 1명 · 심평원`)
  - 몰라몰라의 `전문의 인증` 배지는 지금처럼 검수에서 승인된 경우에만 붙습니다
- **병원 전화번호**: **모든 병원 상세에 보여줍니다.** 공개된 정보이고, 08 알림이 "병원에 전화해 주세요" 라고 하기 때문입니다
- **운영자 화면**: 동기화 기록과 **미입점 병원 조회수 상위 목록**(영업용)을 보여줍니다

## 이것만은 지켜주세요 / 건드리지 말아주세요

- 출처 표시를 빠뜨리지 마세요. 공공누리 1유형의 조건입니다. 병원 상세와 가격 옆에 모두 들어가야 합니다
- 미입점 병원에는 상담 신청을 **절대 열지 마세요.** 병원이 모르는 신청이 쌓입니다
- 가격 문구에 "최저가", "할인" 같은 유인 표현을 쓰지 마세요. 가격은 정보로만 보여줍니다 (의료법 27조)
- 샘플 병원 11곳은 개발용으로 남겨 두되, 운영 서버(요청서 21)에는 넣지 않을 수 있게 구분해 주세요
- 동기화하는 동안에도 화면은 지난 데이터로 정상 동작해야 합니다

---

## 확인하고 싶은 것

- 서울로 동기화를 돌리면 운영자 화면에 서울 치과 수(치과병원+치과의원)가 나오고, 탐색에 미입점 치과가 보인다
- 미입점 치과 상세에는 `상담 신청` 버튼이 없고, 전화번호와 출처 안내가 있다
- 비급여 가격이 있는 치과 상세에 항목, 금액, 기준일이 보인다
- 카테고리에서 `임플란트` 를 고르면 카드에 임플란트 비급여 금액이 보인다. 가격이 없는 곳은 표시하지 않는다
- 관리자 화면에서 입점 병원의 이름을 바꾼 뒤 동기화를 다시 돌려도 바꾼 이름이 유지된다
- 서비스키가 커밋 기록 어디에도 없다
