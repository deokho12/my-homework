# 병원 탐색

> 병원 또는 의사를 시술·조건·정렬로 걸러서 목록·지도·가격 비교표로 훑어보고, 마음에 드는 곳에 바로 상담을 신청하는 화면입니다.

| | |
|---|---|
| **주소** | `/explore` (홈의 시술 아이콘으로 들어오면 `?mode=hospital&category=implant` 처럼 조건이 붙습니다) |
| **누가 보나요** | 누구나 (상담 신청만 로그인 필요) |
| **어디서 들어오나요** | 아래 탭바의 `병원`, 넓은 화면(PC)의 위쪽 메뉴 `병원`, 홈의 `시술로 찾기` 아이콘과 `전체보기`, 검색 화면에서 시술 이름을 검색했을 때 |
| **소스 파일** | `frontend/src/screens/tabs/explore.tsx` (필터·정렬) + `frontend/src/features/hospital/components/HospitalExploreCard.tsx` (병원 카드) + `frontend/src/components/DoctorCard.tsx` (의사 카드) + `frontend/src/features/hospital/components/HospitalMapView.tsx` (지도) + `frontend/src/features/hospital/components/PriceCompareTable.tsx` (가격 비교표) |

## 여기서 할 수 있는 일

상태 표시: ✅ 실제로 동작함 · 🟡 화면은 되지만 데이터가 샘플 · 🚧 아직 아무 일도 안 일어남 · 🔒 로그인 필요

| 할 수 있는 일 | 상태 | 지금 어떻게 동작하나요 |
|---|---|---|
| `의사` / `병원` 모드 바꾸기 | ✅ | 맨 위 알약 모양 스위치. 아래 목록이 병원 카드 ↔ 의사 카드로 통째로 바뀝니다. 선택해둔 시술·정렬·조건 필터는 그대로 유지되고 새 모드에 다시 적용됩니다. 처음 열면 `병원` 쪽이 선택돼 있습니다 |
| `리스트 보기` / `지도 보기` 바꾸기 | 🟡 | `병원` 모드에서만 이 버튼이 보입니다. 지도로 바꾸면 목록 대신 지도가 나옵니다 (아래 "지도" 항목 참고) |
| 시술로 걸러내기 | ✅ | 시술 칩 15개 중 하나만 선택됩니다 (여러 개 동시 선택은 안 됩니다). 목록이 그 시술을 하는 병원/의사만으로 줄어듭니다 |
| 정렬 바꾸기 | ✅ | `인기순` / `후기순` / `상담많은순` 중 하나. 실제로 순서가 바뀝니다 |
| 조건으로 걸러내기 | ✅ | `상담가능` `원데이` `전문의` `진료시간` `경력` 5개. **여러 개를 동시에 켤 수 있고**, 켠 조건을 모두 만족하는 곳만 남습니다. 다시 누르면 꺼집니다 |
| 결과 개수 확인 | ✅ | 목록 위에 `총 11곳` 또는 `총 14명` 처럼 지금 조건에 맞는 개수가 표시됩니다 |
| `가격 비교표 보기` / `카드로 보기` | 🟡 | `병원` 모드 + `리스트 보기` 에서만 나오는 글자 버튼. 카드 목록을 표로 바꿔서 최저가 순으로 비교할 수 있습니다 |
| 병원 카드 누르기 | 🟡 | 병원 상세 화면으로 이동합니다 |
| 의사 카드 누르기 | 🟡 | 전문의 상세 화면으로 이동합니다 |
| 카드의 `상담신청` 누르기 | ✅ 🔒 | 상담 신청 화면으로 이동합니다. 로그인하지 않았으면 로그인 화면으로 보내고, 로그인 후 상담 신청 화면으로 돌아옵니다. 상담을 받지 않는 병원은 버튼이 회색 `상담 마감`으로 바뀌고 눌리지 않습니다 |
| 지도에서 병원 찾기 | 🚧 🟡 | 지도 자체가 **지금은 화면에 나오지 않습니다.** 카카오맵 열쇠(API 키)가 설정되지 않아 `카카오맵 API 키가 설정되지 않았어요` 문구만 보입니다. 반경 버튼은 눌리지만 지도가 없어 결과를 확인할 수 없습니다 |
| 지도 반경 바꾸기 | 🟡 | `500m` `1km` `3km` `5km`. 기본은 `3km`. 지도가 보이게 되면 반경 안의 병원만 마커로 표시됩니다 |
| 결과 없음 확인 | ✅ | 조건이 너무 좁으면 `조건에 맞는 병원이 없어요` / `조건에 맞는 의사가 없어요` 가 표시됩니다 |
| 병원 찜하기 | 🚧 | **이 화면의 카드에는 하트(찜하기)가 없습니다.** 찜은 병원 상세 화면이나 마이페이지 찜 목록에서만 할 수 있습니다 |

## 필터·정렬 전체 목록

**이 목록에 없는 조건은 아직 만들어지지 않은 것입니다.**

### 1) 모드 (하나만 선택, 기본 `병원`)

| 버튼 | 결과 |
|---|---|
| `의사` | 의사 카드 목록 |
| `병원` | 병원 카드 목록 (+ `리스트 보기` / `지도 보기` / `가격 비교표 보기` 사용 가능) |

### 2) 보기 방식 (`병원` 모드에서만, 기본 `리스트 보기`)

| 버튼 | 결과 |
|---|---|
| `리스트 보기` | 병원 카드가 세로로 (넓은 화면에서는 2열로) 나열 |
| `지도 보기` | 지도 + 반경 버튼 |

### 3) 시술 칩 — 총 15개 (하나만 선택)

순서대로: `추천` · `임플란트` · `교정` · `라미네이트` · `인레이` · `크라운` · `치아미백` · `사랑니` · `충치치료` · `잇몸치료` · `스플린트` · `코골이장치` · `턱관절` · `보톡스` · `기타`

- `추천` — 운영자가 추천으로 표시한 병원/의사만
- 시술 이름 13개 — 그 시술을 한다고 등록된 병원/의사만
- `기타` — **아무 시술도 걸러내지 않는 "전체"** 입니다. 이름만 `기타`이고 동작은 전체 보기입니다
- 처음 이 화면을 열면 `기타`(= 전체)가 선택된 상태입니다

### 4) 정렬 — 총 3개 (하나만 선택, 기본 `인기순`)

| 칩 | 실제 기준 |
|---|---|
| `인기순` | **평점이 높은 순** |
| `후기순` | 후기 수가 많은 순 |
| `상담많은순` | 상담 신청 수가 많은 순 |

### 5) 조건 칩 — 총 5개 (여러 개 동시 선택 가능, 기본 전부 꺼짐)

| 칩 | `병원` 모드에서 남는 것 | `의사` 모드에서 남는 것 |
|---|---|---|
| `상담가능` | 지금 상담을 받는 병원 | 소속 병원이 지금 상담을 받는 의사 |
| `원데이` | 하루에 끝나는 진료가 가능한 병원 | 소속 병원이 원데이 가능한 의사 |
| `전문의` | 인증 완료된 전문의가 한 명 이상 있는 병원 | 본인이 인증 완료된 전문의인 경우 |
| `진료시간` | **야간 상담이 가능한 병원** | 소속 병원이 야간 상담 가능한 의사 |
| `경력` | **경력 10년 이상** 의사가 한 명 이상 있는 병원 | 본인 경력이 10년 이상인 의사 |

- `전문의` 는 관리자 화면에서 전문의 인증을 **승인받은** 경우만 해당합니다. 심사 대기·반려 상태나 `일반의` 는 걸러집니다.
- **`치아고민` 같은 별도 필터는 의도적으로 만들지 않았습니다.** 위의 시술 칩이 같은 역할을 하기 때문입니다.
- 지역·가격대·거리 필터는 **없습니다.** (지도 화면의 반경 버튼만 거리 개념을 씁니다)

## 화면에 보이는 정보

위에서 아래 순서대로입니다.

- **제목** — `병원 탐색`
- **모드 스위치** — `의사` / `병원`
- **보기 방식 버튼** — `리스트 보기` / `지도 보기` (`병원` 모드에서만)
- **시술 칩 줄** — 아이콘 + 이름, 좌우 스크롤
- **정렬 칩 줄** — 좌우 스크롤
- **조건 칩 줄** — 좌우 스크롤
- **결과 머리글** — `"임플란트" 병원` 처럼 선택한 시술 이름 + 모드, 그 아래 `총 N곳` / `총 N명`, 오른쪽에 `가격 비교표 보기`
- **병원 카드** — 병원 사진(원데이 가능하면 사진 위에 `⚡ 원데이 가능`), 병원 이름, 전문 분야, 지역, 배지(`광고` / `🌟 추천` / `OO전문의 상주` / 시술 이름 최대 3개), `후기 N` `상담 N` `★ 4.8`, 아래에 `상담신청` 버튼
- **의사 카드** — 동그란 프로필 사진, `이름 + 직함`, 전문 과목, 소속 병원 이름, 배지(`🌟 추천` / `전문의` / 시술 이름 최대 3개), `후기 N` `상담 N` `★ 4.8`, 아래에 `상담신청` 버튼
- **가격 비교표** — `병원` / `최저가` / `평점` 3칸. 최저가가 싼 순서로 정렬되고, 이벤트 할인가가 있는 병원은 할인가와 함께 빨간 `할인가` 표시가 붙습니다. 행을 누르면 병원 상세로 이동합니다
- **지도** — 위쪽에 반경 버튼 `500m` `1km` `3km` `5km`, 아래에 지도. 마커를 누르면 화면 아래에 작은 병원 카드(병원 이름, `시술 · 거리 · 후기 수`, `상담신청` 버튼)가 뜹니다

### 결과가 없거나 지도를 못 띄울 때

| 상황 | 화면 |
|---|---|
| 조건에 맞는 곳이 없음 | `조건에 맞는 병원이 없어요` / `조건에 맞는 의사가 없어요` |
| 지도 열쇠(API 키)가 없음 | 지도 자리에 `카카오맵 API 키가 설정되지 않았어요` |
| 위치 권한을 안 줬거나 확인 실패 | 반경 버튼 위에 `위치 권한을 확인할 수 없어 서울시청을 기준으로 보여드려요` |
| 반경 안에 병원이 없음 | 지도 위에 `반경 3km 안에 병원이 없어요` |

## 알아두실 것

- **병원 11곳, 의사 14명은 모두 샘플입니다.** 실제 병원이 아니고 서버도 아직 연결되지 않았습니다. 데이터는 브라우저에 저장되므로 다른 컴퓨터에서는 다르게 보일 수 있습니다.
- **`지도 보기` 는 지금 지도가 안 나옵니다.** 카카오맵 열쇠(API 키)가 아직 설정되지 않아서 `카카오맵 API 키가 설정되지 않았어요` 문구만 보입니다. 고장이 아니라 준비가 안 된 상태입니다.
- **`진료시간` 칩은 이름과 동작이 다릅니다.** 실제로는 "야간 상담이 가능한 병원"만 남기는 필터입니다. 진료시간을 시간대로 지정해서 찾는 기능은 아직 없습니다.
- **`기타` 칩은 "그 밖의 시술"이 아니라 "전체"입니다.** 그래서 이 화면을 처음 열면 결과 머리글이 `"기타" 병원` 으로 보이면서 모든 병원이 나옵니다. 표현이 어색하지만 목록 자체는 정상입니다.
- **`인기순` 은 평점 순입니다.** 조회수나 클릭수 같은 별도의 인기 지표는 아직 없습니다.
- **필터·정렬·모드 선택은 저장되지 않습니다.** 다른 탭에 갔다가 돌아오거나 새로고침하면 `병원` + `기타` + `인기순` + 조건 전부 꺼짐 상태로 초기화됩니다.
- **광고 병원은 목록 맨 위로 올라갑니다.** 광고 기간 중이고 평점이 3.5 이상인 병원만 위로 올라가며, 카드에 `광고` 배지가 붙습니다. 평점이 3.5 미만이면 `광고` 배지는 붙지만 맨 위로 올라가지는 않습니다. `기타`(전체)를 선택했을 때는 광고 우선 노출이 적용되지 않습니다.
- **샘플 광고 기간은 2026년 7~9월로 고정돼 있습니다.** 그 기간이 지나면 `광고` 배지가 저절로 사라지는데, 이것도 고장이 아닙니다.
- **이 화면 카드에는 하트(찜하기)가 없습니다.** 찜은 병원 상세 화면에서 하고, 찜 목록은 마이페이지에서 봅니다.
- **의사 카드의 `상담신청` 은 그 의사가 아니라 그 의사가 소속된 "병원" 상담 신청으로 연결됩니다.** 특정 전문의를 지정해서 신청하는 것은 아닙니다.
- **상담을 신청해도 실제로 병원에 연락이 가지는 않습니다.** 신청 내용은 저장되고 관리자 화면의 상담 목록에 나타납니다.
- **`OO전문의 상주` 배지는 그 병원의 인증된 전문의 중 첫 번째 사람 기준입니다.** 선택한 시술과 전공이 맞으면 배지 색이 초록으로 강조됩니다.
- **가격 비교표의 `최저가` 는 병원이 등록한 가격대의 최저 금액이거나, 이벤트가 있으면 그 할인가입니다.** 선택한 시술의 가격이 아니므로 시술을 바꿔도 금액은 그대로입니다.
- 넓은 화면(768px 이상)에서는 카드가 2열로 배치됩니다.

## 이 화면을 바꾸고 싶을 때

`docs/features/requests/_TEMPLATE.md` 를 복사해서 `docs/features/requests/` 에 요청서를 만들거나,
채팅창에 `/feature-request` 를 입력하세요.

이 화면에서 손대면 함께 확인해야 하는 것:

- **시술 칩 15개 중 13개는 홈의 `시술로 찾기` 격자, 커뮤니티 질문하기의 시술 선택과 같은 목록**입니다. 시술을 추가·삭제·이름 변경하면 세 화면이 모두 바뀝니다.
- **`전문의` 필터와 `전문의` / `OO전문의 상주` 배지**는 관리자의 전문의 인증 검수 결과를 그대로 씁니다. 관리자에서 승인/반려를 바꾸면 이 화면 결과도 바로 달라집니다.
- **병원 정보(상담 가능 여부, 원데이, 야간상담, 추천, 광고 기간, 가격대)** 는 관리자 화면에서 수정됩니다. 필터 결과가 이상하면 관리자에서 바뀐 값일 수 있습니다.
- **병원 카드**는 홈·검색·마이페이지의 병원 카드와 같은 병원 데이터를 씁니다. 한쪽만 바꾸면 어긋납니다.
- **`상담신청` 버튼**은 상담 신청 화면으로만 연결됩니다. 실제 저장은 그 화면에서 일어납니다.
- **지도**를 실제로 띄우려면 카카오맵 API 키가 필요합니다 (`frontend/.env` 에 `VITE_KAKAO_MAP_JS_KEY`).
