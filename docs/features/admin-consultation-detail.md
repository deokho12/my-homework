# 관리자 — 상담 예약 (상세)

> 상담 한 건의 신청 내용을 보고, **전화를 걸고**, 상태와 확정 방문 일시를 바꾸고,
> 내부 공유용 메모를 남기는 자리입니다. 목록과 **같은 화면**이고 넓은 화면에서는 오른쪽 칸입니다.

| | |
|---|---|
| **주소** | `/admin/consultations/:id` (예: `/admin/consultations/cr1`) |
| **누가 보나요** | 담당 병원의 `hospital_admin` 은 전부, `operator` 는 **가려진 값만 보기만** 합니다 |
| **어디서 들어오나요** | 상담 예약 목록의 카드, 관리자 알림함의 `새로운 상담 신청` 알림 |
| **소스 파일** | `frontend/src/features/consult/components/AdminConsultDetail.tsx` (상태 폼 `AdminConsultStatusForm.tsx`, 메모 `AdminConsultMemos.tsx`, 이력 `AdminConsultHistory.tsx`, 화면 `frontend/src/pages/admin/AdminConsultationsPage.tsx`) |

## 여기서 할 수 있는 일

상태 표시: ✅ 실제로 동작함 · 🟡 화면은 되지만 데이터가 샘플 · 🚧 아직 아무 일도 안 일어남 · 🔒 로그인 필요

| 할 수 있는 일 | 상태 | 지금 어떻게 동작하나요 |
|---|---|---|
| 신청 내용 확인 | ✅ 🔒 | 이름 · 상태 · 신청 시각 · 연락처 · 병원 · 시술 · 희망 시간 · (있으면) 확정 방문 · 환자가 남긴 말. **서버에 저장된 실제 신청입니다** (2026-10-22) |
| 전화 걸기 | ✅ 🔒 | **담당 병원 관리자에게만** `전화 걸기` 버튼이 보입니다. 누르면 기기의 전화 앱이 열립니다(`tel:` 링크) |
| 상태 바꾸기 | ✅ 🔒 | 5개(`신규` `연락중` `예약확정` `내원완료` `취소`) 중 하나를 **고르고 `저장`** 을 눌러야 바뀝니다. 어느 상태에서 어느 상태로든 갈 수 있습니다 |
| 확정 방문 일시 넣기 | ✅ 🔒 | `예약확정` 을 고르면 `확정 날짜 (필수)` · `시간 (필수)` 칸이 열립니다. **둘 다 채워야 저장됩니다** |
| 일시만 바꾸기 | ✅ 🔒 | 이미 `예약확정` 이면 `일시 변경` 버튼. 현재 값이 채워져 나오고, **그대로면 저장할 수 없습니다** |
| 취소 사유 남기기 | ✅ 🔒 | `취소` 를 고르면 사유 선택이 필수입니다 — `연락이 안 됨` / `환자 요청` / `진료 불가 시술` / `중복 신청` / `기타` |
| 메모 남기기 | ✅ 🔒 | 담당 병원 관리자만 씁니다. 저장되면 목록 맨 위에 나타나고 입력칸이 비워집니다 |
| 처리 이력 보기 | ✅ 🔒 | 누가·언제·무엇으로 바꿨는지 + 환자 알림 발송 여부가 최신순으로 쌓입니다 |
| 메모 수정 · 삭제 | 🚧 | 없습니다. 한 번 추가한 메모는 고치거나 지울 수 없습니다 |
| 문자 보내기 · 답장 | 🚧 | 없습니다 |
| 유입 경로 | 🚧 | 수집하지 않습니다 (목록 문서 참고) |
| 상담 삭제하기 | 🚧 | 없습니다 |

## 화면에 보이는 정보

- **머리** — `10/7 11:30 신청` · 환자 이름(크게) · 상태 칩 · (해당되면) `지연` + `24시간 넘게 신규 상태예요. 먼저 연락해 주세요.`
- **연락처 상자** — 번호와 `전화 걸기`. 가려진 응답이면 버튼 대신 `연락처 전체와 전화 걸기는 담당 병원 관리자만 볼 수 있어요.`
- **정보** — `병원` / `시술` / `희망 시간`(없으면 `미지정`) / `확정 방문`(있을 때만, 굵게)
- **`환자가 남긴 말`** — 없으면 `남긴 메시지가 없어요`
- **`상태 바꾸기`** — `바꾸면 환자에게 알림이 가요` + 상태 버튼 5개. 현재 상태는 연한 색, 내가 고른 것은 채워진 색입니다
  - 이미 `예약확정` 이면 위에 `10/9(목) 14:00 방문` 상자와 `일시 변경` 버튼 (일시가 없는 옛 건은 `일시 미입력`)
  - 저장 버튼 문구가 결과를 말합니다: `신규로 저장` · `연락중으로 저장` · `예약 확정하기` · `일시 변경 저장` · `내원완료로 저장` · `취소로 저장`. 옆의 `되돌리기` 는 고른 것을 버립니다
- **`메모`** — `병원 안에서만 보여요. 환자에게는 보이지 않아요.` + 메모 목록(최신순) + 입력칸 + `메모 추가`
- **`처리 이력`** — 예: `10/7 11:30 앱에서 상담 신청` · `10/7 13:00 예약확정 10/9(목) 14:00 · 김실장 · 환자 알림 발송` · `10/8 09:10 일시 변경 10/10(토) 11:00 · 김실장 · 환자 알림 발송` · `10/7 09:00 취소 · 연락이 안 됨 · 김실장 · 환자 알림 발송`

### 저장이 막히는 경우와 그때 보이는 말

| 상황 | 화면 |
|---|---|
| `예약확정` 인데 날짜·시간 중 하나라도 빔 | 저장 버튼이 눌리지 않고 `날짜와 시간을 모두 넣어야 저장할 수 있어요` |
| 지난 날짜를 넣고 저장 | `지난 날짜는 고를 수 없어요` (달력도 오늘 이전은 고를 수 없습니다) |
| `일시 변경` 인데 값이 그대로 | `일시가 그대로예요` |
| `취소` 인데 사유를 안 고름 | 저장 버튼이 눌리지 않고 아래에 `취소 사유를 골라야 저장할 수 있어요` 가 보입니다 |
| 저장이 실패 | 입력칸 아래에 빨간 줄로 이유가 뜹니다. **고른 값은 그대로 남습니다** |
| 현재 상태와 같은 것을 다시 고름 | 아무것도 열리지 않습니다 (같은 상태로 알림이 또 나가지 않게). `예약확정` 만 예외이고 그것은 "일시 변경" 입니다 |
| 저장하지 않은 선택을 두고 다른 상담을 염 | `저장하지 않은 내용이 있어요 / 저장하지 않고 다른 상담을 열까요?` |

## 상태를 바꾸면 실제로 무슨 일이 일어나나요

- 맨 위에 `예약확정으로 저장했어요. 환자에게 알림이 갔어요.` (일시 변경이면 `일시를 10/10(토) 11:00으로 바꿨어요. …`) 가 뜨고 **읽는 자리로 포커스가 옮겨 갑니다**.
- `처리 이력` 에 한 줄이 쌓입니다 — 상태 변경은 바뀐 상태, 일시 변경은 `일시 변경`.
- 환자 알림함에 알림 한 건이 생깁니다 — `상담 상태 변경` / `상담 상태가 '예약확정'(으)로 변경되었어요`,
  일시만 바꾸면 `예약 일시 변경` / `예약 일시가 '10월 10일(토) 11:00'(으)로 변경되었어요`.
- 환자의 마이페이지 상담 내역에 **같은 확정 일시**가 보입니다 (`10/9(목) 14:00 방문`).
- 목록 카드·상태 탭 숫자·관리자 홈의 `처리 대기 중인 상담` 이 함께 달라집니다.
- **고객에게 문자·전화·이메일이 실제로 가지는 않습니다.** 앱 안의 알림함에만 기록됩니다.
- **같은 값으로 다시 저장하면 아무 일도 일어나지 않습니다** — 이력도 알림도 늘지 않습니다.

### 확정 일시가 사라지는 경우

| 바꾼 상태 | 확정 일시 |
|---|---|
| `예약확정` | 새로 넣은 값 (안 넣으면 원래 값) |
| `내원완료` | **그대로 둡니다** — "언제 오기로 했던 건인가" 는 내원 기록의 일부입니다 |
| `취소` · `연락중` · `신규` | **지웁니다** — 취소된 건에 방문 예정이 남으면 환자 화면에서 거짓말이 됩니다. 그 약속이 있었다는 사실은 처리 이력에 남습니다 |

## 알아두실 것

- **전체 번호는 담당 병원 관리자의 이 화면에만 있습니다.** 목록은 담당자에게도 가립니다. 운영자는 여기서도 `박*영` · `010-****-4411` 만 봅니다.
- **취소 사유는 환자에게 보이지 않습니다.** 병원 내부 분류이고, `연락이 안 됨` 은 환자에게 비난으로 읽힙니다.
- **`기타` 에 설명 칸이 없습니다.** 자세한 사정은 메모에 적습니다.
- **확정 일시가 없는 `예약확정` 건은 `일시 미입력` 으로 보입니다.** 담당자가 `일시 변경` 으로 채우면 됩니다 (지금 `예약확정` 으로 저장하려면 일시가 반드시 필요합니다).
- **메모는 "내부 공유용"입니다.** 담당 병원 관리자만 쓰고 읽으며, 환자에게는 내려가지 않습니다. 다만 메모에 연락처를 적으면 마스킹이 무의미해지니 적지 말아 주세요.
- **메모에 작성자 표시가 없습니다.** 처리 이력에는 이름이 남지만 메모 줄에는 아직 보여주지 않습니다 (서버에는 누가 썼는지 적혀 있습니다).
- **이 화면을 열 때마다 열람 기록이 남습니다** (2026-10-22). 전체 연락처가 보이는 유일한 자리라, 누가 언제 열었는지가 서버에 기록됩니다 (`docs/decisions/0001-roles-and-pii.md`). 그 기록을 보는 화면은 아직 없습니다.
- 시각은 모두 **한국 시간(Asia/Seoul)** 기준입니다.
