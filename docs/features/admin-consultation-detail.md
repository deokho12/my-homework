# 상담 상세

> 상담 한 건의 신청 내용을 자세히 보고, 상태를 바꾸고, 내부 공유용 메모를 남기는 화면입니다.

| | |
|---|---|
| **주소** | `/admin/consultations/:id` (예: `/admin/consultations/cr1`) |
| **누가 보나요** | 병원 관리자용 화면입니다. 다만 **지금은 로그인 검사가 없어서 주소만 알면 누구나 고객 실명·전화번호와 메모를 볼 수 있습니다** |
| **어디서 들어오나요** | 상담 관리 목록(`/admin/consultations`)의 상담 카드, 관리자 알림함에서 `새로운 상담 신청` 알림을 눌렀을 때 |
| **소스 파일** | `frontend/src/screens/admin/consultations/[id].tsx` |

---

## 여기서 할 수 있는 일

상태 표시: ✅ 실제로 동작함 · 🟡 화면은 되지만 데이터가 샘플 · 🚧 아직 아무 일도 안 일어남 · 🔒 로그인 필요

| 할 수 있는 일 | 상태 | 지금 어떻게 동작하나요 |
|---|---|---|
| 신청 내용 확인 | 🟡 | 병원명·이름·연락처·희망 시술·희망 시간·신청일시가 한 카드에 표시됩니다. 샘플 상담입니다 |
| 문의 메시지 읽기 | 🟡 | 고객이 남긴 글. 없으면 `남긴 메시지가 없어요` |
| 상태 바꾸기 | ✅ | `상태 변경` 칩 4개(`신규` `연락중` `예약완료` `취소`) 중 하나를 누르면 즉시 바뀝니다. 확인창은 없습니다 |
| 상태 변경 이력 보기 | ✅ | 바뀐 상태와 시각이 **최신순**으로 쌓입니다. 없으면 `아직 상태 변경 이력이 없어요` |
| 메모 남기기 | ✅ | 아래 입력칸에 쓰고 `메모 추가`. 저장되고 목록 맨 위에 나타나며, 다시 들어와도 남아 있습니다 |
| 메모 목록 보기 | ✅ | 내용과 작성 시각이 **최신순**으로 표시됩니다. 없으면 `아직 작성된 메모가 없어요` |
| 메모 수정 · 삭제 | 🚧 | **없습니다.** 한 번 추가한 메모는 고치거나 지울 수 없습니다 |
| 전화 걸기 · 문자 보내기 · 답장 | 🚧 | 연락처는 **글자로만** 표시됩니다. 눌러도 전화가 걸리지 않고, 고객에게 답을 보내는 기능도 없습니다 |
| 상담 삭제하기 | 🚧 | **없습니다** |
| 예약 날짜·시간 지정 | 🚧 | **없습니다.** `예약완료` 상태로만 표시할 수 있고, 실제 예약 일시를 넣는 칸은 없습니다 (필요하면 메모에 적는 식으로 씁니다) |

## 화면에 보이는 정보

- **신청 정보 카드** — 맨 위에 병원 이름(찾지 못하면 `알 수 없는 병원`), 그 아래 항목이 한 줄씩

  | 줄 이름 | 값 | 비어 있을 때 |
  |---|---|---|
  | `이름` | 고객 실명 | — |
  | `연락처` | 전화번호 | — |
  | `희망 시술` | 예: `임플란트` | `미지정` |
  | `희망 시간` | 예: `평일 오전` | `미지정` |
  | `신청일시` | 예: `2026. 7. 28. 오후 6:15` (보고 있는 컴퓨터 시간대 기준) | — |

- **`문의 메시지`** — 고객이 남긴 글. 없으면 `남긴 메시지가 없어요`
- **`상태 변경`** — 칩 4개. 현재 상태만 색이 채워집니다
- **`상태 변경 이력`** — 왼쪽에 상태 이름, 오른쪽에 바뀐 시각. 최신순
- **`메모`** — 회색 상자 안에 메모 내용과 작성 시각. 최신순. 그 아래 여러 줄 입력칸(`내부 공유용 메모를 남겨보세요`)과 `메모 추가` 버튼 (입력칸이 비어 있으면 버튼이 흐리게 표시되고 눌리지 않습니다)
- **없는 상담 주소로 들어왔을 때** — `상담 정보를 찾을 수 없어요` 만 보입니다

## 상태를 바꾸면 실제로 무슨 일이 일어나나요

- 이 화면과 상담 목록의 상태 표시가 즉시 바뀝니다.
- `상태 변경 이력` 맨 위에 한 줄이 추가됩니다.
- 고객(사용자) 알림함에 알림 한 건이 생깁니다 — `상담 상태 변경` / `상담 상태가 '예약완료'(으)로 변경되었어요` 형태. **관리자 알림함에는 나오지 않습니다.**
- 관리자 홈의 `처리 대기 중인 상담` 숫자도 함께 달라집니다.
- **고객에게 문자·전화·이메일이 실제로 가지는 않습니다.** 앱 안의 알림함에만 기록됩니다.

## 알아두실 것

- **⚠️ 지금 관리자 화면에는 로그인 검사가 전혀 없습니다.** `/admin/consultations/cr1` 처럼 주소만 알면 로그인하지 않은 누구나 들어와서 **고객의 실명·전화번호·문의 내용과 내부 메모까지 볼 수 있고**, 상태를 바꾸고 메모도 남길 수 있습니다. 이미 확인된 문제이고 리팩터링 계획 **8단계**에서 막을 예정입니다. 그때까지 **이 화면 주소를 절대 외부에 공유하지 마세요.**
- **메모는 "내부 공유용"이지만 실제로는 보호되고 있지 않습니다.** 위 경고와 같은 이유로, 주소를 아는 사람은 누구나 읽을 수 있습니다.
- **메모는 지울 수 없습니다.** 잘못 적어도 되돌릴 방법이 없으니 신중하게 적어주세요.
- **메모에 작성자 표시가 없습니다.** 누가 남긴 메모인지 화면에서 알 수 없습니다.
- **같은 상태를 한 번 더 눌러도 처리됩니다.** 이력에 한 줄이 또 추가되고 고객 알림도 한 건 더 생깁니다.
- **상태 변경에 확인창이 없습니다.**
- **`예약완료` 로 바꿔도 예약 날짜·시간이 저장되지는 않습니다.** 실제 일정은 메모에 적어야 합니다.
- **`상태 변경 이력` 에는 누가 바꿨는지 남지 않습니다.** 상태와 시각만 기록됩니다.
- 시각은 **보고 있는 컴퓨터의 시간대**로 표시됩니다.
- 데이터는 서버가 아니라 **보고 있는 브라우저에 저장**됩니다. 다른 컴퓨터에서는 메모와 이력이 보이지 않습니다.

## 이 화면을 바꾸고 싶을 때

`docs/features/requests/_TEMPLATE.md` 를 복사해서 `docs/features/requests/` 에 요청서를 만들거나,
채팅창에 `/feature-request` 를 입력하세요.

이 화면에서 손대면 함께 확인해야 하는 것:

- **상담 관리 목록**과 같은 데이터를 씁니다. 상태 칩이 두 화면에 모두 있으니 한쪽만 바꾸면 어긋납니다. (`docs/features/admin-consultations.md`)
- 상태를 바꾸면 **사용자 알림함**에 알림이 생깁니다.
- **관리자 알림함**에서 `새로운 상담 신청` 알림을 누르면 이 화면으로 들어옵니다. (`docs/features/admin-notifications.md`)
- **관리자 홈**의 숫자 카드가 같은 상담 데이터를 셉니다. (`docs/features/admin-home.md`)
