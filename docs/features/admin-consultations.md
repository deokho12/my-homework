# 상담 관리 (상담 목록)

> 고객이 신청한 상담을 한 목록에서 보고, 상태별로 걸러 보거나 카드에서 바로 상태를 바꾸는 화면입니다.

| | |
|---|---|
| **주소** | `/admin/consultations` |
| **누가 보나요** | 병원 관리자용 화면입니다. 다만 **지금은 로그인 검사가 없어서 주소만 알면 누구나 고객 실명과 전화번호를 볼 수 있습니다** |
| **어디서 들어오나요** | 병원 관리자 홈(`/admin`)의 `상담 관리` 버튼 |
| **소스 파일** | `frontend/src/screens/admin/consultations/index.tsx` |

상태 표시: ✅ 실제로 동작함 · 🟡 화면은 되지만 데이터가 샘플 · 🚧 아직 아무 일도 안 일어남 · 🔒 로그인 필요

| 할 수 있는 일 | 상태 | 지금 어떻게 동작하나요 |
|---|---|---|
| 접수된 상담 목록 보기 | 🟡 | 신청일시 **최신순**으로 고정 정렬됩니다. 샘플 상담 7건이 들어 있습니다 |
| 상태별로 걸러 보기 | ✅ | 위쪽 칩 `전체` `신규` `연락중` `예약완료` `취소`. 누르면 목록이 실제로 바뀝니다 |
| 상담 상세 보기 | ✅ | 카드를 누르면 상담 상세 화면으로 이동 |
| 카드에서 바로 상태 바꾸기 | ✅ | 카드 아래 작은 버튼 4개(`신규` `연락중` `예약완료` `취소`) 중 하나를 누르면 **화면을 옮기지 않고** 그 자리에서 상태가 바뀝니다. 확인창은 없습니다 |
| 고객 연락처 확인 | ✅ | 카드에 `연락처 010-1234-5601` 형태로 그대로 표시됩니다 |
| 이름·연락처로 검색 | 🚧 | **없습니다** |
| 병원별로 걸러 보기 | 🚧 | **없습니다.** 모든 병원의 상담이 한 목록에 섞여 나옵니다 |
| 기간(날짜)으로 걸러 보기 | 🚧 | **없습니다** |
| 전화 걸기 · 문자 보내기 | 🚧 | 연락처는 **글자로만** 표시됩니다. 눌러도 전화가 걸리지 않습니다 |
| 상담 삭제하기 | 🚧 | **없습니다** |
| 엑셀 등으로 내려받기 | 🚧 | **없습니다** |

## 화면에 보이는 정보

- **제목 영역** — `상담 관리` + 설명 문구 `접수된 상담 신청을 확인하고 상태를 관리해요`
- **상태 필터 칩** — `전체` `신규` `연락중` `예약완료` `취소` (선택한 칩만 색이 채워집니다)
- **상담 카드** (한 건당 하나)
  - 고객 **이름** (가장 크게)
  - `병원명 · 시술명`. 시술을 고르지 않고 신청한 건은 `시술 미지정`, 병원을 찾지 못하면 `알 수 없는 병원`
  - 오른쪽 배지 — 현재 상태. **`예약완료` 만 색이 있는 배지**이고 나머지는 회색입니다
  - `신청일시 2026. 7. 28. 오후 6:15` 형태 (보고 있는 컴퓨터의 시간대 기준)
  - `연락처 010-1234-5601`
  - 아래 빠른 상태 변경 버튼 4개. 현재 상태인 것만 색이 채워집니다
- **목록이 비었을 때**
  | 상황 | 화면 |
  |---|---|
  | `전체` 인데 상담이 없음 | `📭` + `접수된 상담 신청이 없어요` |
  | 필터를 걸었는데 해당 상태가 없음 | `📭` + `해당 상태의 상담 신청이 없어요` |

## 상태를 바꾸면 실제로 무슨 일이 일어나나요

- 목록과 상담 상세 화면의 상태가 즉시 바뀝니다.
- 상담 상세 화면의 **`상태 변경 이력`** 에 바뀐 시각과 함께 한 줄이 추가됩니다.
- 고객(사용자) 알림함에 알림 한 건이 생깁니다 — 제목 `상담 상태 변경`, 내용 `상담 상태가 '예약완료'(으)로 변경되었어요` 형태. **이 알림은 사용자 알림함(`/notifications`)에 쌓이고, 관리자 알림함에는 나오지 않습니다.**
- 관리자 홈의 `처리 대기 중인 상담` 숫자(상태가 `신규` 인 건수)도 함께 달라집니다.
- **고객에게 문자·전화·이메일이 실제로 가지는 않습니다.** 앱 안의 알림함에만 기록됩니다.

## 알아두실 것

- **⚠️ 지금 관리자 화면에는 로그인 검사가 전혀 없습니다.** `/admin/consultations` 주소만 알면 로그인하지 않은 누구나 들어와서 **고객의 실명과 전화번호가 적힌 목록 전체를 볼 수 있고**, 상담 상태도 바꿀 수 있습니다. 이 화면은 개인정보가 그대로 노출되는 자리라 특히 위험합니다. 이미 확인된 문제이고 리팩터링 계획 **8단계**에서 막을 예정입니다. 그때까지 **이 화면 주소를 절대 외부에 공유하지 마세요.**
- **모든 병원의 상담이 한 목록에 나옵니다.** 병원별로 나뉘어 있지 않아서, 내 병원 상담만 보는 방법이 없습니다.
- **이미 선택된 상태를 한 번 더 눌러도 처리됩니다.** 같은 상태로 바꿔도 이력에 한 줄이 또 추가되고 고객 알림도 한 건 더 생깁니다. 실수로 두 번 누르지 않도록 주의하세요.
- **상태 변경에 확인창이 없습니다.** 카드 아래 버튼을 스크롤 중에 잘못 눌러도 바로 반영됩니다.
- **상담 신청 내용은 실제로 병원에 연락이 가서 생긴 게 아닙니다.** 사용자가 상담 신청 화면에서 넣은 내용이 저장돼서 여기 나타나는 것입니다.
- **샘플 상담 7건이 미리 들어 있습니다.** 실제 고객이 아닙니다 (`김민준` `박서준` `최지훈` `정하윤` `강도윤` `이서연` `한소율`).
- **신청일시는 보고 있는 컴퓨터의 시간대로 표시됩니다.** 컴퓨터 시간대가 다르면 시각이 다르게 보일 수 있습니다.
- 정렬은 **최신순 고정**입니다. 오래된 순으로 보거나 상태순으로 정렬하는 기능이 없습니다.
- 데이터는 서버가 아니라 **보고 있는 브라우저에 저장**됩니다. 다른 컴퓨터에서는 다른 목록이 보입니다.

## 이 화면을 바꾸고 싶을 때

`docs/features/requests/_TEMPLATE.md` 를 복사해서 `docs/features/requests/` 에 요청서를 만들거나,
채팅창에 `/feature-request` 를 입력하세요.

이 화면에서 손대면 함께 확인해야 하는 것:

- 목록에 뜨는 상담은 사용자의 **상담 신청 화면**에서 저장된 것과 같은 데이터입니다.
- **상담 상세 화면**과 같은 데이터를 씁니다. 상태 표시·이력이 어긋나지 않게 함께 확인해야 합니다. (`docs/features/admin-consultation-detail.md`)
- 상태를 바꾸면 **사용자 알림함**에 알림이 생깁니다.
- **관리자 홈**의 숫자 카드 2개가 이 상담 데이터를 셉니다. (`docs/features/admin-home.md`)
- 새 상담이 접수되면 **관리자 알림함**에 `새로운 상담 신청` 알림이 생깁니다. (`docs/features/admin-notifications.md`)
