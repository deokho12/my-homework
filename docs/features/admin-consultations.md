# 관리자 — 상담 예약 (목록)

> 환자가 신청한 상담을 한 화면에서 보고, 연락한 뒤 상태를 바꾸는 화면입니다. 왼쪽이 목록,
> 오른쪽이 상세입니다 (상세의 내용은 [admin-consultation-detail.md](admin-consultation-detail.md)).

| | |
|---|---|
| **주소** | `/admin/consultations` (상담을 고르면 `/admin/consultations/:id`) |
| **누가 보나요** | 병원 담당자(`hospital_admin`)는 **담당 병원의 상담만**, 운영자(`operator`)는 전체를 **보기만** 합니다 |
| **어디서 들어오나요** | 관리자 홈(`/admin`)의 `상담 예약` 버튼 |
| **소스 파일** | `frontend/src/pages/admin/AdminConsultationsPage.tsx` (목록·필터·상세는 `frontend/src/features/consult/components/`, 문구·날짜는 `frontend/src/features/consult/consultDisplay.ts`, 판정 규칙은 `frontend/src/features/consult/lib/transition.ts`) |

## 여기서 할 수 있는 일

상태 표시: ✅ 실제로 동작함 · 🟡 화면은 되지만 데이터가 샘플 · 🚧 아직 아무 일도 안 일어남 · 🔒 로그인 필요

| 할 수 있는 일 | 상태 | 지금 어떻게 동작하나요 |
|---|---|---|
| 상태 탭 바꾸기 | ✅ 🔒 | `전체 N` · `신규 N` · `연락중 N` · `예약확정 N` · `내원완료 N` · `취소 N`. 기본 탭은 `신규` 이고 주소에 적지 않습니다. 키보드 ←/→/Home/End 로도 옮길 수 있습니다 |
| 탭 숫자 보기 | ✅ 🔒 | **지금 걸린 기간·시술·검색을 함께 반영한 숫자**입니다. 탭을 눌러도 다른 탭의 숫자는 흔들리지 않습니다 |
| 기간으로 걸러 보기 | ✅ 🔒 | `오늘` · `이번 주`(월요일 시작) · `최근 30일`(기본, 오늘 포함) · `전체`. 경계는 **한국 시간(Asia/Seoul) 달력**입니다 |
| 시술로 걸러 보기 | ✅ 🔒 | 9개 대분류 중 하나 (`전체 시술` 이 기본) |
| 이름·연락처 뒷자리로 검색 | ✅ 🔒 | 입력을 멈추면 0.25초 뒤에 걸립니다. 이름은 부분일치, 숫자는 번호와 대조합니다 (운영자는 **뒤 4자리만**) |
| 목록에서 상담 고르기 | ✅ 🔒 | 고르면 오른쪽에 상세가 열립니다 (좁은 화면에서는 상세만 보이고, 뒤로 가기로 목록에 돌아옵니다. 걸어둔 조건은 그대로입니다) |
| 지연된 건 알아보기 | ✅ 🔒 | `신규` 로 **24시간**이 지나면 빨간 `지연` 표시가 붙습니다 |
| 목록에서 바로 상태 바꾸기 | 🚧 | **일부러 없앴습니다.** 상태를 바꾸면 환자에게 알림이 나가고 되돌릴 수 없어서, 상세에서 고른 뒤 `저장`을 눌러야 바뀝니다 |
| 목록에서 전체 연락처 보기 | 🚧 | **일부러 가립니다** (`010-****-4411`). 전체 번호는 상세 한 곳에만 있습니다 (아래 "알아두실 것") |
| 병원별로 걸러 보기 | 🚧 | 화면에 없습니다. 담당 병원이 여러 곳인 담당자는 한 목록에서 함께 봅니다 (어느 병원의 건인지는 카드에 적힙니다) |
| 유입 경로(어느 화면에서 신청했는지) | 🚧 | **만들지 않았습니다.** 신청 화면이 그 값을 보내지 않아 전 건이 빈칸이 됩니다 |
| 엑셀로 내려받기 | 🚧 | **만들지 않았습니다** (대량 반출이라 기록·권한 설계가 먼저입니다) |
| 상담 삭제하기 | 🚧 | 없습니다 |

## 화면에 보이는 정보

- **제목** — `상담 예약` + `환자가 앱에서 '상담 신청'을 누르면 여기로 들어와요. 연락한 뒤 상태를 바꿔 주세요.`
- **상태 탭 6개** — 라벨은 카드의 상태 칩과 같은 표에서 옵니다. 숫자를 아직 모르는 동안(불러오는 중·실패)에는 **숫자를 그리지 않습니다**
- **필터 줄** — `기간` · `시술` · `검색`(`환자 이름 또는 연락처 뒷자리`)
- **상담 카드 한 장 = 네 줄**
  1. 상태 칩 + (해당되면) `지연` + 오른쪽에 접수 시각 `10/7 18:20` (한국 시간)
  2. 환자 **이름** + 가려진 연락처 `010-****-4411`
  3. `{병원 이름} · {대분류} · {세부 시술}` (시술을 고르지 않았으면 `시술 미지정`). 병원 이름은 상담 응답에 없어 **병원 id 로 따로 조회**합니다 — 불러오는 동안은 `—` 입니다
  4. 확정된 방문 일시 `10/9(목) 14:00 방문` (굵게) — 없으면 `평일 오후 연락 희망`
- 상태 칩 색: `신규` 파랑 · `연락중` 호박 · `예약확정` 브랜드색 · `내원완료` 회색 · `취소` 빨강(연한 장미색).
  **마이페이지 상담 내역의 칩과 같은 색표**입니다 (`frontend/src/features/consult/consultDisplay.ts`)

### 특별한 상황일 때

| 상황 | 화면 |
|---|---|
| 조건이 전부 기본값인데 0건 | 탭에 맞는 문구 — `처리할 새 상담이 없어요` / `연락중인 상담이 없어요` / `예약이 잡힌 상담이 없어요` / `내원한 상담이 없어요` / `취소된 상담이 없어요` / (전체) `접수된 상담 예약이 없어요` — 아래에 `최근 30일 기준이에요. 그 전에 들어온 상담은 기간을 넓혀야 보여요.` 와 `전체 기간 보기` 버튼이 함께 나옵니다. 30일 넘게 아무도 연락하지 않은 신규 건이 기본 기간에 가려 "없다" 고 보이지 않게 하기 위해서입니다 |
| 기간·시술·검색 때문에 0건 | `조건에 맞는 상담이 없어요` · `검색어나 기간을 바꿔 보세요` · `조건 초기화` 버튼 (**기간·시술·검색만 되돌리고 탭은 그대로 둡니다**) |
| 아직 상담을 고르지 않음 (넓은 화면) | 오른쪽에 `왼쪽에서 상담을 선택하세요` |
| 담당하지 않는 병원의 상담 주소로 들어옴 | `상담 정보를 찾을 수 없어요` — **"권한이 없다"고 말하지 않습니다.** 그렇게 말하면 주소를 바꿔가며 "저 번호의 상담이 있다"를 알아낼 수 있기 때문입니다 |
| 마스킹된 번호(`010-****-4411`)로 검색 | **0건이 정상입니다.** `*` 는 숫자가 아니라 아무것과도 맞지 않습니다 |

## 주소에 남는 것

고른 조건은 주소에 적혀서, 상세에 들어갔다 뒤로 와도 그대로입니다.

| 조건 | 주소 | 기본값 (주소에 적지 않음) |
|---|---|---|
| 상태 탭 | `?status=contacted` | `신규` |
| 기간 | `?period=today` | `최근 30일` |
| 시술 | `?category=implant` | 전체 시술 |
| 검색 | `?q=박서영` | 빈 값 |

검색만 **주소를 덮어쓰며**(뒤로 가기 이력이 글자마다 쌓이지 않게), 탭·기간·시술은 새 이력으로 쌓입니다.

## 알아두실 것

- **목록에서는 담당자에게도 번호 가운데가 가려집니다** (`010-****-4411`). 목록은 "누가 무엇을 봤는지" 기록이 남지 않는 자리라, 전체 번호가 여기 실리면 기록 없이 대량으로 빼낼 수 있게 됩니다. 전체 번호를 보는 길을 **기록이 남는 상세 한 곳**으로 모았고, `전화 걸기` 도 거기 있습니다.
- **운영자는 이름도 가려서 봅니다** (`박*영`). 분쟁·CS 확인에 필요한 것은 상담의 존재와 상태이지 연락처가 아닙니다.
- **지연(24시간)은 화면이 판정합니다.** 서버가 "지연됨" 을 내려주면 받는 순간부터 낡기 시작하는 값이 화면에 남기 때문입니다.
- **한 번에 100건까지 보여줍니다.** 101건째부터는 조용히 잘립니다 (`docs/features/known-issues.md`).
- **데이터는 서버가 아니라 보고 있는 브라우저에 저장됩니다.** 다른 컴퓨터에서는 다른 목록이 보입니다. 담당 병원 가르기도 브라우저 안에서 흉내 낸 것이라 **진짜 보호는 아직 아닙니다**.
- **샘플 상담 7건이 미리 들어 있습니다.** 실제 고객이 아닙니다 (`김민준` `박서준` `최지훈` `정하윤` `강도윤` `이서연` `한소율`). 날짜가 2026년 6~7월로 고정이라 **기본 기간(`최근 30일`)과 `오늘`·`이번 주` 로는 보이지 않습니다** — 빈 화면의 `전체 기간 보기` 를 누르거나 `기간` 을 `전체` 로 바꾸면 나옵니다.
- 정렬은 **신청 최신순 고정**입니다.

## 이 화면을 바꾸고 싶을 때

`docs/features/requests/_TEMPLATE.md` 를 복사해서 `docs/features/requests/` 에 요청서를 만들거나,
채팅창에 `/feature-request` 를 입력하세요.

이 화면에서 손대면 함께 확인해야 하는 것:

- 목록에 뜨는 상담은 환자의 **상담 신청 화면**에서 저장된 것과 같은 데이터입니다. (`docs/features/consult-request.md`)
- **상담 상세**는 같은 화면의 오른쪽입니다. 상태 칩·날짜 표기가 어긋나지 않게 함께 봐야 합니다. (`docs/features/admin-consultation-detail.md`)
- 상태를 바꾸면 **사용자 알림함**에 알림이 생기고, 환자의 **마이페이지**에 확정 일시가 보입니다. (`docs/features/notifications.md`, `docs/features/mypage.md`)
- **관리자 홈**의 숫자 카드가 같은 상담 데이터를 셉니다. (`docs/features/admin-home.md`)
- 새 상담이 접수되면 **관리자 알림함**에 `새로운 상담 신청` 알림이 생깁니다. (`docs/features/admin-notifications.md`)
