# 알려진 문제

화면 문서를 만들면서 코드를 훑어 찾은 문제들입니다. **이미 알고 있으니 다시 제보하지 않으셔도 됩니다.**
"이거 고장난 것 같은데" 싶을 때 여기 있는지 먼저 확인해 주세요.

여기 없는 것을 발견하셨으면 알려주세요.

> 작성 시점: 2026-08-12. 전부 코드로 확인한 것이며 추측이 아닙니다.
> 이 목록은 서버가 없어서 생기는 한계(샘플 데이터, 브라우저 저장)와는 별개입니다. 그건 [README](README.md) 를 보세요.

---

## 🔴 먼저 처리해야 하는 것

### 관리자 화면에 로그인 검사가 없습니다

`/admin` 으로 시작하는 7개 화면 전부입니다. 주소만 알면 로그인하지 않은 누구나 들어와서 볼 수 있고 수정할 수 있습니다. **상담 관리 화면에는 고객 실명과 전화번호가 그대로 표시됩니다.**

마이페이지에 `병원 담당자이신가요? 관리자 페이지` 링크가 로그인 여부와 무관하게 노출되어 있어서, 우연히 들어가는 것도 가능합니다.

**그때까지: 관리자 화면 주소를 외부에 공유하지 마세요.** 구조 개편 계획의 8단계에서 막습니다.

### 비밀번호가 브라우저에 그대로 저장됩니다

회원가입 시 입력한 비밀번호가 암호화 없이 브라우저에 저장됩니다. 서버가 없어서 생긴 임시 구현입니다.

**그때까지: 실제로 쓰는 비밀번호를 넣지 마세요.** 테스트용 비밀번호만 쓰세요.

### 다른 사람의 찜 목록이 보입니다

찜 목록이 계정과 연결되어 있지 않고, 로그아웃할 때 지워지지도 않습니다. 그래서 **A 계정으로 찜 → 로그아웃 → B 계정 로그인** 하면 A가 찜한 병원이 B에게 그대로 보입니다.

같은 이유로 알림도 계정별로 나뉘지 않습니다. 로그인한 아무 계정이나 모든 사용자 알림을 봅니다. 관리자가 상담 상태를 바꾸면 그 알림이 **관리자 자신의 알림함**에도 들어옵니다.

## 🟠 기능이 의도대로 동작하지 않는 것

### 검색으로 들어가면 홈으로 못 돌아갑니다

홈의 인기 검색어 태그를 누르면 검색 화면을 거쳐 자동으로 병원/시술 화면으로 넘어갑니다. 그다음 뒤로 가기를 누르면 검색 화면이 다시 자동 실행되어 또 앞으로 밀어냅니다. 홈으로 돌아갈 수 없습니다.

### 추천 검색어(광고) 알약이 아무것도 하지 않습니다

검색 화면 상단의 `✦` 알약 6개입니다.

- 눌러도 **검색이 실행되지 않습니다.** 검색창에 글자만 채워집니다
- 직접 검색 버튼을 눌러도 6개 중 **`교정` 하나만** 결과가 나옵니다. 나머지 5개(`몰라몰라 PICK 인기 임플란트` 등)는 `검색 결과가 없어요` 로 떨어집니다

광고 영역인데 실질적으로 죽어 있는 상태입니다.

### 의사를 검색하면 병원 화면으로 갑니다

인기 검색어의 `의사` 탭 항목을 누르면 전문의 상세 화면이 아니라 그 의사가 소속된 병원 상세로 갑니다. 전문의 상세 화면(`/doctor/:id`)이 있는데도 쓰지 않습니다.

### "전문의 상담신청"인데 어느 전문의인지 저장되지 않습니다

병원 상세나 전문의 상세에서 `전문의 상담신청` 을 눌러도, 저장되는 신청 내용에는 **병원만** 기록됩니다. 관리자가 상담을 받아도 어느 전문의를 지목했는지 알 수 없습니다.

지금은 상담 신청 폼의 `남기고 싶은 말 (선택)` 칸에 직접 적어야 합니다.

### 상담 마감인 병원도 상담이 접수됩니다

병원 상세에서는 `상담 마감` 으로 버튼이 막히지만, 상담 신청 주소로 직접 들어가면 정상 접수됩니다.

### 커뮤니티 답변을 쓸 수 있는 화면이 없습니다

답변은 샘플 데이터에만 있습니다. 사용자가 새로 쓴 글은 영구히 `아직 답변이 없어요` 상태로 남습니다.

### 커뮤니티 글 작성자가 항상 `익명` 입니다

로그인한 사람의 이름을 쓰지 않고 항상 `익명` 으로 저장됩니다. 글쓰기에 로그인 검사도 없습니다.

### 상담 신청 내역을 볼 화면이 없습니다

마이페이지와 로그인 화면이 `상담 신청 내역을 확인할 수 있어요` 라고 안내하지만, 사용자용 상담 내역 화면이 존재하지 않습니다. 신청 내용은 관리자 화면에만 나타납니다.

### 지도가 보이지 않습니다

카카오맵 API 키가 설정되지 않아서 지도 자리에 `카카오맵 API 키가 설정되지 않았어요` 만 표시됩니다. 병원 탐색의 지도 보기, 병원 상세의 지도 창 모두 해당합니다.

## 🟡 관리자 화면 — 데이터가 잘못될 수 있는 것

### 전문의 이름을 비우고 저장하면 그 전문의가 삭제됩니다

병원 정보 수정 화면에서 기존 전문의의 이름만 지우고 저장하면, 삭제 버튼을 누르지 않았는데도 완전히 삭제됩니다. 되돌릴 수 없습니다.

### 대표 이미지를 바꿔도 병원 상세 사진이 그대로입니다

병원 정보 수정에서 대표 이미지 주소를 바꿔도 병원 상세 화면의 사진 캐러셀에는 반영되지 않습니다. 새로 등록할 때는 반영됩니다.

### 인증된 전문의의 전문 분야를 바꿔도 재검수되지 않습니다

승인된 전문의의 전문 분야를 다른 과로 바꾸면 인증 상태가 그대로 유지되어, 검수 없이 새로운 과의 `전문의` 배지가 노출됩니다.

### 전문의 승인/반려 결과가 병원에 통보되지 않습니다

상담 상태를 바꾸면 사용자에게 알림이 가는데, 전문의 인증 승인·반려는 어떤 알림도 만들지 않습니다. 병원은 검수 결과를 알 방법이 없습니다.

### 같은 상태를 다시 눌러도 처리됩니다

이미 `예약완료` 인 상담에 `예약완료` 를 다시 누르면 상태 변경 기록이 중복으로 쌓이고 사용자 알림도 또 생성됩니다. 목록에서 빠른 상태 버튼을 오탭하면 쉽게 발생합니다.

### 병원 목록·전문의 검수 목록이 0건일 때 빈 화면입니다

아무 안내 문구 없이 비어 보입니다. 상담 목록과 알림함에는 안내가 있어 일관성이 없습니다.

### `이번 달 신규 상담` 이 항상 0입니다

샘플 상담 데이터의 날짜가 2026년 6~7월이라 현재 월과 맞지 않습니다.

## ⚪ 사소한 것

- **뒤로 가기 버튼이 두 개** — 전문의 상세, 시술 꿀팁 상세에서 화면 상단 헤더의 `‹` 와 화면 안 동그란 버튼이 같이 나옵니다. 두 화면의 헤더 제목도 항상 비어 있습니다
- **이벤트 화면에서 두 번째 줄 카드가 붙습니다** — 카드 사이 위아래 여백이 없습니다
- **커뮤니티 조회수가 방문마다 올라갑니다** — 같은 사람이 다시 봐도 계속 증가해서 실제 조회 수와 무관합니다
- **홈 배너를 눌러도 반응이 없습니다** — 링크가 없는 것이 현재 정상 동작입니다. 자동 넘김도 없습니다
- **광고 노출 기간이 2026년 7~9월로 고정** — 그 기간이 지나면 `광고` 배지와 상단 노출이 조용히 사라집니다
- **`주요 진료 분야` 가 비면 제목만 남습니다** — 전문의 상세에서, 다른 영역들은 `등록된 ... 없어요` 안내가 있는데 이 영역만 없습니다
- **앱 다운로드 QR과 스토어 주소가 비어 있습니다** — 홈 화면 하단. 회색 `QR` 상자만 나옵니다
- **회사 정보가 전부 임시 값입니다** — 대표 `홍길동`, 개인정보관리책임자 `김보안` 등. `frontend/src/mocks/fixtures/placeholder-company-info.ts` 의 값을 바꾸면 홈 화면 하단에 반영됩니다

## 개발자용 메모

문서에는 쓰지 않았지만 구조 개편 때 함께 다뤄야 하는 것들입니다.

- **저장소 갈라짐 위험** — 병원은 `mockDb` 로 통일했지만 의사·커뮤니티는 아직 zustand persist 입니다. `molarmolar-community-posts` 키는 `useCommunityStore` 와 `mockDb.LEGACY_SOURCES` 가 동시에 소유합니다. 각 도메인을 API 레이어로 옮길 때 병원에서 겪은 회귀가 재현될 수 있습니다. 특히 `HospitalForm` 저장 한 번에 병원(mockDb)과 전문의(persist)가 서로 다른 저장소로 갑니다
- **비반응형 스토어 읽기** — `PromotionCard:14`, `tips/[id].tsx:29-31`, `doctor/[id].tsx:31` 이 `getHospitalById()`(`getState()` 스냅샷)를 씁니다. 관리자가 수정해도 재렌더되지 않습니다
- **관리자 알림 이동이 종류를 구분하지 않음** — `admin/notifications.tsx:14` 가 `relatedId` 만 보고 상담 상세로 보냅니다
- **도달 불가 코드** — `specialists.tsx` 의 `reason.trim() || '사유 미입력'` 은 버튼이 disabled 라 실행될 수 없습니다
- **검수 목록에 `일반의` 포함** — `isVerifiedSpecialist` 가 제외하는 대상인데 승인/반려 버튼과 함께 표시됩니다
- **낡은 주석** — `explore.tsx:44-46` 이 "12개 시술, tmj 로 끝난다"고 하지만 `botox` 추가로 실제 15개입니다
- **`RouterBridge` 가 렌더 중 모듈 변수 대입** — `navigation/index.tsx:57`. 의도된 shim 이지만 React 19 동시성 렌더에서 위험한 패턴입니다
