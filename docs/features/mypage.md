# 마이페이지

> 내 활동을 한자리에서 보는 화면입니다. 프로필 아래 탭 세 개(**상담 내역 · 내 문의 · 찜**)로 내가 신청한 상담, 남긴 문의, 찜해둔 병원을 확인하고, 그 아래 메뉴에서 알림함으로 가거나 로그아웃합니다. 병원 담당자가 관리자 화면으로 들어가는 입구도 여기에 있습니다.

| | |
|---|---|
| **주소** | `/mypage` (탭이 주소에 남습니다 — `/mypage?tab=inquiries`, `/mypage?tab=favorites`) |
| **누가 보나요** | 누구나 들어올 수 있지만, **로그인했는지에 따라 보이는 내용이 크게 달라집니다** |
| **어디서 들어오나요** | 아래 탭바의 `마이페이지`, 넓은 화면(PC)에서는 오른쪽 위 👤 프로필 동그라미 (로그인한 경우에만 나타납니다), 상담 신청 완료 화면의 `내 상담 내역 보기` |
| **소스 파일** | `frontend/src/pages/MyPage.tsx` + 상담 줄의 문구·색을 정하는 `frontend/src/features/consult/consultDisplay.ts` + 찜 카드 `frontend/src/features/hospital/components/HospitalCard.tsx` |

## 여기서 할 수 있는 일

상태 표시: ✅ 실제로 동작함 · 🟡 화면은 되지만 데이터가 샘플 · 🚧 아직 아무 일도 안 일어남 · 🔒 로그인 필요

| 할 수 있는 일 | 상태 | 지금 어떻게 동작하나요 |
|---|---|---|
| 로그인 화면으로 가기 | ✅ | 로그인하지 않은 상태에서 보이는 `로그인` 버튼 |
| 회원가입 화면으로 가기 | ✅ | 로그인하지 않은 상태에서 보이는 `회원가입` 버튼 |
| 내 정보 확인하기 | ✅ 🔒 | 이름 첫 글자 동그라미와 함께 `OOO님, 안녕하세요` · 가입할 때 쓴 이메일이 보입니다 |
| **상담 내역 보기** | ✅ 🔒 🟡 | 탭 `상담 내역 N`. **내가 신청한 건만** 최신순으로 나옵니다. 한 줄에 병원 이름, `대분류 · 세부시술`, 상태 칩, `10/7 신청 · 평일 저녁 연락 희망` |
| 상담 한 줄 눌러 병원 보기 | ✅ 🔒 | 그 상담을 신청한 병원의 상세 화면으로 갑니다 |
| **내 문의 보기** | ✅ 🔒 | 탭 `내 문의 N`. **내가 남긴 문의만** 최신순으로 나옵니다. 한 줄에 질문 첫 줄, 상태 칩(`답변 대기`/`답변완료`), `병원이름 · 공개/비공개`, `10/7 문의` |
| 문의 한 줄 펼쳐 답변 읽기 | ✅ 🔒 | 줄을 누르면 질문 전문과 병원 답변이 펼쳐집니다. 아직 답이 없으면 `아직 답변을 기다리는 중이에요`. 비공개 답변을 읽을 수 있는 곳은 **여기뿐**입니다 |
| 펼친 줄에서 병원 보기 | ✅ 🔒 | `병원 상세 보기 ›`. 공개로 답변받은 문의라면 병원 상세의 `문의` 섹션으로 바로 내려갑니다 |
| 찜한 병원 목록 보기 | ✅ 🔒 🟡 | 탭 `찜 N`. 찜해둔 병원이 **최근에 찜한 것부터** 카드로 나열됩니다. 새로고침해도 유지됩니다. 병원 정보 자체는 샘플입니다 |
| 찜 해제하기 | ✅ 🔒 | 카드 오른쪽 위 채워진 하트를 누르면 빈 하트로 바뀌고 **목록에서 바로 사라지며 탭의 숫자도 줄어듭니다** |
| 탭 바꾸기 | ✅ 🔒 | 눌러서, 또는 키보드 ←/→/Home/End 로 옮깁니다. 주소가 함께 바뀌어 **새로고침해도 같은 탭**이 열립니다 (뒤로 가기 이력은 쌓지 않습니다) |
| 알림함 들어가기 | ✅ 🔒 | 메뉴의 `알림함`. 안 읽은 알림이 있으면 오른쪽에 빨간 동그라미로 개수가 표시됩니다 |
| 로그아웃하기 | ✅ 🔒 | 메뉴의 `로그아웃` → 브라우저 확인창 `로그아웃` / `로그아웃할까요?`. 확인하면 탭·메뉴·목록이 사라지고 `로그인이 필요해요` 카드만 남습니다 |
| 관리자 화면으로 가기 | ✅ 🔒 | 맨 아래 `병원 관리자 페이지`. **병원 관리자·운영자 계정으로 로그인했을 때만 보입니다** |
| 알림 설정 / 회원정보 수정 | 🚧 🔒 | 메뉴에 자리만 있고 회색 + `준비중` 배지입니다. **눌리지 않고 키보드 포커스도 가지 않습니다** |
| 예약 확정 일시 보기 | 🚧 🔒 | `10/9(목) 14:00 방문` 처럼 보여줄 자리와 서식은 준비됐지만, **병원이 일시를 입력할 방법이 아직 없습니다** (요청서 `2026-10-12-04`) |
| 프로필 사진·이름 바꾸기 / 비밀번호 변경 / 회원 탈퇴 | 🚧 | 해당 화면이 없습니다 |

## 화면에 보이는 정보

### 로그인하지 않았을 때

- **제목** — `마이페이지`
- **안내 카드** — `로그인이 필요해요` / `로그인하면 찜한 병원과 상담 신청 내역을 확인할 수 있어요` / 나란히 놓인 `로그인` · `회원가입` 버튼
- 탭, 메뉴, 관리자 입구는 **아예 나타나지 않습니다**

### 새로고침 직후 (로그인 상태를 확인하는 아주 짧은 순간)

- 프로필 자리에 **회색 네모 하나**만 깜빡입니다. 이때 `로그인이 필요해요` 카드를 그리지 않기 때문에, 로그인해 둔 사람이 새로고침할 때 "로그아웃됐나?" 싶은 번쩍임이 없습니다.

### 로그인했을 때

- **제목** — `마이페이지`
- **프로필** — 이름 첫 글자 동그라미, `OOO님, 안녕하세요`, 이메일
- **탭 3개** — `상담 내역 N` · `내 문의 N` · `찜 N`
  - 숫자는 **아직 모르는 동안(불러오는 중·실패)에는 붙지 않습니다.** 라벨만 보입니다
  - 고른 탭만 색이 들어오고, 그 탭의 목록만 그려집니다
- **메뉴** — `알림함`(안 읽은 개수 빨간 배지 + `›`) / `알림 설정` `준비중` / `회원정보 수정` `준비중` / `로그아웃`
- **맨 아래** — `병원 관리자 페이지` + `관리자 전용` (병원 관리자·운영자에게만)

### 상담 내역 한 줄에 보이는 것

- **병원 이름** — 길면 한 줄로 잘립니다. 불러오는 중에는 `—`, 병원을 찾을 수 없으면 `알 수 없는 병원`
- **상태 칩** — `신규`(파랑) · `연락중`(호박) · `예약확정`(브랜드색) · `내원완료`(회색) · `취소`(빨강). **관리자 상담 예약 목록의 칩과 같은 색**입니다
- **시술** — `충치치료 · 레진` 처럼 `대분류 · 세부시술`. 고르지 않고 신청했으면 `시술 미지정`
- **아랫줄** — 병원이 방문 일시를 확정했으면 **`10/9(목) 14:00 방문`(굵게)**, 아직이면 `10/7 신청 · 평일 저녁 연락 희망` (날짜는 한국 시간 기준, 연도는 적지 않습니다). 둘을 함께 보여주지 않는 이유는 **어느 날짜를 지켜야 하는지가 흐려지기 때문**입니다
- 빈 목록일 때 — `아직 신청한 상담이 없어요` / `관심 있는 병원을 찾아 상담을 신청해보세요` / `병원 찾아보기`

### 내 문의 한 줄에 보이는 것

- **제목** — 질문 **첫 줄**(40자가 넘으면 `…`). 문의에는 제목 칸이 없어서 본문에서 만듭니다
- **상태 칩** — `답변 대기`(파랑) · `답변완료`(브랜드색). **관리자 문의 화면의 `미답변`/`답변완료` 와 같은 색**입니다 (부르는 말만 다릅니다)
- **둘째 줄** — `강남 스마일 치과 · 공개` 또는 `· 비공개` (답이 오기 전에는 내가 고른 값, 답이 온 뒤에는 병원 상세에 실제로 올라갔는지)
- **셋째 줄** — `10/7 문의` + 펼침 화살표
- **펼쳤을 때** — 질문 전문, 답변 블록(`10/8 답변 · 공개` 또는 `10/8 답변 · 비공개 · 나만 볼 수 있어요`), `병원 상세 보기 ›`
- 빈 목록일 때 — `아직 남긴 문의가 없어요` / `병원 상세에서 궁금한 점을 물어보세요` / `병원 찾아보기`

### 찜한 병원 카드에 표시되는 것

- 병원 사진, 진행중인 이벤트가 있으면 사진 위에 🔥 배지 (예: `🔥 얼리버드`)
- 오른쪽 위 하트 (찜 해제용 — 병원 탐색·카테고리 카드, 병원 상세와 같은 버튼입니다)
- 병원 이름, 상담을 받는 병원이면 오른쪽에 `상담가능` 배지
- 지역
- 배지들 — `광고` · `🌟 추천` · `⚡ 원데이 가능` · `OO전문의 상주` · 시술 이름 최대 3개. 시술 이름은 **세부 시술 이름**(`레진` `크라운` …)이고, 서버에 저장된 이름과 같습니다 (2026-10-21 부터)
- 이벤트가 있으면 할인율 · 할인가 · 취소선 원래 가격
- 가격대와 `★ 4.8 (312)` 형태의 평점·후기 수
- 빈 목록일 때 — `아직 찜한 병원이 없어요` / `병원 카드의 하트를 눌러 찜해보세요` / `병원 찾아보기`

## 알아두실 것

- **상담 내역은 내가 신청한 것만 보입니다.** 같은 브라우저를 다른 계정으로 써도 남의 신청은 보이지 않습니다. 다만 **샘플로 들어 있는 상담 7건은 주인이 없어서 누구의 내역에도 잡히지 않습니다** — 직접 신청해 보셔야 목록에 뜹니다.
- **상담 내용은 아직 이 브라우저 안에만 저장됩니다.** 서버의 상담 기능이 없어서, 다른 컴퓨터나 시크릿 창에서는 내역이 비어 있고 브라우저 데이터를 지우면 사라집니다. (로그인 자체는 실제 서버를 씁니다 — 아래 참고)
- **상태는 병원이 바꿉니다.** 관리자가 `상담 예약`에서 상태를 바꾸면 이 화면의 칩도 따라 바뀌고, [알림함](notifications.md)에 그 상태에 맞는 알림(`상담 예약이 확정됐어요` 등)이 들어옵니다.
- **상담 알림을 누르면 이 탭이 열리고 그 상담 줄에 포커스와 강조 테두리가 갑니다.** 주소의 `?consult=...` 는 한 번 쓰고 지워지므로 새로고침하면 강조가 사라지고, 내 내역에 없는 상담 id(샘플 상담, 100건 상한 밖)면 **아무 줄도 강조되지 않고 탭만 열립니다.**
- **방문 일시는 병원이 `예약확정` 으로 바꾸면서 넣는 값입니다.** 병원이 취소하거나 `연락중` 으로 되돌리면 그 줄은 **사라집니다** — 취소된 상담에 방문 예정이 남으면 거짓말이 되기 때문입니다. `내원완료` 가 되어도 일시는 그대로 남습니다.
- **취소 사유는 보이지 않습니다.** 병원 내부의 처리 분류라 환자 화면으로 내려오지 않습니다.
- **상담 내역은 100건까지만 보입니다.** 페이지 넘김이 없어 101번째부터는 조용히 잘립니다.
- **내 문의도 내가 남긴 것만 보입니다.** 문의는 샘플 데이터가 없어서, 직접 [문의하기](inquiry.md)로 남겨 보셔야 목록에 뜹니다. 상담과 마찬가지로 이 브라우저 안에만 저장됩니다.
- **`공개`/`비공개` 는 답이 오기 전과 후에 뜻이 다릅니다.** 답이 오기 전에는 "내가 공개로 물었다" 는 뜻이고(병원이 아직 고르지 않았으므로), 답이 온 뒤에는 **병원 상세에 실제로 올라갔는지**를 말합니다. 공개로 물었어도 병원이 비공개로 답하면 `비공개` 로 바뀌고 답변 줄에 `비공개 · 나만 볼 수 있어요` 가 붙습니다. `병원 상세 보기 ›` 는 실제로 올라간 건만 병원 상세의 `문의` 영역으로 바로 데려갑니다.
- **내 문의도 100건까지만 보입니다.** 상담 내역과 같은 상한입니다.
- **답변 알림을 누르면 이 탭이 열리고 그 문의가 펼쳐집니다.** 주소의 `?inquiry=...` 는 한 번 쓰고 지워지므로, 새로고침하면 다시 접힙니다.
- **찜 목록이 계정별로 나뉘어 있지 않습니다.** 브라우저 하나에 찜 목록도 하나뿐입니다. 다만 **로그인·로그아웃할 때 찜 목록을 비우기 때문에**, A 계정으로 찜한 병원이 B 계정에게 보이지는 않습니다. 대신 로그아웃하면 내 찜도 함께 사라집니다 — 계정별 찜은 서버가 생겨야 제대로 됩니다.
- **찜 목록의 순서는 최근에 찜한 것이 먼저입니다.**
- **로그인은 실제 서버를 씁니다.** 계정·비밀번호는 브라우저가 아니라 서버에 있고(비밀번호는 해시로 저장됩니다), 이 화면이 들고 있는 것은 토큰뿐입니다. 새로고침하면 서버에 `내가 누구인지`를 다시 물어봅니다 — 위의 회색 네모가 그 사이입니다.
- **로그아웃 확인창은 브라우저가 직접 띄우는 기본 창입니다.** 그래서 모양이 브라우저마다 다르고, 앱 디자인과 어울리지 않아 보일 수 있습니다.
- **알림함의 안 읽은 개수는 사용자용 알림만 셉니다** (관리자용 알림은 세지 않습니다). 알림 내용도 모두 샘플입니다.
- **탭을 바꿔도 뒤로 가기 이력이 쌓이지 않습니다.** 찜 탭에서 병원 상세로 갔다가 뒤로 오면 찜 탭 그대로이고, 한 번 더 뒤로 누르면 마이페이지에 들어오기 전 화면으로 나갑니다.
- **병원 정보는 샘플입니다.** 실제 병원이 아니고, 카드에 보이는 가격·평점·후기 수도 예시 값입니다.
- **상담 내역의 병원 이름은 줄마다 따로 불러옵니다.** 상담 데이터에 병원 이름이 들어 있지 않아서입니다. 목록이 길면 그만큼 조회가 나가고, 이름이 `—` 에서 바뀌는 순간이 보일 수 있습니다.
- 넓은 화면(PC)에서 👤 프로필 동그라미는 **로그인한 경우에만** 위쪽 막대에 나타납니다. 로그인하지 않았다면 `로그인 및 회원가입` 버튼이 그 자리에 있습니다.
- 홈 맨 아래에 있는 회사 정보·약관 영역은 **이 화면에는 없습니다.**

## 이 화면을 바꾸고 싶을 때

`docs/features/requests/_TEMPLATE.md` 를 복사해서 `docs/features/requests/` 에 요청서를 만들거나,
채팅창에 `/feature-request` 를 입력하세요.

이 화면에서 손대면 함께 확인해야 하는 것:

- **상담 상태 칩의 색과 이름**은 관리자 `상담 예약` 목록과 **같은 표 하나**(`frontend/src/features/consult/consultDisplay.ts`)에서 나옵니다. 한쪽만 바꾸면 같은 상담이 두 화면에서 다른 색으로 보입니다.
- **`대분류 · 세부시술` 라벨**은 상담 신청 화면의 시술 알약·완료 화면과 같은 함수를 씁니다.
- **찜 목록**은 병원 상세 화면의 하트와 **같은 데이터**입니다. 여기서 해제하면 병원 상세의 하트도 빈 하트로 바뀝니다.
- **로그인 상태**는 상담 신청·찜하기처럼 로그인을 요구하는 다른 화면들과 같은 정보를 씁니다. 여기서 로그아웃하면 그 화면들이 다시 로그인을 요구합니다.
- **알림함의 안 읽은 개수**는 알림 화면, 그리고 넓은 화면 위쪽 막대의 🔔 아이콘과 **같은 숫자**를 씁니다.
- **내 문의 탭은 [문의하기](inquiry.md)·[관리자 문의 화면](admin-inquiries.md)과 같은 데이터**입니다. 상태 칩의 색은 두 화면이 같은 표(`frontend/src/features/inquiry/inquiryDisplay.ts`)를 씁니다.
- **찜한 병원 카드**는 홈·병원 탐색·검색의 병원 카드와 같은 병원 데이터를 씁니다. 한쪽만 바꾸면 어긋납니다.
- **카드의 시술 배지 이름**은 홈·탐색·시술 카테고리 화면과 같은 목록(`frontend/src/features/procedure/taxonomy.ts`)을 씁니다. 2026-10-21 부터 서버도 같은 31개 이름을 쓰므로 커뮤니티 질문하기·관리자 상담 화면에서도 같은 시술이 같은 이름으로 보입니다.
- **로그인 화면·회원가입 화면**의 동작을 바꾸면 이 화면의 카드 내용도 함께 확인해야 합니다.
