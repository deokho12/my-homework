| 할 수 있는 일 | 상태 | 지금 어떻게 동작하나요 |
|---|---|---|
| 로그인 화면으로 가기 | ✅ | 로그인하지 않은 상태에서 보이는 `로그인` 버튼 |
| 회원가입 화면으로 가기 | ✅ | 로그인하지 않은 상태에서 보이는 `회원가입` 버튼 |
| 내 정보 확인하기 | ✅ 🔒 | 로그인하면 `OOO님, 안녕하세요` 와 가입할 때 쓴 이메일이 보입니다 |

| 찜한 병원 목록 보기 | ✅ 🔒 🟡 | 찜해둔 병원이 카드로 나열됩니다. 새로고침해도 유지됩니다. 병원 정보 자체는 샘플입니다 |
| 찜 해제하기 | ✅ 🔒 | 카드 오른쪽 위 ❤️ 를 누르면 🤍 로 바뀌고 **목록에서 바로 사라집니다.** 해제된 상태도 저장됩니다 |
| 찜한 병원 카드 누르기 | 🟡 | 그 병원의 상세 화면으로 이동합니다 |
| 관리자 화면으로 가기 | ✅ | 화면 맨 아래 `병원 담당자이신가요? 관리자 페이지`. **로그인하지 않아도 들어갑니다** |
| 상담 신청 내역 보기 | 🚧 | 안내 문구에는 언급되지만 **이 화면에 상담 내역 영역이 없습니다** |

## 화면에 보이는 정보

### 로그인하지 않았을 때

- **제목** — `마이페이지`
- **안내 카드** — `로그인이 필요해요` / `로그인하면 찜한 병원과 상담 신청 내역을 확인할 수 있어요` / 나란히 놓인 `로그인` · `회원가입` 버튼
- **맨 아래 링크** — `병원 담당자이신가요? 관리자 페이지`
- 알림함 줄, `찜한 병원` 제목, 찜 목록은 **아예 나타나지 않습니다**

### 로그인했을 때

- **제목** — `마이페이지`
- **내 정보 카드** — `OOO님, 안녕하세요` / 이메일 / `로그아웃` 버튼
- **알림함 줄** — `🔔 알림함`, 안 읽은 개수 빨간 배지, 오른쪽 `›`
- **`찜한 병원`** 제목과 병원 카드 목록
- **찜한 게 없을 때** — 🤍 그림과 함께 `아직 찜한 병원이 없어요` / `병원 카드의 하트를 눌러 찜해보세요`
- **맨 아래 링크** — `병원 담당자이신가요? 관리자 페이지`

### 찜한 병원 카드에 표시되는 것

- 병원 사진, 진행중인 이벤트가 있으면 사진 위에 🔥 배지 (예: `🔥 얼리버드`)
- 오른쪽 위 하트 (찜 해제용)
- 병원 이름, 상담을 받는 병원이면 오른쪽에 `상담가능` 배지
- 지역
- 배지들 — `광고` · `🌟 추천` · `⚡ 원데이 가능` · `OO전문의 상주` · 시술 이름 최대 3개
- 이벤트가 있으면 할인율 · 할인가 · 취소선 원래 가격
- 가격대와 `★ 4.8 (312)` 형태의 평점·후기 수

## 알아두실 것

- **지금의 로그인은 서버 없이 흉내만 낸 것입니다.** 가입한 계정(이메일·비밀번호·이름)이 **그 브라우저 안에만** 저장됩니다. 그래서 이런 일이 생깁니다.
  - 미리 만들어진 계정이 없습니다. **먼저 회원가입을 해야 로그인할 수 있습니다.**
  - 다른 컴퓨터·다른 브라우저·시크릿 창에서는 그 계정이 존재하지 않습니다.
  - 브라우저 데이터를 지우면 계정과 찜 목록이 함께 사라집니다.
  - 비밀번호가 암호화되지 않은 상태로 저장됩니다. 실제 서비스 전에 반드시 바꿔야 하는 부분입니다.
- **찜 목록이 계정별로 나뉘어 있지 않습니다.** 브라우저 하나에 찜 목록도 하나뿐이라서, A 계정으로 찜한 뒤 로그아웃하고 B 계정으로 로그인하면 **A가 찜해둔 병원이 그대로 보입니다.** 로그아웃해도 찜 목록은 지워지지 않습니다.
- **`로그인하면 찜한 병원과 상담 신청 내역을 확인할 수 있어요` 라고 적혀 있지만, 상담 신청 내역은 이 화면에 없습니다.** 사용자가 자기 상담 내역을 보는 화면은 아직 만들어지지 않았고, 신청된 상담은 관리자 화면의 상담 목록에서만 확인할 수 있습니다.
- **로그아웃 확인창은 브라우저가 직접 띄우는 기본 창입니다.** 그래서 모양이 브라우저마다 다르고, 앱 디자인과 어울리지 않아 보일 수 있습니다.
- **`관리자 페이지` 링크는 아무나 들어갈 수 있습니다.** 로그인하지 않아도, 병원 담당자가 아니어도 열립니다. 권한 확인이 아직 없습니다.
- **알림함의 안 읽은 개수는 사용자용 알림만 셉니다** (관리자용 알림은 세지 않습니다). 샘플 알림 기준으로 처음에는 1건이 안 읽음 상태입니다. 알림 내용도 모두 샘플입니다.
- **로그인하지 않으면 화면이 거의 비어 보입니다.** 안내 카드 하나와 맨 아래 관리자 링크만 있는 것이 정상입니다.
- **병원 정보는 샘플입니다.** 실제 병원이 아니고, 카드에 보이는 가격·평점·후기 수도 예시 값입니다.
- 넓은 화면(PC)에서 👤 프로필 동그라미는 **로그인한 경우에만** 위쪽 막대에 나타납니다. 로그인하지 않았다면 `로그인 및 회원가입` 버튼이 그 자리에 있습니다.
- 홈 맨 아래에 있는 회사 정보·약관 영역은 **이 화면에는 없습니다.**

## 이 화면을 바꾸고 싶을 때

`docs/features/requests/_TEMPLATE.md` 를 복사해서 `docs/features/requests/` 에 요청서를 만들거나,
채팅창에 `/feature-request` 를 입력하세요.

이 화면에서 손대면 함께 확인해야 하는 것:

- **찜 목록**은 병원 상세 화면의 하트와 **같은 데이터**입니다. 여기서 해제하면 병원 상세의 하트도 빈 하트로 바뀝니다.
- **로그인 상태**는 상담 신청·찜하기처럼 로그인을 요구하는 다른 화면들과 같은 정보를 씁니다. 여기서 로그아웃하면 그 화면들이 다시 로그인을 요구합니다.
- **알림함의 안 읽은 개수**는 알림 화면, 그리고 넓은 화면 위쪽 막대의 🔔 아이콘과 **같은 숫자**를 씁니다.
- **찜한 병원 카드**는 홈·병원 탐색·검색의 병원 카드와 같은 병원 데이터를 씁니다. 한쪽만 바꾸면 어긋납니다.
- **로그인 화면·회원가입 화면**의 동작을 바꾸면 이 화면의 카드 내용도 함께 확인해야 합니다.
