# 검색

> 시술·병원·원장님 이름을 검색해서 **해당 화면으로 바로 이동**하는 화면입니다. 검색 결과 목록을 보여주는 곳이 아닙니다.

| | |
|---|---|
| **주소** | `/search` (검색어를 미리 넣은 경우 `/search?q=임플란트`) |
| **누가 보나요** | 누구나 (로그인 필요 없음) |
| **어디서 들어오나요** | 홈 화면 맨 위의 검색창, 홈 화면 검색창 아래의 인기 검색어 알약, 화면이 넓을 때(768px 이상) 상단 내비게이션의 🔍 |
| **소스 파일** | `frontend/src/screens/search.tsx` |

---

## 검색이 어떻게 동작하나요 (먼저 읽어주세요)

이 화면의 검색은 **목록을 걸러내는 방식이 아닙니다.** 입력한 글자와 맞는 것 **한 개**를 찾아서, 그 화면으로 곧바로 데려갑니다. 그래서 검색을 실행하면 이 화면은 사라지고 다른 화면이 열립니다.

찾는 순서는 **① 시술 → ② 병원 → ③ 전문의** 이고, 먼저 맞는 것이 나오면 거기서 멈춥니다.

| 순서 | 무엇과 비교하나요 | 맞으면 어디로 가나요 |
|---|---|---|
| ① | 시술 이름 (`임플란트` `교정` `라미네이트` `인레이` `크라운` `치아미백` `사랑니` `충치치료` `잇몸치료` `스플린트` `코골이장치` `턱관절` `보톡스` — 13개) | **병원 탐색** 화면. 병원 목록 모드로 열리고, 그 시술 탭이 미리 눌려 있습니다 |
| ② | 병원 이름 | 그 **병원 상세** 화면 |
| ③ | 전문의 이름 | 그 전문의가 **소속된 병원의 상세** 화면 (전문의 상세 화면이 아닙니다) |
| 없음 | — | 이동하지 않고, 검색창 아래에 `"OO"에 대한 검색 결과가 없어요. 아래 인기 검색어를 살펴보세요` 라는 회색 안내 상자가 나옵니다 |

**글자를 비교하는 방식**: 입력한 글자가 이름 **안에 들어 있어야** 맞는 것으로 봅니다. 즉 이름보다 짧게 치면 찾아지고(`임플` → `임플란트` ✅), 이름보다 길게 치면 못 찾습니다(`임플란트 가격` ❌). 전문의만 예외로, `김민준 원장` 처럼 이름 뒤에 직함을 붙여 쳐도 찾습니다.

## 여기서 할 수 있는 일

상태 표시: ✅ 실제로 동작함 · 🟡 화면은 되지만 데이터가 샘플 · 🚧 아직 아무 일도 안 일어남 · 🔒 로그인 필요

| 할 수 있는 일 | 상태 | 지금 어떻게 동작하나요 |
|---|---|---|
| 검색어 입력 | ✅ | 화면에 들어오면 약 0.2초 뒤 검색창에 커서가 자동으로 들어갑니다. 안내 문구는 `시술, 병원, 원장님 이름을 검색해보세요` |
| 검색 실행 | ✅ 🟡 | 키보드의 Enter 또는 검색창 오른쪽 🔍 를 누르면 실행됩니다. 위의 `검색이 어떻게 동작하나요` 순서대로 찾아서 해당 화면으로 이동합니다. 찾는 대상(시술·병원·전문의)은 샘플 데이터입니다 |
| 결과가 없을 때 안내 받기 | ✅ | 회색 상자로 `"OO"에 대한 검색 결과가 없어요. 아래 인기 검색어를 살펴보세요` 가 나옵니다. 검색창에 글자를 한 자라도 더 입력하거나 지우면 이 안내는 바로 사라집니다 |
| 추천 검색어(광고) 알약 누르기 | 🟡 | 가로로 넘겨보는 `✦` 표시 알약들입니다. **누르면 그 문구가 검색창에 채워지기만 하고, 검색은 실행되지 않습니다.** 실행하려면 Enter 나 🔍 를 한 번 더 눌러야 합니다 |
| 인기 검색어 탭 바꾸기 | ✅ 🟡 | `전체` `시술` `병원` `의사` 네 개. 누르면 아래 순위 목록이 바뀝니다. 목록 내용은 고정된 샘플입니다 |
| 인기 검색어 항목 누르기 | ✅ 🟡 | 검색창을 거치지 않고 곧바로 정해진 화면으로 이동합니다. 시술 항목 → 병원 탐색, 병원 항목 → 병원 상세, 의사 항목 → 그 의사의 **병원 상세** |
| 순위 변동 보기 | 🟡 | 항목 오른쪽에 `▲ 2`(빨강, 상승) `▼ 1`(파랑, 하락) `NEW`(파랑, 신규) `－`(변동 없음)가 표시됩니다. 실제 집계가 아니라 고정된 샘플 값입니다 |
| 뒤로 가기 | ✅ | 검색창 왼쪽의 `‹` |

## 화면에 보이는 정보

- **검색창** — 왼쪽에 `‹` 뒤로 가기, 가운데 입력칸, 오른쪽에 🔍 버튼. 테두리는 브랜드 색입니다
- **추천 검색어(광고) 줄** — 검색창 바로 아래, 가로로 넘겨보는 알약들. 지금 들어 있는 6개는 `몰라몰라 PICK 인기 임플란트` `교정` `몰라몰라만 누리는 라미네이트 할인` `원데이 가능 병원 모음` `코골이장치 상담` `치아미백 이벤트`
- **안내 상자** — 검색 결과가 없을 때만 나타납니다
- **`인기 검색어` 제목 + 시각** — 제목 오른쪽에 `14:32 기준` 처럼 시각이 붙습니다. 이 화면을 열었을 때의 시각이고, 머물러 있는 동안 갱신되지 않습니다
- **탭 줄** — `전체` `시술` `병원` `의사`. 선택된 탭은 검은 글씨 + 아래 검은 밑줄
- **순위 목록** — 왼쪽에 순위 숫자, 가운데 검색어, 오른쪽에 순위 변동. 탭마다 개수가 다릅니다 (`전체` 10개 · `시술` 10개 · `병원` 6개 · `의사` 8개)

이 화면에는 상단 제목 바가 없고, 아래쪽 탭바(홈/병원/커뮤니티/마이)도 나오지 않습니다.

## 이 화면에서 이동할 수 있는 곳

| 어디로 | 무엇을 눌렀을 때 |
|---|---|
| 병원 탐색 (해당 시술 탭이 선택된 상태) | 시술 이름으로 검색, 또는 인기 검색어의 시술 항목 |
| 병원 상세 | 병원 이름으로 검색, 또는 인기 검색어의 병원 항목 |
| 병원 상세 (그 전문의의 소속 병원) | 전문의 이름으로 검색, 또는 인기 검색어의 의사 항목 |
| 직전 화면 | `‹` |

## 알아두실 것

- **검색 결과 목록이 안 나오는 것은 고장이 아닙니다.** 이 화면은 일부러 목록을 만들지 않고, 맞는 것 하나를 찾아 그 화면으로 바로 보냅니다. "임플란트로 검색했더니 병원 목록 화면이 열렸다"는 것이 정상 동작입니다. 여러 결과를 나란히 보여주는 검색 결과 화면이 필요하면 새로 만들어야 합니다.
- **원장님 이름으로 검색하면 전문의 상세가 아니라 병원 상세가 열립니다.** 인기 검색어의 `의사` 탭 항목을 눌러도 똑같이 병원 상세로 갑니다. 전문의 상세 화면(`/doctor/...`)은 병원 상세의 `전문의 소개` 카드를 눌러야 열립니다.
- **추천 검색어(광고) 알약은 눌러도 검색이 실행되지 않습니다.** 검색창에 글자만 채워집니다.
- **추천 검색어 6개 중 `교정` 하나만 실제로 결과가 나옵니다.** 나머지 5개는 문구가 시술·병원 이름보다 길어서, 그대로 검색하면 `검색 결과가 없어요` 가 나옵니다. 광고 문구용으로 넣어둔 값이라 그렇습니다.
- **홈 화면의 인기 검색어 알약을 눌러 들어오면, 검색이 자동으로 실행돼 곧바로 다른 화면으로 넘어갑니다.** 검색 화면이 잠깐 스쳐 지나가는 것처럼 보입니다.
  이때 **브라우저 뒤로 가기를 누르면 검색이 다시 자동 실행되어 앞으로 되돌아옵니다.** 홈으로 돌아가려면 뒤로 가기를 여러 번 누르거나 홈 버튼을 쓰세요. 알려진 문제입니다.
- **`14:32 기준` 은 데이터를 집계한 시각이 아닙니다.** 화면을 연 시각을 그대로 보여주는 것뿐이고, 순위 목록은 언제 봐도 같습니다.
- **순위와 변동 화살표는 실제 검색량이 아닙니다.** 코드에 적어둔 고정 값입니다.
- **병원 이름 검색은 관리자가 새로 등록한 병원까지 찾습니다.** 브라우저에 저장된 병원 목록을 그대로 뒤지기 때문입니다. 다만 데이터가 브라우저에 저장되므로 다른 컴퓨터에서는 다르게 나옵니다.
- **같은 글자가 여러 곳에 걸리면 시술이 이깁니다.** 예를 들어 `라미네이트` 는 시술과 병원 이름(`더화이트 라미네이트클리닉`)에 모두 들어 있지만, 시술을 먼저 찾기 때문에 병원 탐색 화면으로 갑니다. 그 병원으로 가고 싶으면 `더화이트` 처럼 병원 이름만 있는 글자로 검색하세요.
- **검색 기록(최근 검색어)은 저장되지 않습니다.** 검색 후 다시 이 화면에 들어오면 입력칸이 비어 있습니다.
- **좁은 화면(768px 미만)에서는 홈 화면을 통해서만 검색으로 들어올 수 있습니다.** 상단 내비게이션의 🔍 는 넓은 화면에서만 보입니다.

## 이 화면을 바꾸고 싶을 때

`docs/features/requests/_TEMPLATE.md` 를 복사해서 `docs/features/requests/` 에 요청서를 만들거나,
채팅창에 `/feature-request` 를 입력하세요.

이 화면에서 손대면 함께 확인해야 하는 것:

- **인기 검색어 목록과 추천 검색어(광고) 목록은 같은 파일 하나**(`frontend/src/mocks/fixtures/trendingSearches.ts`)에 들어 있습니다. 문구만 바꾸면 검색이 안 되는 문구가 될 수 있으니, 시술·병원·전문의 이름과 맞는지 함께 확인해야 합니다.
- **홈 화면의 인기 검색어 알약**은 이 화면의 `전체` 탭 상위 6개를 그대로 가져다 씁니다. 여기 목록을 바꾸면 홈 화면 알약도 함께 바뀝니다.
- **시술로 검색했을 때 도착하는 병원 탐색 화면**은 넘겨받은 시술 탭을 처음 열릴 때 한 번만 반영합니다. 시술 목록을 바꾸면 두 화면을 함께 확인해야 합니다.
- **검색으로 도착하는 두 화면**(병원 탐색 · 병원 상세)의 주소가 바뀌면 검색이 빈 화면으로 이어질 수 있습니다.
