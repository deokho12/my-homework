# 관리자 알림함

> 새 상담 신청이나 운영 공지 같은 관리자용 알림을 모아 보는 화면입니다. 알림을 누르면 읽음으로 바뀌고 관련 상담으로 바로 들어갑니다.

| | |
|---|---|
| **주소** | `/admin/notifications` |
| **누가 보나요** | 🔒 **병원 관리자·운영자 계정**으로 로그인해야 볼 수 있습니다. 로그인하지 않았으면 로그인 화면으로 보내고, 일반 사용자 계정이면 `접근 권한이 없어요` 만 보입니다 |
| **어디서 들어오나요** | **모든 관리자 화면** 상단바 오른쪽의 🔔 ([공통 레이아웃](admin-shell.md)) |
| **소스 파일** | `frontend/src/screens/admin/notifications.tsx` |

---

## 여기서 할 수 있는 일

상태 표시: ✅ 실제로 동작함 · 🟡 화면은 되지만 데이터가 샘플 · 🚧 아직 아무 일도 안 일어남 · 🔒 로그인 필요

| 할 수 있는 일 | 상태 | 지금 어떻게 동작하나요 |
|---|---|---|
| 관리자 알림 목록 보기 | 🟡 | 관리자용 알림만 골라 **최신순**으로 보여줍니다. 사용자용 알림은 나오지 않습니다. 샘플 알림 3건이 들어 있습니다 |
| 읽지 않은 알림 구분하기 | ✅ | 안 읽은 알림은 왼쪽에 파란 점, 진한 제목, 연한 배경으로 표시됩니다. 읽은 알림은 점이 없고 글씨가 흐려집니다 |
| 알림 하나 읽음 처리하기 | ✅ | 알림을 누르면 그 알림이 읽음으로 바뀝니다. 다시 들어와도 읽음 상태가 유지됩니다 |
| 알림에서 상담으로 바로 가기 | ✅ | 상담과 연결된 알림을 누르면 읽음 처리와 함께 그 **상담 상세 화면**으로 이동합니다 |
| 한 번에 모두 읽음 처리하기 | ✅ | 오른쪽 위 `모두 읽음`. 관리자 알림 전부가 읽음으로 바뀌고, 상단바 종의 **빨간 점**도 사라집니다 |
| 알림 삭제하기 | 🚧 | **없습니다.** 개별 삭제도, 전체 비우기도 없습니다 |
| 종류별로 걸러 보기 | 🚧 | **없습니다** |
| 휴대폰 푸시 알림 받기 | 🚧 | **없습니다.** 이 화면에 들어와야 볼 수 있습니다 |

---

## 화면에 보이는 정보

- **제목 영역** — 화면 제목 `알림함` 은 **상단바**에 있고(모든 관리자 화면이 같은 자리), 본문에는 오른쪽 `모두 읽음` 만 있습니다
- **알림 한 줄마다**
  - 왼쪽: 안 읽음 표시 파란 점 (읽은 알림은 이 자리가 빕니다)
  - 제목 — 예: `새로운 상담 신청`, `정기 점검 안내`
  - 내용 — 예: `김민준님이 상담을 신청했어요`, `7/31 새벽 서버 점검이 예정되어 있어요`
  - 받은 시각 — 예: `2026. 7. 28. 오후 6:15` (보고 있는 컴퓨터 시간대 기준)
- **목록이 비었을 때** — `🔔` + `아직 도착한 알림이 없어요`

### 여기에 뜨는 알림은 어떤 것인가요

| 알림 | 언제 생기나요 | 누르면 |
|---|---|---|
| `새로운 상담 신청` / `OO님이 상담을 신청했어요` | 사용자가 상담 신청을 저장하면 자동으로 생깁니다 | 그 상담의 상세 화면으로 이동 |
| 운영 공지 (샘플: `정기 점검 안내`) | 지금은 샘플로 미리 들어 있습니다. 이 알림을 새로 만드는 화면은 없습니다 | 연결된 상담이 없어서 읽음 처리만 됩니다 |

**관리자가 상담 상태를 바꿀 때 생기는 `상담 상태 변경` 알림은 고객(사용자) 알림함으로 갑니다. 이 화면에는 나오지 않습니다.**

## 이 화면에서 이동할 수 있는 곳

| 어디로 | 무엇을 눌렀을 때 |
|---|---|
| 상담 상세 | 상담과 연결된 알림 |
| 직전 화면 (보통 관리자 홈) | 상단 왼쪽 `<` |

## 알아두실 것

- **⚠️ 알림이 병원별로 나뉘지 않습니다.** 알림은 아직 서버가 없어 이 브라우저에 저장되고, 이 브라우저에서 로그인한 **병원 관리자·운영자라면 누구나 같은 관리자 알림을 모두** 봅니다. 알림 내용에는 `김민준님이 상담을 신청했어요` 처럼 **고객 이름이 들어 있습니다.** 다만 알림을 눌러 들어가는 상담 상세는 따로 막혀 있어서, 다른 병원의 상담이면 `상담 정보를 찾을 수 없어요` 가 나오고 운영자에게는 이름·연락처가 가려져 보입니다. 서버가 생기면 담당 병원의 알림만 오도록 바뀌어야 합니다 ([알려진 문제](known-issues.md)).
- **휴대폰 푸시 알림이 아닙니다.** 새 상담이 들어와도 밖으로 알려주지 않고, 이 화면(또는 관리자 홈의 종 배지)을 직접 확인해야 압니다.
- **알림을 지울 수 없습니다.** 계속 쌓이기만 하고, 읽은 알림도 목록에 그대로 남습니다.
- **읽음 표시는 되돌릴 수 없습니다.** 다시 안 읽음으로 바꾸는 방법이 없습니다.
- **알림 종의 빨간 숫자는 관리자 홈에만 있습니다.** 다른 관리자 화면에서는 새 알림이 왔는지 알 수 없습니다.
- **`모두 읽음` 은 확인창 없이 즉시 전부 읽음으로 바꿉니다.**
- 상담 알림을 눌러 이동한 상담이 이미 지워졌거나 못 찾는 경우, 상담 상세 화면에 `상담 정보를 찾을 수 없어요` 가 보입니다.
- 시각은 **보고 있는 컴퓨터의 시간대**로 표시됩니다.
- 데이터는 서버가 아니라 **보고 있는 브라우저에 저장**됩니다. 다른 컴퓨터에서는 알림 목록과 읽음 상태가 다릅니다.

## 이 화면을 바꾸고 싶을 때

`docs/features/requests/_TEMPLATE.md` 를 복사해서 `docs/features/requests/` 에 요청서를 만들거나,
채팅창에 `/feature-request` 를 입력하세요.

이 화면에서 손대면 함께 확인해야 하는 것:

- **모든 관리자 화면 상단바의 종**이 이 화면의 안 읽은 개수를 봅니다. `모두 읽음` 을 누르면 빨간 점이 사라집니다. (`docs/features/admin-shell.md`)
- **사용자 알림함(`/notifications`)** 과 **같은 알림 데이터**를 쓰고, 보여줄 대상(`관리자` / `사용자`)으로만 나눠 걸러냅니다. 한쪽 화면만 고치면 다른 쪽이 어긋날 수 있습니다.
- 새 상담이 접수될 때 여기 알림이 생기고, 관리자가 상태를 바꿀 때는 **사용자 알림함**에 알림이 생깁니다. (`docs/features/admin-consultations.md`)
- 알림을 누르면 **상담 상세 화면**으로 이동합니다. (`docs/features/admin-consultation-detail.md`)
