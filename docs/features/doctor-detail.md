# 전문의 상세

> 전문의(원장님) 한 명의 경력·진료 분야·평점과 소속 병원을 보고, 그 병원에 상담을 신청하는 화면입니다.

| | |
|---|---|
| **주소** | `/doctor/:id` (예: `/doctor/d1`) |
| **누가 보나요** | 누구나 (평점 보기·상담 신청만 로그인 필요) |
| **어디서 들어오나요** | 병원 상세 화면의 `전문의 소개` 카드, 병원 탐색 화면에서 `의사` 모드로 본 전문의 카드 |
| **소스 파일** | `frontend/src/screens/doctor/[id].tsx` |

---

## 여기서 할 수 있는 일

상태 표시: ✅ 실제로 동작함 · 🟡 화면은 되지만 데이터가 샘플 · 🚧 아직 아무 일도 안 일어남 · 🔒 로그인 필요

| 할 수 있는 일 | 상태 | 지금 어떻게 동작하나요 |
|---|---|---|
| 상담 신청하기 | ✅ 🔒 | 하단 `상담 신청` 버튼 → 이 전문의가 **소속된 병원**의 상담 신청 화면으로 이동합니다. 비로그인이면 로그인 화면으로 보내고, 로그인하면 상담 신청 화면으로 바로 이어집니다. 병원이 상담을 받지 않으면 버튼이 `상담 마감`으로 바뀌고 눌리지 않습니다 (샘플 데이터에서는 `해피덴탈의원`의 `정하은 원장`이 이 경우입니다) |
| 평점 확인하기 | ✅ 🔒 | 로그인한 상태에서만 평점 숫자가 제대로 보입니다. 비로그인이면 그 자리에 흐린 막이 덮이고 `로그인하면 실제 후기를 볼 수 있어요` 문구가 나옵니다 |
| 평점 영역의 `로그인` 누르기 | ✅ | 로그인 화면으로 이동하고, 로그인하면 **이 전문의 화면으로 다시 돌아옵니다** |
| 소속 병원 보러 가기 | 🟡 | `소속 병원` 카드를 누르면 그 병원의 병원 상세 화면으로 이동합니다. 병원 정보는 샘플입니다 |
| 프로필 사진 보기 | 🟡 | 원형 프로필 사진. 실제 인물 사진이 아니라 샘플 이미지입니다. 사진을 못 불러오면 🦷 아이콘이 있는 연한 상자로 대체됩니다 |
| 주요 진료 분야 확인 | 🟡 | 이 전문의가 다루는 시술 이름들이 알약 모양 배지로 나옵니다 |
| 경력 및 활동 확인 | 🟡 | 점(•) 목록으로 나옵니다. 등록된 게 없으면 `등록된 경력 정보가 없어요` |
| 뒤로 가기 | ✅ | 화면 왼쪽 위의 동그란 화살표, 또는 그 위 상단 바의 화살표 |

## 화면에 보이는 정보

- **프로필 사진** — 원형 사진
- **이름 + 직함** — 예: `김민준 대표원장`
- **`전문의` 배지** — 관리자가 자격 검수를 **승인한** 전문의에게만 붙습니다. 검수 대기 중이거나 반려됐거나, 전공이 `일반의`인 경우에는 배지가 없습니다
- **전공 이름** — 예: `치과보철전문의`. 검수가 승인되기 전에는 이 줄이 아예 나오지 않습니다. 단 `일반의`는 검수와 무관하게 항상 표시됩니다
- **연차** — 예: `15년차`
- **후기 수 · 상담 수** — 예: `후기 180` `상담 90`
- **주요 진료 분야** — 시술 이름 배지들
- **평점 영역** — 큰 숫자 평점(예: `4.9`)과 `후기 180개 평균 평점`. 비로그인이면 흐린 막 + `로그인하면 실제 후기를 볼 수 있어요` + `로그인` 버튼
- **소속 병원** — 병원 사진, 병원 이름, 지역, 대표 시술 배지 3개까지, `★ 4.8`, `상담 90`. 소속 병원을 찾을 수 없으면 `소속 병원 정보를 찾을 수 없어요`
- **경력 및 활동** — 점 목록. 없으면 `등록된 경력 정보가 없어요`
- **하단 고정 버튼** — `상담 신청` (또는 `상담 마감`)

### 정보를 찾지 못했을 때

| 상황 | 화면 |
|---|---|
| 없는 전문의 주소로 들어옴 | `전문의 정보를 찾을 수 없어요` |
| 전문의는 있지만 소속 병원이 지워짐 | 소속 병원 자리에 `소속 병원 정보를 찾을 수 없어요`, 하단 버튼은 `상담 마감`으로 눌리지 않습니다 |

## 이 화면에서 이동할 수 있는 곳

| 어디로 | 무엇을 눌렀을 때 |
|---|---|
| 상담 신청 | 하단 `상담 신청` |
| 병원 상세 | `소속 병원` 카드 |
| 로그인 | 평점 영역의 `로그인` 버튼, 또는 비로그인 상태에서 `상담 신청` |
| 직전 화면 | 왼쪽 위 화살표 |

## 알아두실 것

- **전문의·병원 데이터는 모두 샘플입니다.** 실제 의료인이 아니고, 서버도 아직 연결되지 않았습니다. 데이터는 브라우저에 저장되므로 다른 컴퓨터에서는 다르게 보일 수 있습니다.
- **평점 잠금을 풀어도 후기 글은 나오지 않습니다.** 문구는 `로그인하면 실제 후기를 볼 수 있어요` 라고 되어 있지만, 로그인하면 평점 숫자만 드러납니다. 이 화면에는 후기 목록 자체가 없습니다.
- **비로그인 상태의 잠금은 진짜 흐림 효과가 아닙니다.** 반투명한 흰 막을 덮어둔 것이라 평점 숫자가 뒤에 희미하게 보일 수 있습니다.
- **이 화면에는 찜하기(하트)가 없습니다.** 찜은 병원 단위로만 할 수 있어서, 전문의를 찜해두려면 병원 상세 화면으로 가야 합니다.
- **상담 신청은 전문의가 아니라 병원으로 갑니다.** 여기서 `상담 신청`을 누르면 소속 병원의 상담 신청 화면이 열리고, **어느 전문의를 보고 눌렀는지는 신청 내용에 남지 않습니다.** 신청서에는 병원과 시술만 기록됩니다. "이 원장님께 상담받고 싶다"를 전하려면 신청서의 `남기고 싶은 말 (선택)` 칸에 직접 적어야 합니다.
- **`전문의` 배지와 전공 이름이 안 보인다고 고장난 게 아닙니다.** 관리자의 `전문의 인증 검수`에서 승인되지 않은 전문의는 일부러 전공을 숨깁니다. 샘플 데이터에서는 `이서연 원장`(검수 대기), `박도윤 원장`(반려)이 이 경우입니다.
- **화면 위쪽에 뒤로 가기 화살표가 두 개 있습니다.** 회색 상단 바의 화살표와, 그 아래 동그란 회색 원 안의 화살표. 둘 다 같은 동작(직전 화면으로 이동)을 합니다. 의도한 모양인지는 아직 확정되지 않았습니다.
- **주요 진료 분야가 등록되지 않은 전문의는 `주요 진료 분야` 제목만 남고 아래가 빈 채로 보입니다.** "없어요" 같은 안내 문구가 나오지 않습니다.
- 상담 수·후기 수·평점은 실제 집계가 아니라 샘플로 넣어둔 고정 숫자입니다. 상담을 신청해도 이 숫자는 올라가지 않습니다.

## 이 화면을 바꾸고 싶을 때

`docs/features/requests/_TEMPLATE.md` 를 복사해서 `docs/features/requests/` 에 요청서를 만들거나,
채팅창에 `/feature-request` 를 입력하세요.

이 화면에서 손대면 함께 확인해야 하는 것:

- **전문의 데이터**는 관리자 화면의 `병원 정보 수정`(의료진 추가/수정/삭제)과 `전문의 인증 검수`(승인/반려)에서 바뀝니다. 여기 표시가 이상하면 관리자에서 수정된 값일 수 있습니다.
- **`전문의` 배지와 전공 표시 규칙**은 병원 상세의 `전문의 소개`, 병원 탐색의 병원·전문의 카드에서도 똑같이 쓰입니다. 한쪽만 바꾸면 어긋납니다.
- **`상담 신청` / `상담 마감` 버튼 규칙**은 병원 상세 화면의 하단 버튼과 같은 규칙(병원의 상담 접수 여부)을 씁니다.
- **소속 병원 카드**는 병원 데이터를 읽어옵니다. 병원 이름·지역·평점 표시를 바꾸려면 병원 쪽과 함께 봐야 합니다.
