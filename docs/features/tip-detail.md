# 시술 꿀팁 상세

> 시술에 대해 알아두면 좋은 정보 글 한 편을 읽고, 그 시술을 하는 병원으로 넘어가는 화면입니다.

| | |
|---|---|
| **주소** | `/tips/:id` (예: `/tips/g1`) |
| **누가 보나요** | 누구나 (관련 병원 찜하기만 로그인 필요) |
| **어디서 들어오나요** | 홈 화면 `이런 꿀팁 어때요?` 영역의 꿀팁 카드 |
| **소스 파일** | `frontend/src/screens/tips/[id].tsx` |

## 여기서 할 수 있는 일

상태 표시: ✅ 실제로 동작함 · 🟡 화면은 되지만 데이터가 샘플 · 🚧 아직 아무 일도 안 일어남 · 🔒 로그인 필요

| 할 수 있는 일 | 상태 | 지금 어떻게 동작하나요 |
|---|---|---|
| 꿀팁 본문 읽기 | 🟡 | 글이 문단 단위로 나뉘어 표시됩니다. 샘플 꿀팁 8편이 미리 들어있습니다 |
| 큰 사진 보기 | 🟡 | 글 맨 위에 대표 사진 한 장. 인터넷에서 가져오는 샘플 사진입니다. 못 불러오면 사진 자리에 🦷 표시가 나타납니다 |
| 관련 병원 보기 | 🟡 | 이 꿀팁에 병원이 연결되어 있을 때만 `관련 병원 보기` 영역이 나타납니다. 병원 카드를 누르면 병원 상세로 갑니다 |
| 관련 병원 찜하기 / 찜 해제 | ✅ 🔒 | 병원 카드 오른쪽 위 하트. 누르면 🤍 ↔ ❤️ 로 바뀌고 마이페이지 찜 목록에 반영됩니다. 비로그인이면 로그인 화면으로 보냅니다 |
| 관련 시술 병원 상담받기 | ✅ | 화면 맨 아래 고정된 버튼. 누르면 **병원 탐색 화면**으로 이동하면서 이 꿀팁의 시술 카테고리로 걸러진 병원 목록을 보여줍니다 |
| 뒤로 가기 | ✅ | 본문 위쪽 동그란 회색 화살표 버튼, 또는 헤더 왼쪽 화살표 |
| 좋아요 · 스크랩 · 공유 | 🚧 | 없습니다 |
| 꿀팁 쓰기 · 고치기 | 🚧 | 없습니다 (관리자 화면에도 없습니다) |

## 화면에 보이는 정보

- **동그란 뒤로 가기 버튼** — 회색 원 안에 `‹` 화살표
- **대표 사진** — 화면 폭에 꽉 차는 높이 200 정도의 사진
- **시술 배지** — 예: `임플란트`
- **제목** — 굵은 큰 글씨
- **작성자 · 작성일** — `몰라몰라 편집팀 · 2026-06-02` 형태
- **본문** — 빈 줄로 구분된 문단마다 간격을 두고 표시됩니다
- **`관련 병원 보기`** — 이 꿀팁에 연결된 병원 카드들. 연결된 병원이 없으면 이 영역 자체가 나타나지 않습니다
- **하단 고정 버튼** — `관련 시술 병원 상담받기`

### 없는 꿀팁 주소로 들어왔을 때

| 상황 | 화면 |
|---|---|
| 없는 꿀팁 주소 | `꿀팁 정보를 찾을 수 없어요` 한 줄만 표시 |

### 미리 들어있는 샘플 꿀팁 8편

| 제목 | 시술 |
|---|---|
| `임플란트 통증, 얼마나 아플까?` | 임플란트 |
| `투명교정 vs 일반교정 차이점` | 교정 |
| `라미네이트 전 꼭 확인할 것` | 라미네이트 |
| `코골이장치, 수면다원검사부터 시작하세요` | 코골이장치 |
| `충치 방치하면 생기는 일` | 충치치료 |
| `스케일링 얼마나 자주 해야 할까?` | 잇몸치료 |
| `사랑니, 꼭 발치해야 할까?` | 사랑니 |
| `크라운과 인레이, 어떤 차이가 있을까?` | 크라운 |

8편 모두 작성자가 `몰라몰라 편집팀` 이고, 관련 병원이 2~3곳씩 연결되어 있습니다.

## 이 화면에서 이동할 수 있는 곳

| 어디로 | 무엇을 눌렀을 때 |
|---|---|
| 병원 상세 | `관련 병원 보기` 의 병원 카드 |
| 병원 탐색 (이 꿀팁의 시술로 걸러진 목록) | 하단 `관련 시술 병원 상담받기` |
| 로그인 | 비로그인 상태로 병원 카드의 하트 |
| 이전 화면 | 동그란 뒤로 가기 버튼 또는 헤더 왼쪽 화살표 |

## 알아두실 것

- **꿀팁 8편은 고정된 샘플 글입니다.** 화면에서 꿀팁을 새로 쓰거나 고치거나 지우는 기능이 없고, 관리자 화면에도 없습니다. 글을 바꾸려면 개발자가 데이터를 직접 수정해야 합니다.
- **꿀팁은 브라우저에 저장되는 데이터가 아닙니다.** 다른 병원·상담·질문 데이터와 달리 코드 안에 들어있어서, 브라우저 데이터를 지워도 8편이 그대로 남습니다. 반대로 어떤 컴퓨터에서 봐도 똑같이 8편입니다.
- **화면 위쪽에 뒤로 가기 화살표가 두 개 보입니다.** 헤더의 화살표와 본문 안 동그란 버튼이 겹칩니다. 둘 다 같은 동작(이전 화면으로)을 합니다. 의도한 모양인지는 아직 확정되지 않았습니다.
- **헤더 제목이 비어 있습니다.** 다른 화면처럼 상단에 화면 이름(`꿀팁` 등)이나 글 제목이 나오지 않습니다.
- **하단 버튼은 상담을 신청하는 버튼이 아닙니다.** `관련 시술 병원 상담받기` 를 누르면 상담 신청 폼이 아니라, 해당 시술을 하는 병원 목록(병원 탐색 화면)으로 이동합니다. 실제 상담 신청은 병원을 고른 뒤 병원 상세에서 합니다.
- **`관련 병원 보기` 는 꿀팁에 병원이 연결된 경우에만 나타납니다.** 지금 샘플 8편은 모두 연결되어 있어서 늘 보입니다. 연결된 병원이 병원 목록에 없으면 그 카드만 조용히 빠집니다.
- **관련 병원 카드에 붙는 배지·가격·평점은 모두 샘플입니다.** 실제 병원이 아닙니다.
- **사진은 인터넷(무료 사진 사이트)에서 가져옵니다.** 인터넷이 끊겨 있거나 사이트가 막혀 있으면 사진 대신 🦷 아이콘이 들어간 연한 상자가 보입니다. 실제 서비스에서는 병원이 제공한 실제 사진으로 바꿔야 하는 임시 사진입니다.
- 본문은 **빈 줄을 기준으로 문단을 나눕니다.** 제목·목록·표·이미지 같은 서식은 지원하지 않고, 문단으로 된 글만 표시됩니다.

## 이 화면을 바꾸고 싶을 때

`docs/features/requests/_TEMPLATE.md` 를 복사해서 `docs/features/requests/` 에 요청서를 만들거나,
채팅창에 `/feature-request` 를 입력하세요.

이 화면에서 손대면 함께 확인해야 하는 것:

- **홈 화면 `이런 꿀팁 어때요?` 의 카드**와 같은 꿀팁 데이터를 씁니다. 제목·요약·사진을 바꾸면 홈 화면 카드도 함께 바뀝니다.
- **`관련 병원 보기` 의 병원 카드**는 홈·병원 탐색·마이페이지 찜 목록에서 쓰는 것과 **같은 병원 카드**입니다. 카드 모양을 바꾸면 그쪽도 모두 바뀝니다.
- **찜하기**는 마이페이지 찜 목록과 같은 데이터를 씁니다.
- **하단 버튼이 넘겨주는 시술 카테고리**는 병원 탐색 화면의 카테고리 탭과 같은 목록을 씁니다. 시술 이름·목록을 바꾸면 양쪽을 함께 확인해야 합니다.
