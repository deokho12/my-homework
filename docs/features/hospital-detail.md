# 병원 상세

> 병원 한 곳의 사진·가격·진료시간·의료진·후기·문의를 자세히 보고, 상담을 신청하거나 궁금한 점을 물어보거나 찜해두는 화면입니다.

| | |
|---|---|
| **주소** | `/hospital/:id` (예: `/hospital/h1`) |
| **누가 보나요** | 누구나 (상담 신청·찜하기만 로그인 필요) |
| **어디서 들어오나요** | 홈·병원 탐색·검색 결과의 병원 카드, 마이페이지 찜 목록, 시술 팁 화면의 추천 병원 |
| **소스 파일** | `frontend/src/pages/HospitalDetailPage.tsx` (조회) + `frontend/src/features/hospital/components/HospitalDetailView.tsx` (화면) |

---

## 여기서 할 수 있는 일

상태 표시: ✅ 실제로 동작함 · 🟡 화면은 되지만 데이터가 샘플 · 🚧 아직 아무 일도 안 일어남 · 🔒 로그인 필요

| 할 수 있는 일 | 상태 | 지금 어떻게 동작하나요 |
|---|---|---|
| 병원 사진 넘겨보기 | 🟡 | 좌우로 스와이프해서 넘깁니다. 사진은 샘플 이미지입니다 |
| 병원 상담 신청하기 | ✅ 🔒 | 하단 `병원 상담신청` 버튼 → 상담 신청 화면으로 이동. 비로그인이면 로그인 화면으로 보내고, 로그인 후 원래 자리로 돌아옵니다. 병원이 상담을 받지 않으면 버튼이 `상담 마감`으로 바뀌고 눌리지 않습니다 |
| 특정 전문의에게 상담 신청하기 | ✅ 🔒 | 의료진 카드의 `전문의 상담신청` 버튼 |
| 병원 찜하기 / 찜 해제 | ✅ 🔒 | **화면 맨 아래 버튼 줄 왼쪽 끝**의 하트(상담신청 버튼 옆). 누르면 빈 하트 ↔ 채워진 분홍 하트로 바뀌고, 새로고침해도 유지됩니다. 마이페이지 찜 목록, 병원 탐색·시술 카테고리 카드의 하트와 **같은 상태**입니다 |
| 진료시간 펼쳐보기 | ✅ | 오늘 요일이 먼저 접힌 상태로 보이고, 누르면 한 주 전체가 펼쳐집니다. 다시 누르면 `접기` |
| 주소 복사하기 | ✅ | `주소복사` 버튼 → `주소가 복사되었어요` 안내 |
| 지도로 위치 보기 | 🟡 | `지도보기` 버튼 → 지도 창이 열립니다. **카카오맵 API 키가 설정되지 않으면 지도 대신 안내 문구가 표시됩니다** |
| 의료진 상세 보기 | 🟡 | 의료진 카드를 누르면 전문의 상세 화면으로 이동 |
| 후기 읽기 | 🟡 | 사진과 함께 표시됩니다. 후기를 새로 쓰는 기능은 없습니다 |
| 진행중인 이벤트 보기 | 🟡 | 병원에 등록된 이벤트가 있을 때만 이 영역이 나타납니다 |
| 목차로 건너뛰기 | ✅ | 헤더 아래에 `정보` `시술·가격` `의료진` `후기` `문의` 다섯 칸이 가로로 붙어 있고, 누르면 그 자리로 스크롤합니다. 스크롤해도 화면 위에 붙어 따라옵니다 (활성 표시는 없습니다 — 탭이 아니라 건너뛰기 바입니다) |
| 공개 Q/A 읽기 | ✅ | `문의` 섹션에 다른 환자의 질문과 병원 답변이 `Q`/`A` 로 보입니다. **공개로 남겼고 병원이 공개로 답한 것만** 보입니다. 처음에는 3건, `문의 더보기 (n)` 로 나머지를 펼칩니다 |
| 문의하기 | ✅ 🔒 | `문의` 섹션 오른쪽의 `문의하기` 버튼 → [문의하기 화면](inquiry.md). 비로그인이면 로그인 화면으로 보내고, 로그인 후 그 화면으로 돌아옵니다 |

## 화면에 보이는 정보

- **사진 캐러셀** — 병원 사진 여러 장
- **이름 · 주소 · 평점 · 후기 수** — 예: `★ 4.8 (312)`
- **배지** — 추천 병원이면 `추천 병원`, 광고 계약 중이면 `광고`
- **할인 배너** — 진행중인 할인이 있으면 헤더(목차 위)에 할인율·할인가·원가(취소선)
- **목차 바** — `정보` `시술·가격` `의료진` `후기` `문의`
- **`가격대`** — 할인이 없는 병원은 `시술 · 가격` 섹션 맨 위에 최저~최고 금액이 보입니다 (할인 배너가 있으면 같은 값을 두 번 적지 않습니다)
- **대표 시술** — 이 병원이 하는 시술을 **분야별로 묶어서** 보여줍니다. 회색 작은 글씨로 분야 이름(`충치치료`)이 나오고 그 아래에 세부 시술 알약(`레진` `크라운`)이 붙습니다. 분야가 여럿이면 여러 묶음이 세로로 쌓입니다. 등록된 시술이 하나도 없으면 `등록된 시술 정보가 없어요`
- **진료시간** — 오늘 요일을 강조. 등록된 정보가 없으면 `등록된 진료시간 정보가 없어요`
- **위치** — 주소, 주소복사·지도보기 버튼, `찾아오시는 길` 안내 (등록된 경우에만)
- **병원 소개**
- **병원 특징** — 해당하는 것만 배지로 표시. 하나도 없으면 `등록된 병원 특징이 없어요`
  - `⚡ 원데이가능` — 다른 배지와 **출처가 다릅니다.** 관리자 폼의 `원데이 진료 가능 여부 (당일 보철 등)` 체크박스에서 옵니다
  - `전담코디네이터` `무통마취` `디지털진료` `주차가능` `야간상담` `CCTV설치` — 관리자 폼의 `병원 특징` 체크박스 6개에서 옵니다
- **전문의 소개** — 의료진 목록. 인증된 전문의는 `전문의` 배지. 없으면 `등록된 의료진 정보가 없어요`
- **진행중인 이벤트** — 있을 때만
- **방문자 후기** — 없으면 `아직 등록된 후기가 없어요`
- **문의** — 제목 줄에 `문의 N건 · 답변 N` 과 `문의하기` 버튼. 아래에 공개된 질문·답변이 `Q`/`A` 로 쌓입니다. 질문마다 `10/5 답변` 처럼 답변 날짜가 붙고 **작성자 이름은 보이지 않습니다.** 하나도 없으면 `아직 공개된 문의가 없어요 / 궁금한 점을 먼저 물어보세요`
- **하단 고정 버튼** — 병원 상담신청 (문의하기는 여기 없고 `문의` 섹션 안에 있습니다)

### 섹션 순서

목차 순서가 곧 화면 순서입니다.

| 목차 | 그 안에 들어 있는 것 |
|---|---|
| 정보 | 진료시간 · 위치(주소복사·지도보기) · 찾아오시는 길 · 병원 소개 · 병원 특징 |
| 시술·가격 | 가격대 · 대표 시술 · 진행중인 이벤트 |
| 의료진 | 전문의 소개 |
| 후기 | 방문자 후기 |
| 문의 | 공개 Q/A + `문의하기` |

### 정보를 불러오는 중이거나 실패했을 때

| 상황 | 화면 |
|---|---|
| 불러오는 중 | 잠깐 빈 화면. 0.2초 이상 걸리면 회전하는 표시가 나타납니다 (지금은 워낙 빨라서 거의 안 보입니다) |
| 없는 병원 주소로 들어옴 | `병원 정보를 찾을 수 없어요` |

## 알아두실 것

- **병원·의료진·후기·이벤트 데이터는 모두 샘플입니다.** 실제 병원이 아니고, 서버도 아직 연결되지 않았습니다. 데이터는 브라우저에 저장되므로 다른 컴퓨터에서는 다르게 보입니다.
- **상담을 신청해도 실제로 병원에 연락이 가지는 않습니다.** 신청 내용은 저장되고 관리자 화면의 상담 목록에 나타납니다.
- **후기를 작성하는 기능은 없습니다.** 읽기만 됩니다.
- **`대표 시술` 의 이름이 관리자가 고른 이름과 같습니다.** 서버에 저장된 이름(`충치치료`)이 아니라 세부 시술 이름(`레진`)으로 보입니다. 위쪽 회색 글씨가 분야(`충치치료`), 아래 알약이 세부 시술(`레진`)입니다.
- **`대표 시술` 의 분야 순서는 고정입니다** (임플란트 → 스케일링·예방 → 교정 → 충치치료 → 심미 → 잇몸치료 → 턱관절·스플린트 → 보톡스 → 사랑니·발치). 병원이 등록한 순서가 아닙니다.
- **지도는 카카오맵 API 키가 있어야 보입니다.** 키가 없으면 지도 자리에 안내 문구가 표시됩니다.
- 로딩·에러·`찾을 수 없어요` 화면이 **세로 중앙이 아니라 상단에 붙어** 보입니다. 의도한 모양인지는 아직 확정되지 않았습니다.
- 화면 폭이 좁을 때(430px 정도) 평점 오른쪽과 `지도보기` 버튼이 살짝 잘려 보일 수 있습니다.
- **`문의` 섹션의 두 숫자는 세는 대상이 다릅니다.** `문의 N건` 은 **환자가 공개로 남긴** 문의 수(아직 답이 없는 것도 포함)이고, `답변 N` 은 그중 **실제로 아래에 보이는** Q/A 수입니다. 둘의 차이가 "공개로 물었는데 아직 답이 없는 수" 입니다. 비공개 문의는 어느 숫자에도 들어가지 않습니다.
- **공개 Q/A 에는 작성자 표기가 아예 없습니다.** 닉네임도 `익명` 도 넣지 않습니다.
- **문의는 아직 샘플 데이터가 없습니다.** 직접 남겨 보기 전까지 모든 병원이 `아직 공개된 문의가 없어요` 입니다.
- 마이페이지 `내 문의` 에서 `병원 상세 보기 ›` 로 들어오면 **전문의·후기 영역이 다 불러와진 뒤 문의 섹션으로 바로 내려갑니다.**

## 이 화면을 바꾸고 싶을 때

`docs/features/requests/_TEMPLATE.md` 를 복사해서 `docs/features/requests/` 에 요청서를 만들거나,
채팅창에 `/feature-request` 를 입력하세요.

이 화면에서 손대면 함께 확인해야 하는 것:

- **찜하기**는 마이페이지의 찜 목록, 병원 탐색·시술 카테고리 카드의 하트와 같은 데이터·같은 버튼 컴포넌트(`frontend/src/features/favorite/components/FavoriteHeartButton.tsx`)를 씁니다.
- **상담 신청 버튼**은 상담 신청 화면으로만 연결됩니다. 실제 저장은 그 화면에서 일어납니다.
- **병원 정보**는 관리자 화면에서 수정할 수 있습니다. 여기 표시가 이상하면 관리자에서 수정된 값일 수 있습니다.
- 병원 카드(홈·탐색·검색)와 이 화면은 **같은 병원 데이터**를 씁니다. 한쪽만 바꾸면 어긋납니다.
- **`대표 시술` 의 분야·세부 시술 이름**은 [시술 카테고리 화면](category.md)·홈의 `시술로 찾기`·관리자 병원 폼과 같은 목록(`frontend/src/features/procedure/taxonomy.ts`)입니다.
- **`문의` 섹션에 무엇이 보일지는 병원 관리자의 선택에 달려 있습니다.** 관리자 [문의 화면](admin-inquiries.md)에서 공개로 답한 건만 올라옵니다. 공개 판정은 코드 한 곳(`frontend/src/features/inquiry/inquiryVisibility.ts`)에 있고, 관리자 화면의 `공개/비공개` 표기도 같은 함수를 씁니다.
- **목차와 섹션 순서는 한 곳(`HospitalDetailView.tsx` 의 `TOC`)에서 나옵니다.** 섹션을 추가·이동하면 목차도 함께 바뀌어야 합니다.
