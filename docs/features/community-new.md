# 커뮤니티 질문 작성

> 커뮤니티에 새 질문을 올리는 화면입니다. 관련 시술을 고르고 제목과 내용을 적어 등록합니다.

| | |
|---|---|
| **주소** | `/community/new` |
| **누가 보나요** | 누구나 (로그인하지 않아도 등록됩니다) |
| **어디서 들어오나요** | 커뮤니티 탭(`/community`) 오른쪽 위 `질문하기` 버튼 |
| **소스 파일** | `frontend/src/screens/community/new.tsx` |

---

## 여기서 할 수 있는 일

상태 표시: ✅ 실제로 동작함 · 🟡 화면은 되지만 데이터가 샘플 · 🚧 아직 아무 일도 안 일어남 · 🔒 로그인 필요

| 할 수 있는 일 | 상태 | 지금 어떻게 동작하나요 |
|---|---|---|
| 관련 시술 고르기 | ✅ | 시술 13개가 알약 모양 버튼(칩)으로 쭉 나열됩니다. 누르면 그 시술만 브랜드색으로 채워집니다. 처음 들어오면 `🦷 임플란트` 가 이미 선택되어 있고, 한 번에 하나만 고를 수 있습니다 |
| 제목 입력 | ✅ | 한 줄 입력칸. 안내 문구는 `궁금한 점을 한 줄로 요약해주세요` |
| 내용 입력 | ✅ | 여러 줄 입력칸(기본 높이 6줄 정도). 안내 문구는 `상황을 자세히 설명할수록 더 정확한 답변을 받을 수 있어요` |
| 질문 등록하기 | ✅ | `질문 등록하기` 버튼을 누르면 질문이 저장되고 **바로 이전 화면(보통 커뮤니티 목록)으로 돌아갑니다.** 새 질문이 목록 맨 위에 나타납니다 |
| 사진 · 파일 첨부 | 🚧 | 없습니다 |
| 임시저장 · 미리보기 | 🚧 | 없습니다 |

---

## 무엇을 입력받고, 무엇을 검사하나요

| 입력 항목 | 필수 | 검사 내용 |
|---|---|---|
| 관련 시술 | 필수 | 항상 하나가 선택된 상태입니다. 선택을 해제할 수 없어서 따로 검사할 것이 없습니다 |
| 제목 | 필수 | 앞뒤 공백을 뺀 뒤 한 글자 이상이어야 합니다 |
| 내용 | 필수 | 앞뒤 공백을 뺀 뒤 한 글자 이상이어야 합니다 |

- 제목과 내용 중 하나라도 비어 있으면 `질문 등록하기` 버튼이 **흐리게 보이고 눌리지 않습니다.** 빨간 경고 문구가 뜨는 방식이 아니라, 버튼이 눌리지 않는 방식으로 막습니다.
- **글자 수 상한이 없습니다.** 아무리 길게 써도 등록됩니다.
- 욕설·스팸·중복 글 검사는 없습니다.
- 로그인 여부를 확인하지 않습니다.

---

## 등록하면 무슨 일이 일어나나요

1. 제목과 내용의 앞뒤 공백을 잘라내고 질문을 저장합니다.
2. 이때 함께 정해지는 값:
   - **작성자 이름** — 언제나 `익명` 으로 고정됩니다. 로그인한 사람의 이름이나 이메일을 쓰지 않습니다
   - **작성일** — 등록한 날의 날짜 (`2026-08-12` 같은 형태, 시간은 저장하지 않습니다)
   - **조회수** — 0
   - **답변** — 0개
3. 새 질문이 커뮤니티 목록 **맨 위**에 놓입니다.
4. 화면은 곧바로 이전 화면으로 돌아갑니다. `등록되었습니다` 같은 확인 메시지나 안내창은 나타나지 않습니다.
5. 저장된 질문은 브라우저에 남으므로 새로고침해도 그대로 있습니다.

| 어디로 | 무엇을 눌렀을 때 |
|---|---|
| 이전 화면 (보통 커뮤니티 목록) | `질문 등록하기` — 등록 후 자동으로 돌아갑니다 |
| 이전 화면 | 헤더 왼쪽 `‹` 뒤로 가기 화살표 (이때는 저장되지 않습니다) |

## 알아두실 것

- **로그인하지 않아도 질문이 등록됩니다.** 다른 화면(찜하기, 상담 신청)과 달리 로그인을 요구하지 않습니다. 의도한 동작인지는 확인이 필요합니다. **(확인 필요)**
- **작성자는 항상 `익명` 입니다.** 로그인한 사람의 이름이나 닉네임이 붙지 않습니다. 그래서 "내가 쓴 질문"을 골라내는 방법도 지금은 없습니다.
- **등록 후 확인 메시지가 없습니다.** 버튼을 누르면 아무 안내 없이 곧바로 이전 화면으로 넘어갑니다. 등록이 안 된 것처럼 보일 수 있지만, 목록 맨 위를 보시면 들어와 있습니다.
- **등록한 질문에는 답변이 달릴 수 없습니다.** 답변을 쓰는 화면이 아직 없어서, 직접 올린 질문은 계속 `아직 답변이 없어요` 상태로 남습니다.
- **데이터가 브라우저에 저장됩니다.** 다른 컴퓨터나 시크릿 창에서는 내가 올린 질문이 보이지 않고, 브라우저 데이터를 지우면 사라집니다. 서버에 올라가지 않습니다.
- **뒤로 가면 입력한 내용이 사라집니다.** 임시저장이 없어서 다시 들어오면 빈 칸에서 시작합니다.
- **시술은 반드시 하나가 선택됩니다.** "시술 안 고름" 이나 "기타" 를 선택할 수 없고, 처음 화면에서는 `🦷 임플란트` 가 이미 선택되어 있습니다. 시술을 고르지 않고 올린 것처럼 보이는 질문이 나올 수 없다는 뜻입니다.
- 주소창에 `/community/new` 를 직접 입력해 새 탭에서 열고 등록하면, 돌아갈 이전 화면이 없어서 화면이 그 자리에 머무를 수 있습니다. 질문 자체는 저장됩니다. **(확인 필요 — 브라우저 방문 기록 상황에 따라 다릅니다)**

## 이 화면을 바꾸고 싶을 때

`docs/features/requests/_TEMPLATE.md` 를 복사해서 `docs/features/requests/` 에 요청서를 만들거나,
채팅창에 `/feature-request` 를 입력하세요.

이 화면에서 손대면 함께 확인해야 하는 것:

- **커뮤니티 목록과 질문 상세**(`docs/features/community-post.md`)가 여기서 저장한 질문을 그대로 보여줍니다. 입력 항목을 늘리거나 줄이면 두 화면의 표시도 함께 확인해야 합니다.
- **시술 칩 13개**는 앱 전체가 공유하는 시술 목록에서 옵니다. 시술을 추가·삭제하면 여기 칩도, 홈 화면의 시술 카테고리와 병원 탐색 화면의 카테고리 탭도 같이 바뀝니다.
- **작성자 이름을 `익명` 대신 로그인한 사람의 이름으로 바꾸려면** 로그인 상태를 확인하는 처리(비로그인일 때 어떻게 할지)도 함께 정해야 합니다.
