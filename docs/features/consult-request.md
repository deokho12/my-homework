# 상담 신청

> 병원 한 곳에 상담을 신청하는 화면입니다. 희망 시술·희망 연락 시간·이름·연락처를 남기고 개인정보 제3자 제공에 동의하면 접수되고, 같은 화면이 접수 완료 화면으로 바뀝니다.

| | |
|---|---|
| **주소** | `/consult/:hospitalId` (예: `/consult/h1`) |
| **누가 보나요** | 로그인한 사용자만 |
| **어디서 들어오나요** | 병원 상세의 `병원 상담신청`, 병원 탐색 카드와 지도 목록의 상담 신청 버튼, 전문의 상세 화면 |
| **소스 파일** | `frontend/src/pages/ConsultRequestPage.tsx` (폼·동의 팝업·완료 화면은 `frontend/src/features/consult/components/`, 동의 안내문은 `frontend/src/features/consult/content/thirdPartyConsentNotice.ts`) |

## 여기서 할 수 있는 일

상태 표시: ✅ 실제로 동작함 · 🟡 화면은 되지만 데이터가 샘플 · 🚧 아직 아무 일도 안 일어남 · 🔒 로그인 필요

| 할 수 있는 일 | 상태 | 지금 어떻게 동작하나요 |
|---|---|---|
| 희망 시술 고르기 | ✅ | 그 병원이 등록한 시술이 `충치치료 · 레진` 처럼 `대분류 · 세부시술` 알약 버튼으로 나옵니다. 맨 마지막 `잘 모르겠어요` 가 **처음부터 선택**되어 있고, 하나만 고를 수 있습니다 |
| 희망 연락 시간 고르기 | ✅ | `평일 오전` `평일 오후` `평일 저녁` `주말` 네 개가 2열 버튼으로 나오고, 처음에는 `평일 오전`이 선택되어 있습니다 |
| 이름 입력 | ✅ | **로그인한 계정의 이름이 자동으로 채워집니다.** 고칠 수 있고, 고치면 아래 안내 문구가 사라집니다 |
| 연락처 입력 | ✅ | **내가 지난번에 상담 신청하며 쓴 번호가 자동으로 채워집니다** (처음 신청하는 계정이면 빈칸). 휴대폰 번호 형식을 검사합니다 |
| 남기고 싶은 말 입력 | ✅ | 여러 줄 입력 칸. 비워둬도 됩니다 (2000자까지) |
| 제3자 제공 동의하기 | ✅ | `[필수] 개인정보 제3자 제공 동의` 체크박스. **화면에 들어올 때마다 꺼진 상태로 시작**하고, 켜야만 신청 버튼이 활성화됩니다 |
| 동의 내용 `자세히` 보기 | ✅ | 앱 안 팝업으로 제공받는 자·목적·항목·보유 기간·거부 권리 5개 항목을 보여줍니다. 읽기 전용이라 `확인` 을 눌러도 체크박스가 켜지지 않습니다 |
| 상담 신청하기 | ✅ 🔒 | 이름·연락처·동의가 모두 채워졌을 때만 눌립니다. 누르면 같은 주소에서 **완료 화면**으로 바뀌고, 신청 내용은 저장되어 관리자의 `상담 예약` 목록 맨 위에 `신규` 상태로 나타납니다 |
| 완료 화면에서 `내 상담 내역 보기` | ✅ | 마이페이지의 `상담 내역` 탭으로 이동하고, 방금 신청한 건이 `신규` 로 맨 위에 보입니다 (뒤로 가기로 방금 보낸 폼에 돌아오지 않도록 화면을 바꿔치기합니다) |
| 완료 화면에서 `병원 상세로 돌아가기` | ✅ | 방금 신청한 병원의 상세 화면으로 돌아갑니다 (같은 이유로 화면을 바꿔치기합니다) |
| 접수에 실패했을 때 `다시 시도` | ✅ | 화면 맨 위 안내의 버튼. 입력한 내용 그대로 한 번 더 보냅니다 |
| 뒤로 가기 | ✅ | 화면 위쪽 `‹` 화살표 |

## 화면에 보이는 정보

- **화면 제목** — 위쪽 헤더에 `상담 신청`
- **접수 실패 안내** — 실패했을 때만 맨 위에 (아래 "특별한 상황일 때")
- **병원 요약 카드** — 병원 이름 + `지역 · 주소`
- **카드 3장** — 입력 칸이 세 묶음으로 나뉘어 있습니다 (2026-10-23 시안 A)
  - `상담 내용` — 희망 시술 / 희망 연락 시간
  - `연락받을 정보` — 이름 / 연락처 / 남기고 싶은 말 (`0 / 2000` 글자 수)
  - 동의 카드 — `[필수] 개인정보 제3자 제공 동의`, `상담 연락을 위해 이름과 연락처를 ○○치과에 제공해요.`, `자세히`
- **하단 고정 바의 `상담 신청하기` 버튼** — 화면 아래에 붙어 있어 끝까지 스크롤하지 않아도 보입니다. 조건을 채우기 전에는 흐리게 보이고 눌리지 않으며, 그때는 버튼 **위**에 `이름 · 연락처 · 동의를 모두 채우면 신청할 수 있어요` 한 줄이 보입니다

### 입력 칸별로 지금 무엇을 검사하나요

| 입력 칸 | 필수인가요 | 안내 문구(placeholder) | 지금 실제로 검사하는 것 | 검사하지 않는 것 |
|---|---|---|---|---|
| 희망 시술 | 선택 | — | 없음 (고르지 않은 `잘 모르겠어요` 가 정상 경로이자 기본값입니다) | 그 병원이 정말 그 시술을 하는지는 서버가 볼 몫입니다 (서버가 아직 없습니다) |
| 희망 연락 시간 | 사실상 필수 | — | 네 개 중 하나인지 (항상 하나가 선택되어 있습니다) | 그 병원이 실제로 그 시간에 진료하는지는 보지 않습니다 |
| 이름 | 필수 | `이름을 입력해주세요` | 앞뒤 공백을 뺀 뒤 1자 이상 50자 이하 | 한글/영문 여부, 특수문자 |
| 연락처 | 필수 | `010-0000-0000` | **휴대폰 번호 형식** `01[016789]` 로 시작하고 가운데 3~4자리, 끝 4자리. 하이픈은 있어도 없어도 됩니다 (`01012345678`, `010-1234-5678` 모두 통과) | 실제로 쓰는 번호인지, 본인 번호인지 (인증 절차가 없습니다) |
| 남기고 싶은 말 (선택) | 선택 | `궁금한 점이나 요청사항을 적어주세요` | 2000자 이하 | 내용 |
| 제3자 제공 동의 | 필수 | — | 체크되어 있는지 | — |

즉 **`상담 신청하기` 버튼이 켜지는 조건은 "이름이 공백이 아니고 + 연락처가 휴대폰 번호 형식이고 + 동의가 켜져 있을 것"** 입니다.

연락처·이름 오류 문구는 **그 칸을 한 번 벗어난 뒤에야** 보입니다 (아직 다 쓰지도 않은 번호를 틀렸다고 말하지 않기 위해서입니다). 한 번 보이고 나면 글자를 고칠 때마다 다시 판단해서, 올바른 형식이 되는 순간 사라집니다.

| 상황 | 보이는 문구 |
|---|---|
| 연락처가 비어 있음 | `연락처를 입력해주세요` |
| 연락처 형식이 아님 (`abc`, `1`, `02-123-4567` 등) | `휴대폰 번호 형식이 아니에요. 010-1234-5678 처럼 입력해주세요` |
| 이름이 공백뿐 | `이름을 입력해주세요` |
| 동의를 켜지 않음 | 오류 문구 없이 버튼만 흐려집니다 |

### 특별한 상황일 때

| 상황 | 화면 |
|---|---|
| 로그인하지 않고 이 주소로 들어옴 | 자동으로 로그인 화면으로 보냅니다. 로그인하면 이 상담 신청 화면으로 돌아옵니다 |
| 없는 병원 주소로 들어옴 (예: `/consult/없는병원`) | `병원 정보를 찾을 수 없어요` |
| 로그인 화면으로 넘어가기 직전 | `로그인이 필요해요` 가 아주 짧게 스쳐 보일 수 있습니다 |
| 병원에 등록된 시술이 하나도 없음 | 시술 영역에 `잘 모르겠어요` 칩 하나만 보입니다 |
| 접수에 실패함 | **화면 맨 위**에 안내가 붙습니다 (브라우저 알림창이 아닙니다). 회색 카드에 빨간 느낌표 + `상담 신청을 접수하지 못했어요` + 실패 이유 + `다시 시도` 버튼이고, 화면 낭독기가 바로 읽습니다. **입력한 내용은 그대로 남습니다** |
| `상담 마감` 인 병원에 보냄 | 같은 자리에 같은 모양으로 `지금은 이 병원의 상담 신청을 받지 않아요` 가 보입니다 |
| 접수에 성공함 | 같은 주소에서 폼이 사라지고 완료 화면이 나옵니다. 병원 / 시술 / 연락 시간 / 상태(`신규`)가 요약으로 보입니다. 시술을 고르지 않았으면 `시술 미지정` 으로 보입니다 |
| 완료 후 뒤로 가기 | 직전 화면(보통 병원 상세)으로 갑니다. 이 화면에 다시 들어오면 빈 폼입니다 |

## 알아두실 것

- **신청 내용이 서버에 저장됩니다** (2026-10-22). 다른 컴퓨터에서 병원 관리자로 로그인하면 그 신청이 `신규` 로 보이고, 브라우저 데이터를 지워도 사라지지 않습니다. 다만 **전화·문자·메일로 병원에 알려주지는 않습니다** — 병원이 관리자 화면(또는 관리자 알림함)을 봐야 압니다.
- **제3자 제공 동의 기록도 서버에 남습니다.** 동의 시각(서버 시계)과 안내문 버전을 상담 건에 함께 저장합니다. 다만 **그 기록을 꺼내 보는 화면은 아직 없습니다** — 지금은 데이터베이스에서 직접 확인해야 합니다.
- **동의 안내문은 법무 검토 전입니다.** 특히 `보유·이용 기간` 항목은 기간이 정해지지 않아 **`[확정 필요] 회사에서 보유 기간을 확정하는 대로 안내드릴게요.` 가 사용자에게 그대로 보입니다.** 출시 전에 반드시 실제 기간으로 바꿔야 합니다.
- **동의 안내문은 약관 화면(`이용약관`·`개인정보처리방침`)과 다른 곳에 있습니다.** 지금은 앱 코드 안의 문구 상수라, 고치려면 개발자가 코드를 고쳐야 합니다.
- **동의는 신청할 때마다 새로 받습니다.** 저번에 동의했어도 화면에 다시 들어오면 체크는 꺼진 상태입니다 (요청서에서 정한 방식입니다).
- **연락처 자동 채움의 출처는 계정 정보가 아니라 "내가 지난번에 신청하며 쓴 번호"입니다.** 계정에는 전화번호가 없습니다. 그래서 처음 신청하는 계정은 빈칸으로 시작합니다.
- **자동 채움은 내가 신청한 건에서만 가져옵니다.** 서버가 "내 상담" 만 내려주므로 남의 번호가 뜰 길이 없습니다. 샘플 상담도 각각 주인이 정해져 있어, 그 계정으로 로그인했을 때만 자기 번호가 채워집니다.
- **내 상담 내역은 마이페이지의 `상담 내역` 탭에서 봅니다.** 완료 화면의 `내 상담 내역 보기` 가 그리로 데려다주고, 방금 신청한 건이 `신규` 상태로 맨 위에 있습니다. 병원이 상태를 바꾸면 그 탭의 칩과 확정 방문 일시(`10/9(금) 14:00 방문`)도 함께 바뀝니다.
- **어느 전문의에게 신청했는지는 저장되지 않습니다.** 저장되는 것은 병원·시술·희망 시간뿐입니다. 그래서 병원 상세의 `전문의 상담신청` 버튼은 2026-10-23 에 없어졌습니다 (같은 화면으로 가면서 전문의를 전달하지 못했습니다). 전문의 상세 화면의 상담 신청 버튼은 그대로입니다.
- **중복 신청을 막지 않습니다.** 같은 병원에 여러 번 신청하면 그만큼 따로 접수됩니다. (버튼 연타로 두 건이 들어가는 것은 막습니다)
- **`상담 마감` 인 병원은 이 주소로 직접 들어와도 접수되지 않습니다** (2026-10-22). 화면은 폼을 그대로 보여주지만, 보내는 순간 `지금은 이 병원의 상담 신청을 받지 않아요` 로 거절됩니다 (서버가 막습니다).
- **로그인해야 신청할 수 있습니다.** 신청 내용이 계정에 묶이기 때문입니다 (버튼에 🔒 가 붙어 있는 이유입니다).
- **희망 시술 목록은 그 병원이 등록한 시술만 나옵니다.** (지금 샘플 병원 11곳은 모두 시술이 등록되어 있습니다)
- **희망 연락 시간은 언제나 네 개로 고정입니다.** 병원별 진료시간과 연결되어 있지 않습니다. `평일 저녁` 은 2026-10-12에 늘어난 선택지라, 그 전에 접수된 상담에는 나타나지 않습니다.
- **입력 칸에서 Enter 를 누르면 제출됩니다.** 버튼이 흐린 상태면 Enter 로도 제출되지 않습니다.
- 접수 **실패** 안내는 2026-10-23 부터 브라우저 알림창이 아니라 화면 안 안내입니다. `다시 시도` 를 그 자리에서 누를 수 있고, 긴 문구도 잘리지 않습니다.

## 이 화면을 바꾸고 싶을 때

`docs/features/requests/_TEMPLATE.md` 를 복사해서 `docs/features/requests/` 에 요청서를 만들거나,
채팅창에 `/feature-request` 를 입력하세요.

이 화면에서 손대면 함께 확인해야 하는 것:

- 여기서 접수한 상담은 **관리자 `상담 예약` 화면과 같은 서버 데이터**를 씁니다. 저장 항목을 늘리려면 계약(`docs/api/openapi.yaml`)과 서버부터 고치고, 관리자 목록·상담 상세도 함께 손봐야 합니다.
- 접수하면 **관리자 알림함에 `새로운 상담 신청` 알림**이 함께 쌓입니다.
- **희망 연락 시간의 네 선택지는 서버 계약(`docs/api/openapi.yaml` 의 `ConsultPreferredTime`)과 같은 값이어야 합니다.** 앱에서는 `frontend/src/types/domain.ts` 의 `CONSULT_PREFERRED_TIMES` 한 곳에 있습니다.
- **동의 안내문을 고치면 버전(`THIRD_PARTY_CONSENT_NOTICE_VERSION`)도 함께 올려야 합니다.** 올리지 않으면 옛 문구에 한 동의와 새 문구에 한 동의가 같은 버전으로 기록돼 구분할 수 없습니다.
- **연락처 형식 규칙은 화면과 서버 계약이 같은 정규식을 씁니다.** 한쪽만 바꾸면 화면은 통과시키고 서버는 거절하는 상태가 됩니다.
- 이 화면으로 들어오는 버튼은 **병원 상세·병원 카드·지도 목록·전문의 상세** 여러 곳에 있습니다. 로그인 확인은 그 버튼들이 먼저 하고, 라우트 가드가 한 번 더 합니다.
- 희망 시술 목록은 **병원 정보의 시술 목록**에서 나옵니다. 관리자에서 병원 시술을 바꾸면 여기 선택지도 바뀝니다.
- **알림함**의 상담 알림은 마이페이지 `상담 내역` 의 그 상담 줄로 갑니다 (고정 주소입니다 — 찾는 단계가 없습니다). 내 내역에 없는 상담이면 탭만 열립니다.
