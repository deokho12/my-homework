# 상담 신청

> 병원 한 곳에 상담을 신청하는 화면입니다. 이름·연락처·희망 시술·희망 상담 시간을 남기면 접수됩니다.

| | |
|---|---|
| **주소** | `/consult/:hospitalId` (예: `/consult/h1`) |
| **누가 보나요** | 로그인한 사용자만 |
| **어디서 들어오나요** | 병원 상세의 `병원 상담신청`·`전문의 상담신청`, 병원 탐색 카드와 지도 목록의 상담 신청 버튼, 전문의 상세 화면 |
| **소스 파일** | `frontend/src/screens/consult/[hospitalId].tsx` |

---

## 여기서 할 수 있는 일

상태 표시: ✅ 실제로 동작함 · 🟡 화면은 되지만 데이터가 샘플 · 🚧 아직 아무 일도 안 일어남 · 🔒 로그인 필요

| 할 수 있는 일 | 상태 | 지금 어떻게 동작하나요 |
|---|---|---|
| 이름 입력 | ✅ | 자유롭게 입력합니다. 로그인한 계정의 이름이 자동으로 채워지지는 않습니다 |
| 연락처 입력 | ✅ | 전화번호용 입력 칸이지만 **형식은 검사하지 않습니다**. 글자·기호도 그대로 들어갑니다 |
| 희망 시술 고르기 | ✅ | 그 병원이 등록한 시술이 알약 모양 버튼으로 나오고, 하나만 고를 수 있습니다. **첫 번째 시술이 처음부터 선택되어 있고, 선택을 해제할 수는 없습니다** |
| 희망 상담 시간 고르기 | ✅ | `평일 오전` `평일 오후` `주말` 세 개 중 하나. 처음에는 `평일 오전`이 선택되어 있습니다 |
| 남기고 싶은 말 입력 | ✅ | 여러 줄 입력 칸. 비워둬도 됩니다 |
| 상담 신청하기 | ✅ 🔒 | 이름과 연락처가 채워져 있을 때만 눌립니다. 누르면 브라우저 알림창으로 `상담 신청이 접수되었어요` 가 뜨고, `확인` 을 누르면 직전 화면으로 돌아갑니다. 신청 내용은 저장되고 관리자의 `상담 관리` 목록 맨 위에 `신규` 상태로 나타납니다 |
| 뒤로 가기 | ✅ | 화면 위쪽 `‹` 화살표 |

---

## 화면에 보이는 정보

- **화면 제목** — 위쪽 헤더에 `상담 신청`
- **병원 이름** — 상담을 신청하려는 병원 이름
- **안내 문구** — `상담 정보를 남겨주시면 병원에서 연락드려요`
- **입력 칸 5개** — 아래 표 참고
- **`상담 신청하기` 버튼** — 조건을 채우기 전에는 흐리게 보이고 눌리지 않습니다

### 입력 칸별로 지금 무엇을 검사하나요

| 입력 칸 | 필수인가요 | 안내 문구(placeholder) | 지금 실제로 검사하는 것 | 검사하지 않는 것 |
|---|---|---|---|---|
| 이름 | 필수 | `이름을 입력해주세요` | 앞뒤 공백을 뺀 뒤 한 글자 이상인지 (공백만 넣으면 안 됩니다) | 글자 수 제한, 한글/영문 여부, 특수문자 |
| 연락처 | 필수 | `010-0000-0000` | 앞뒤 공백을 뺀 뒤 한 글자 이상인지 | **전화번호 형식을 전혀 보지 않습니다.** `1` 한 글자, `abc`, `없음` 도 통과합니다. `010` 으로 시작하지 않아도 되고, 자리수·하이픈도 확인하지 않습니다 |
| 희망 시술 | 사실상 필수 | — | 없음 (항상 하나가 선택되어 있습니다) | — |
| 희망 상담 시간 | 사실상 필수 | — | 없음 (항상 하나가 선택되어 있습니다) | 그 병원이 실제로 그 시간에 진료하는지는 보지 않습니다 |
| 남기고 싶은 말 (선택) | 선택 | `궁금한 점이나 요청사항을 적어주세요` | 없음 | 글자 수 제한 없음 |

즉 **`상담 신청하기` 버튼이 켜지는 조건은 "이름과 연락처가 공백이 아닌 것" 딱 하나입니다.**

### 특별한 상황일 때

| 상황 | 화면 |
|---|---|
| 로그인하지 않고 이 주소로 들어옴 | 자동으로 로그인 화면으로 보냅니다. 로그인하면 이 상담 신청 화면으로 돌아옵니다 |
| 없는 병원 주소로 들어옴 (예: `/consult/없는병원`) | `병원 정보를 찾을 수 없어요` |
| 로그인 화면으로 넘어가기 직전 | `로그인이 필요해요` 가 아주 짧게 스쳐 보일 수 있습니다 |

## 이 화면에서 이동할 수 있는 곳

| 어디로 | 무엇을 눌렀을 때 |
|---|---|
| 직전 화면 (보통 병원 상세) | 접수 알림창의 `확인`, 또는 헤더의 `‹` |
| 로그인 | 로그인하지 않은 상태로 이 화면에 들어왔을 때 (자동) |

## 알아두실 것

- **연락처 형식을 검사하지 않습니다.** 010이 아닌 번호, 자리수가 모자란 번호, 아예 글자만 넣은 것도 그대로 접수됩니다. "이런 번호가 왜 들어가나요?"의 답은 "지금은 비어있지 않은지만 봅니다"입니다.
- **이름과 연락처가 자동으로 채워지지 않습니다.** 로그인한 계정에 이름이 있어도 매번 직접 입력해야 합니다.
- **상담을 신청해도 실제로 병원에 연락이 가지 않습니다.** 서버가 없어서, 내용은 이 브라우저 안에만 저장됩니다. 다른 컴퓨터나 시크릿 창에서는 보이지 않고, 브라우저 데이터를 지우면 함께 사라집니다.
- **신청한 사람이 자기 신청 내역을 볼 수 있는 화면이 없습니다.** 저장된 신청은 관리자의 `상담 관리` 화면에서만 확인됩니다. (마이페이지 안내에는 `상담 신청 내역을 확인할 수 있어요` 라고 적혀 있지만, 마이페이지에는 찜한 병원만 나옵니다)
- **어느 전문의에게 신청했는지는 저장되지 않습니다.** 병원 상세의 `전문의 상담신청` 으로 들어와도, 저장되는 것은 병원·시술·희망 시간뿐입니다.
- **중복 신청을 막지 않습니다.** 같은 병원에 여러 번 신청하면 그만큼 따로 접수됩니다.
- **병원 상세에서 `상담 마감` 으로 표시된 병원도 이 주소로 직접 들어오면 신청이 됩니다.** 이 화면은 상담 가능 여부를 확인하지 않습니다.
- **희망 시술 목록은 그 병원이 등록한 시술만 나옵니다.** 병원에 등록된 시술이 없으면 이 영역이 빈 자리로 보입니다. (지금 샘플 병원 11곳은 모두 시술이 등록되어 있습니다)
- **희망 상담 시간은 언제나 `평일 오전` `평일 오후` `주말` 세 개로 고정입니다.** 병원별 진료시간과 연결되어 있지 않습니다.
- **입력 칸에서 Enter 를 눌러도 제출되지 않습니다.** `상담 신청하기` 버튼을 눌러야 합니다.
- 접수 안내가 앱 안의 예쁜 팝업이 아니라 **브라우저 기본 알림창**으로 뜹니다. 브라우저에 따라 `localhost의 메시지:` 같은 문구가 함께 보입니다.

## 이 화면을 바꾸고 싶을 때

`docs/features/requests/_TEMPLATE.md` 를 복사해서 `docs/features/requests/` 에 요청서를 만들거나,
채팅창에 `/feature-request` 를 입력하세요.

이 화면에서 손대면 함께 확인해야 하는 것:

- 여기서 접수한 상담은 **관리자 `상담 관리` 화면과 같은 데이터**를 씁니다. 저장 항목을 늘리면 관리자 목록·상담 상세도 함께 손봐야 합니다.
- 접수하면 **관리자 알림함에 `새로운 상담 신청` 알림**이 함께 쌓입니다.
- 이 화면으로 들어오는 버튼은 **병원 상세·병원 카드·지도 목록·전문의 상세** 여러 곳에 있습니다. 로그인 확인은 그 버튼들이 먼저 하고, 이 화면이 한 번 더 합니다.
- 희망 시술 목록은 **병원 정보의 시술 목록**에서 나옵니다. 관리자에서 병원 시술을 바꾸면 여기 선택지도 바뀝니다.
