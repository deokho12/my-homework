# 병원 등록

> 새 병원을 몰라몰라에 처음 등록하는 화면입니다. 병원 기본정보·진료시간·취급 시술·병원 특징과 소속 전문의를 한 번에 입력해서 저장합니다.

| | |
|---|---|
| **주소** | `/admin/hospital/new` |
| **누가 보나요** | 🔒 **운영자 계정만** 들어올 수 있습니다. 로그인하지 않았으면 로그인 화면으로 보내고, 병원 관리자·일반 사용자 계정이면 `접근 권한이 없어요` 만 보입니다 |
| **어디서 들어오나요** | 병원 관리자 홈(`/admin`)의 `새 병원 등록` 버튼 |
| **소스 파일** | `frontend/src/pages/admin/AdminHospitalNewPage.tsx` + 입력 폼은 `frontend/src/components/admin/HospitalForm.tsx` (병원 정보 수정 화면과 같은 폼을 씁니다) |

---

## 여기서 할 수 있는 일

상태 표시: ✅ 실제로 동작함 · 🟡 화면은 되지만 데이터가 샘플 · 🚧 아직 아무 일도 안 일어남 · 🔒 로그인 필요

| 할 수 있는 일 | 상태 | 지금 어떻게 동작하나요 |
|---|---|---|
| 병원 기본정보 입력 | ✅ | 아래 `입력 항목 전체` 표 참고 |
| 주소 검색해서 고르기 | 🟡 | 검색창에 입력하면 0.3초 뒤 자동으로 검색되고, 결과를 누르면 주소가 확정됩니다. **카카오 주소 검색 키가 설정되지 않으면 실제 주소가 아니라 입력한 글자로 만든 가짜 결과 1~3개가 나옵니다** |
| 취급 시술 고르기 | ✅ | **시술 분야 9개가 접었다 펼 수 있는 목록**으로 나오고, 펼치면 그 안의 세부 시술에 체크박스가 있습니다. 여러 개 고를 수 있습니다. 등록 화면에서는 9개 분야가 **처음부터 전부 펼쳐져** 있습니다 |
| 세부 시술 31개 모두 고르기 | ✅ | **31개 전부 체크할 수 있습니다** (2026-10-21 부터. 그 전에는 서버가 모르는 18개가 `준비중` 배지가 붙은 회색이라 눌리지 않았습니다). 아직 아무 병원도 등록하지 않은 시술을 체크해서 등록하면, 사용자 화면에서 그 시술의 `준비중` 이 바로 사라집니다 |
| 요일별 진료시간 입력 | ✅ | 월~일 7줄이 기본값으로 채워진 상태로 시작합니다. 각 줄의 시간을 직접 고쳐 쓸 수 있습니다 |
| 특정 요일을 휴진으로 바꾸기 | ✅ | 요일 줄 오른쪽 `휴진` 버튼. 누르면 그 줄이 `휴진` 으로 바뀌고 시간 입력이 잠깁니다. 다시 누르면 `09:30 - 18:30` 으로 되돌아옵니다 |
| 병원 특징 체크 | ✅ | 체크박스 6개 |
| 전문의 추가하기 | ✅ | `+ 전문의 추가` 를 누르면 입력 칸 묶음이 하나 더 생깁니다. 몇 명이든 계속 추가할 수 있습니다 |
| 전문의 삭제하기 | ✅ | 각 전문의 칸 오른쪽 위 `삭제`. 확인창 없이 바로 그 칸이 사라집니다 |
| 등록하기 | ✅ | 필수 항목이 다 채워지면 `등록하기` 가 활성화됩니다. 누르면 병원과 전문의가 저장되고 **직전 화면(관리자 홈)으로 돌아갑니다.** 저장됐다는 안내 문구는 따로 나오지 않습니다 |
| 사진 파일 올리기 | 🚧 | **없습니다.** 이미지는 URL을 직접 붙여넣는 방식만 있습니다 |
| 임시저장 / 작성 중 이탈 경고 | 🚧 | **없습니다.** 저장 전에 화면을 벗어나면 입력한 내용은 사라집니다 |

## 입력 항목 전체

화면에 보이는 순서대로입니다. `필수` 표시가 있는 항목이 하나라도 비어 있으면 `등록하기` 버튼이 흐리게 표시되고 눌리지 않습니다.

| 항목 이름 (화면 문구) | 필수 | 형태 | 비어 있을 때 안내 문구 / 기본값 |
|---|---|---|---|
| `병원명` | **필수** | 한 줄 입력 | `병원명을 입력해주세요` |
| `전문 분야 (예: 임플란트 전문의원)` | 선택 | 한 줄 입력 | `전문 분야` |
| `지역` | **필수** | 한 줄 입력 | `예: 서울 강남구` |
| `주소` | **필수** | 검색해서 고르기 (직접 타이핑으로 확정 불가) | `도로명 또는 지번 주소를 입력해주세요` |
| `대표 이미지 URL (선택)` | 선택 | 한 줄 입력 | `https://...` / 비워두면 샘플 이미지가 자동으로 들어갑니다 |
| `병원 소개` | 선택 | 여러 줄 입력 (4줄 높이) | `병원을 소개해주세요` |
| `가격대 (원)` — `최소` | **필수** | 숫자 입력 | `최소` |
| `가격대 (원)` — `최대` | **필수** | 숫자 입력 | `최대` |
| `태그 (쉼표로 구분)` | 선택 | 한 줄 입력. 쉼표로 나눠 여러 개가 됩니다 | `예: 당일진료, 주차가능` |
| `취급 시술 (1개 이상 선택)` | **필수** | 분야 9개 펼침 목록 → 세부 시술 체크박스 | 아래 목록 참고 |
| `실시간 상담 가능` | 선택 | 체크박스 | **기본 켜짐** |
| `원데이 진료 가능 여부 (당일 보철 등)` | 선택 | 체크박스 | 기본 꺼짐 |
| `추천 병원으로 노출 (에디터 추천)` | 선택 | 체크박스 | 기본 꺼짐 |
| `진료시간 (요일별)` | 선택 | 요일 7줄 × (시간 입력 + `휴진` 버튼) | 기본값이 미리 채워져 있습니다 (아래 참고) |
| `찾아오시는 길` | 선택 | 여러 줄 입력 (2줄 높이) | `예: 강남역 11번 출구에서 도보 5분` |
| `병원 특징` | 선택 | 체크박스 6개 | 전부 꺼짐 |
| `전문의` | 선택 | 반복 추가 (아래 참고) | 새 병원은 한 명도 없이 시작합니다 |

### `취급 시술` 로 고를 수 있는 것

**시술 분야 9개 → 세부 시술 31개** 구조입니다. 분야 줄을 누르면 접혔다 펼쳐지고, 줄 오른쪽에
`2개 선택` 처럼 지금 고른 개수가 표시됩니다. **31개 모두 고를 수 있습니다** — 회색이나 `준비중`
표시가 붙은 항목은 없습니다(2026-10-21 부터). 사용자 화면의 `준비중` 은 "그 시술을 등록한 병원이
아직 없다" 는 뜻일 뿐이라, 이 화면에서 체크해 등록하는 것이 바로 그것을 푸는 방법입니다.

| 분야 | 세부 시술 |
|---|---|
| 임플란트 | 일반 임플란트 · 뼈이식 · 상악동거상술 · 임플란트 틀니 |
| 스케일링·예방 | 스케일링 · 불소도포 · 실란트 · 구취관리 |
| 교정 | 투명교정 · 설측교정 · 일반(브라켓)교정 · 부분교정 |
| 충치치료 | 레진 · 인레이 · 온레이 · 크라운 · 신경치료 |
| 심미 | 라미네이트 · 치아미백 · 잇몸성형 |
| 잇몸치료 | 잇몸치료 · 치주수술 · 잇몸이식 |
| 턱관절·스플린트 | 턱관절장애 치료 · 스플린트 · 이갈이장치 · 코골이장치 |
| 보톡스 | 이갈이 보톡스 · 사각턱(교근) 보톡스 |
| 사랑니·발치 | 사랑니 발치 · 일반 발치 |

지금 어느 시술에 등록한 병원이 있는지(★)는 [시술 카테고리 문서](category.md)의 표에 있습니다.

**고른 세부 시술은 그 이름 그대로 서버에 저장됩니다** (2026-10-21 부터). 그 전에는 `레진` 을
체크하면 서버에 `충치치료` 로 저장되는 식으로 화면 이름과 서버 이름이 달랐지만, 이제 관리자
화면·사용자 화면·서버가 모두 같은 이름을 씁니다.

### `진료시간 (요일별)` 기본값

| 요일 | 기본값 |
|---|---|
| 월 · 화 · 수 · 목 · 금 | `09:30 - 18:30` |
| 토 | `09:30 - 14:00` |
| 일 | `휴진` (휴진 버튼이 켜진 상태) |

요일을 추가하거나 없애는 기능은 없습니다. 점심시간을 따로 적는 칸도 없어서, 필요하면 시간 칸에 그냥 함께 적어야 합니다.

### `병원 특징` 체크박스 6개

`전담코디네이터` `무통마취` `디지털진료` `주차가능` `야간상담` `CCTV설치`

> 병원 상세 화면의 특징 배지에 나오는 `⚡ 원데이가능` 은 이 6개가 아니라 위쪽의 `원데이 진료 가능 여부 (당일 보철 등)` 체크박스에서 나옵니다.

### `전문의` 한 명당 입력하는 것 (반복 추가)

`+ 전문의 추가` 를 누를 때마다 아래 묶음이 하나 더 생기고, 묶음 제목은 `전문의 1`, `전문의 2` … 로 번호가 붙습니다.

| 항목 | 형태 | 기본값 / 안내 문구 |
|---|---|---|
| 이름 | 한 줄 입력 | `이름` |
| 직함 | 한 줄 입력 | `원장` 이 미리 들어감 / `직함 (예: 대표원장)` |
| 전문 분야 | 칩 8개 중 하나 선택 | `치과보철전문의` 가 미리 선택됨 |
| 자격증/인증서 이미지 URL | 한 줄 입력 | `자격증/인증서 이미지 URL` |

고를 수 있는 전문 분야 8개: `치과보철전문의` `치과교정전문의` `구강악안면외과전문의` `치주과전문의` `소아치과전문의` `통합치의학과전문의` `구강악안면방사선과전문의` `일반의`

전문의 영역 위에는 이런 안내가 적혀 있습니다: `새로 추가한 전문의는 "대기" 상태로 등록되며, 운영자의 자격증 검수 후 배지가 노출돼요.`

### 이 화면에 **없는** 항목

비개발자분이 "추가해달라"고 요청하실 때 참고용입니다. 아래는 지금 이 폼에서 입력할 수 없습니다.

- 병원 **전화번호**, 이메일, 홈페이지 주소
- 병원 사진 **여러 장** (대표 이미지 1장만 입력합니다)
- **시술별 가격표** (전체 가격대의 최소/최대 두 숫자만 있습니다)
- **할인·이벤트** 등록
- **광고 신청** (병원 정보 수정 화면에 읽기 전용 현황만 있습니다)
- 전문의의 **사진 · 연차 · 경력** (자동으로 빈 값/샘플 사진이 들어갑니다)
- 평점 · 후기 (새 병원은 평점 0, 후기 0으로 시작합니다)

## 저장을 누르면 실제로 무슨 일이 일어나나요

- 입력한 내용으로 병원이 새로 만들어지고, **일반 사용자 화면(홈·병원 탐색·검색·병원 상세)에 바로 나타납니다.**
- 평점·후기 수·상담 수는 `0`, 진행중인 이벤트는 없음, 광고는 꺼진 상태로 시작합니다.
- 대표 이미지 URL을 비워두면 샘플 이미지 주소가 자동으로 들어갑니다.
- 이름을 적은 전문의만 함께 등록됩니다. **이름이 빈 칸으로 남아 있는 전문의 묶음은 조용히 무시됩니다.** **다만 지금은 이 화면에서 넣은 전문의가 실제로 저장되지 않습니다** (2026-10-21 확인 — 서버의 병원 등록 요청에 전문의 칸이 없어 버려집니다). 등록한 뒤 [병원 정보 수정](admin-hospital-edit.md)의 `의료진` 에서 다시 넣어 주세요. [알려진 문제](known-issues.md)에 적어 두었습니다
- 등록된 전문의는 전부 **`대기` 상태**로 들어가고, `전문의 인증 검수` 화면에서 승인해야 사용자 화면에 전문의 배지가 붙습니다.
- 전문의의 담당 시술은 따로 고르는 칸이 없어 서버가 정합니다 — 고른 전문 분야가 다루는 시술 중 **이 병원이 취급하는 시술만** 붙습니다(2026-10-21 부터. 그 전에는 병원이 하지 않는 시술도 전공만 보고 붙었습니다). `일반의` 를 고른 경우에는 이 병원이 취급하는 시술 전체가 담당 시술이 됩니다. 겹치는 시술이 없으면 0개이고, `구강악안면방사선과전문의` 는 해당하는 시술이 없어 항상 0개입니다.
- 저장이 끝나면 **직전 화면으로 돌아갑니다.** `등록되었어요` 같은 확인 문구는 없습니다.

## 알아두실 것

- **병원 등록은 운영자만 할 수 있습니다.** 화면에 들어오는 것도, 실제로 저장하는 것도 서버가 운영자인지 다시 확인합니다. 병원 관리자는 이미 등록된 자기 병원의 정보만 고칠 수 있습니다([병원 정보 수정](admin-hospital-edit.md)).
- **`등록하기` 버튼이 안 눌리면 필수 항목이 빠진 것입니다.** 특히 잘 놓치는 것은 **주소** 입니다 — 주소는 검색창에 글자만 넣어두면 안 되고 **검색 결과를 눌러서 확정해야** 합니다.
- **주소 검색은 카카오 키가 없으면 가짜 결과를 보여줍니다.** 입력한 글자에 `로 12`, ` 12-3` 같은 꼬리가 붙은 결과가 나오면 실제 주소를 조회한 게 아닙니다. 이 경우 저장되는 위치(지도 좌표)도 서울시청 근처의 임의 지점입니다.
- **사진은 파일로 올릴 수 없습니다.** 인터넷에 이미 올라가 있는 이미지 주소(URL)를 붙여넣어야 하고, 비워두면 샘플 사진이 들어갑니다.
- **입력 중 자리를 벗어나면 내용이 사라집니다.** 임시저장이 없고, 나가려 할 때 경고도 없습니다.
- **등록한 병원을 지우는 화면은 없습니다.** 잘못 등록하면 정보를 고칠 수는 있지만 목록에서 없앨 수는 없습니다.
- **가격은 숫자만 넣어야 합니다.** `만원`, 쉼표 같은 글자를 함께 넣으면 저장할 때 `0` 으로 처리됩니다.
- **세부 시술 31개를 모두 고를 수 있습니다** (2026-10-21 부터). 아직 아무 병원도 등록하지 않은 시술(예: `스케일링`)도 체크해서 등록하면 그대로 저장되고, 사용자 화면에서 그 시술의 `준비중` 이 사라집니다.
- **고른 세부 시술, 사용자 화면에 보이는 이름, 서버에 저장되는 이름이 모두 같습니다** (`레진` 은 어디서나 `레진`).
- 데이터는 **개발용 서버에 저장**됩니다. 다른 컴퓨터에서도 등록한 병원이 보입니다.
