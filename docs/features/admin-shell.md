# 관리자 공통 레이아웃 (사이드 메뉴 + 상단바)

> 관리자 화면 **전부**를 감싸는 틀입니다. 왼쪽에 메뉴, 위에 화면 제목·환자 검색·알림 종이 있고, 가운데가 각 화면의 내용입니다. 예전에는 화면마다 입구가 흩어져 있어 상담에서 문의로 가려면 홈을 거쳐야 했습니다.

| | |
|---|---|
| **주소** | 없습니다 — `/admin` 으로 시작하는 **모든 화면**에 함께 그려집니다 |
| **누가 보나요** | 🔒 **병원 관리자·운영자 계정**. 자격이 없으면 메뉴도 상단바도 없이 `접근 권한이 없어요` 화면만 보입니다 (로그인 화면에 관리자 메뉴가 붙어 있으면 "이미 들어와 있다" 로 읽히기 때문입니다) |
| **소스 파일** | `frontend/src/components/admin/AdminShell.tsx` · `AdminSideMenu.tsx` · `AdminNarrowNav.tsx` · `AdminTopBar.tsx` · `AdminHospitalPicker.tsx` · `AdminMenuItem.tsx` · `adminMenu.ts` |

## 여기서 할 수 있는 일

상태 표시: ✅ 실제로 동작함 · 🟡 화면은 되지만 데이터가 샘플 · 🚧 아직 아무 일도 안 일어남 · 🔒 로그인 필요

| 할 수 있는 일 | 상태 | 지금 어떻게 동작하나요 |
|---|---|---|
| 메뉴로 화면 옮기기 | ✅ | 대시보드 · 상담 예약 · 문의 · 기본 정보 · 시술 · 의료진. 지금 보고 있는 화면의 메뉴가 **진한 색으로 강조**됩니다 |
| 상담 예약 배지 보기 | 🟡 | `상담 예약` 옆 숫자 = **신규 상담 수**. 대시보드의 `신규 전체 N건` 과 **같은 숫자**입니다 (한 응답에서 옵니다) |
| 문의 배지 보기 | 🟡 | `문의` 옆 숫자 = **답변 안 한 문의 수**. 대시보드의 `답변 안 한 문의` 카드와 같은 숫자입니다 |
| 담당 병원 고르기 | ✅ | 맡은 병원이 **2곳 이상일 때만** 메뉴 위에 드롭다운이 나옵니다. 1곳이면 숨깁니다 |
| 환자 검색 | ✅ | 상단 오른쪽. 이름이나 연락처를 넣고 Enter → 그 검색어가 걸린 상담 예약 목록이 열립니다. **상태·기간과 상관없이 전체 상담에서** 찾습니다(예약확정·취소된 환자, 30일 넘은 신청도 나옵니다). 좁은 화면에서는 🔍 를 눌러 검색칸을 폅니다 |
| 알림함 열기 | ✅ | 상단 오른쪽 🔔. 안 읽은 알림이 있으면 **빨간 점**이 붙습니다 (숫자는 알림함 안에서 봅니다) |
| 환자 앱으로 돌아가기 | ✅ | 메뉴 맨 아래 `몰라몰라 앱으로` |
| 이벤트 · 후기 · 광고 현황 · 기공소 연계 | 🚧 | 메뉴에 회색 `준비중` 으로만 있습니다. 눌리지 않습니다. **병원 담당자에게만 보입니다** — 자기 병원을 알리는 기능이라 운영자에게는 아예 그리지 않습니다 |
| 담당자 직책 · 승인 상태 | 🚧 | 메뉴 아래 카드에 **병원명과 이름만** 있습니다. 직책과 `승인 완료 · 앱 노출 중` 표시는 아직 저장되는 곳이 없습니다 |

## 화면에 보이는 정보

**넓은 화면(가로 1024px 이상)**

- **왼쪽 메뉴 (248px)** — `몰라몰라 파트너` → (담당 병원 드롭다운) → 그룹별 메뉴 → 맨 아래 `{병원명} / {이름}` 카드 + `몰라몰라 앱으로`
- **메뉴 그룹** — `업무`(대시보드 · 상담 예약 · 문의) / `병원 정보`(기본 정보 · 시술 · 의료진) / `홍보 · 확장`(전부 준비중)
  - 운영자에게는 `대시보드` 대신 `운영` 그룹(병원 목록 · 전문의 인증 검수 · 새 병원 등록)이 보이고, **`홍보 · 확장` 그룹은 보이지 않습니다**
- **상단바** — 화면 제목 + 환자 검색칸 + 🔔

**좁은 화면**

- 메뉴가 **가로 칩 줄**로 바뀝니다 — 업무 3개(배지 포함)는 늘 보이고, 나머지는 `더보기` 를 눌러 폅니다
- 상단바에 뒤로 가기(`<`, 상세 화면에서만) · 제목 · 🔍 · 🔔

## 이 화면에서 이동할 수 있는 곳

| 어디로 | 무엇을 눌렀을 때 |
|---|---|
| 대시보드 / 병원 목록 | 메뉴 `대시보드`(병원 담당자) · `병원 목록`(운영자), 또는 왼쪽 위 `몰라몰라 파트너` |
| 상담 예약 | 메뉴 `상담 예약` |
| 문의 | 메뉴 `문의` |
| 병원 정보 수정 | 메뉴 `기본 정보 · 시술` |
| 병원 정보 수정의 의료진 영역 | 메뉴 `의료진` |
| 전문의 인증 검수 · 병원 등록 | 운영자 메뉴 |
| 관리자 알림함 | 상단 🔔 |
| 검색 결과(상담 예약) | 상단 검색칸에 입력 후 Enter |
| 환자 앱 홈 | 메뉴 맨 아래 `몰라몰라 앱으로` |

## 알아두실 것

- **배지 숫자와 대시보드 숫자는 같은 곳에서 옵니다.** 한 번만 세어 두 자리가 나눠 쓰므로, 상담에 연락하면 배지와 대시보드 카드가 **함께** 줄어듭니다. 따로 세면 1분 차이로 `신규 5건` 옆에 배지 `6` 이 붙는 일이 생깁니다.
- **운영자에게는 배지 숫자가 붙지 않습니다.** 운영자는 상담에 연락할 수도 문의에 답할 수도 없으므로, 전 병원의 미답변 수는 그의 할 일 수가 아닙니다.
- **고른 담당 병원은 이 브라우저에 기억됩니다.** 화면을 옮겨도 따라가고, **계정이 바뀌면 지워집니다.** 담당에서 빠진 병원이 기억돼 있으면 조용히 버리고 첫 번째 병원을 봅니다.
- **병원을 바꾸면 보던 상담·문의 상세는 닫히고 목록으로 돌아갑니다.** 그 상담은 방금 떠난 병원의 것이기 때문입니다. 병원 정보 수정 화면에서는 새로 고른 병원의 수정 화면으로 옮겨갑니다.
- **화면 제목은 상단바에 하나뿐입니다.** 예전에는 상담·문의·검수 화면이 같은 제목을 본문에도 한 번 더 적어, 화면을 읽어 주는 프로그램이 제목을 두 번 읽었습니다.
- **섹션이 바뀔 때만 본문으로 초점이 옮겨갑니다.** 목록에서 다른 상담을 고르는 것처럼 같은 화면 안에서 움직일 때는 보던 자리를 잃지 않습니다.
- **알림 종에는 숫자 대신 점만 있습니다.** 숫자는 알림함 안에서 봅니다.

## 이 화면을 바꾸고 싶을 때

`docs/features/requests/_TEMPLATE.md` 를 복사해서 `docs/features/requests/` 에 요청서를 만들거나,
채팅창에 `/feature-request` 를 입력하세요.

이 화면에서 손대면 함께 확인해야 하는 것:

- **메뉴 구성은 순수 함수 한 곳**(`frontend/src/components/admin/adminMenu.ts`)에서 나오고, 넓은 화면의 세로 메뉴와 좁은 화면의 칩 줄이 **같은 모델**을 그립니다. 한쪽에만 항목을 더하면 화면 폭에 따라 메뉴가 달라집니다.
- **배지 숫자를 다른 곳에서 세지 마세요.** 대시보드 응답(`GET /admin/dashboard`) 하나가 그 숫자의 유일한 출처입니다.
- **선택한 담당 병원은 [상담 예약](admin-consultations.md)·[문의](admin-inquiries.md) 목록에도 걸립니다.** 메뉴만 바꾸고 목록을 그대로 두면 "A 병원 화면에서 B 병원 상담" 이 보입니다.
- 관리자 라우트를 새로 만들 때는 `frontend/src/App.tsx` 의 그 줄에 `shell: 'admin'` 을 꼭 넣어야 합니다 — 빠뜨리면 그 화면만 메뉴 없이 뜹니다.
