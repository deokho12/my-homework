# 이벤트 목록

> 병원들이 진행하는 할인 이벤트를 한자리에 모아 보여주는 화면입니다.

| | |
|---|---|
| **주소** | `/events` |
| **누가 보나요** | 누구나 (로그인 필요 없음) |
| **어디서 들어오나요** | 홈 화면 `지금 진행중인 이벤트` 의 `전체보기`, 넓은 화면(폭 768px 이상) 상단 메뉴의 `이벤트`, 알림함의 이벤트 알림 |
| **소스 파일** | `frontend/src/screens/events.tsx` (화면) + `frontend/src/components/PromotionCard.tsx` (이벤트 카드) |

## 여기서 할 수 있는 일

상태 표시: ✅ 실제로 동작함 · 🟡 화면은 되지만 데이터가 샘플 · 🚧 아직 아무 일도 안 일어남 · 🔒 로그인 필요

| 할 수 있는 일 | 상태 | 지금 어떻게 동작하나요 |
|---|---|---|
| 이벤트 목록 보기 | 🟡 | 샘플 이벤트 4개가 카드로 나열됩니다 |
| 할인율 · 할인가 보기 | 🟡 | 원가와 할인가로 할인율을 자동 계산해서 `28%` 처럼 보여주고, 그 옆에 할인가, 아래에 취소선 그은 원가를 보여줍니다 |
| 이벤트를 눌러 병원 보기 | 🟡 | 카드를 누르면 **그 이벤트를 하는 병원의 상세 화면**으로 이동합니다. 이벤트 자체의 상세 화면은 없습니다 |
| 이벤트 신청 · 참여하기 | 🚧 | 이벤트를 신청하는 버튼이 없습니다. 상담 신청은 병원 상세로 넘어가서 해야 합니다 |
| 필터 · 정렬 · 검색 | 🚧 | 없습니다. 정해진 순서대로만 나옵니다 |
| 찜하기 | 🚧 | 이벤트 카드에는 하트가 없습니다 |

## 화면에 보이는 정보

- **제목** — `지금 진행중인 이벤트`
- **설명 한 줄** — `기간 한정 할인 혜택을 확인해보세요`
- **이벤트 카드** — 카드 하나에 아래 정보가 들어갑니다
  - 병원 사진
  - 사진 왼쪽 위 빨간 배지 — `🔥 얼리버드` 처럼 이벤트별 문구가 들어갑니다
  - 이벤트 제목 (한 줄까지, 길면 잘립니다)
  - 병원 이름 (한 줄까지)
  - 할인율 + 할인가
  - 취소선 그은 원가
- **이벤트가 하나도 없을 때** — `진행중인 이벤트가 없어요`

## 알아두실 것

- **이벤트 4개는 고정된 샘플입니다.** 화면이나 관리자 화면에서 이벤트를 추가·수정·삭제하는 기능이 아직 없습니다. 내용을 바꾸려면 개발자가 데이터를 직접 수정해야 합니다.
- **이벤트는 브라우저에 저장되는 데이터가 아닙니다.** 코드 안에 들어있어서 어떤 컴퓨터에서 봐도 똑같이 4개이고, 브라우저 데이터를 지워도 그대로 남습니다.
- **`기간 한정` 이라고 써 있지만 이벤트에 시작일·마감일 정보가 아예 없습니다.** 그래서 남은 기간, D-day, 마감일이 표시되지 않고, 기간이 지나 자동으로 사라지는 일도 없습니다. "이벤트 기간이 안 보인다"는 것은 고장이 아니라 아직 그 항목이 없는 것입니다.
- **카드를 누르면 이벤트 상세가 아니라 병원 상세로 갑니다.** 이벤트 조건, 포함 항목, 유의사항 같은 것을 보여주는 화면은 없습니다.
- **이벤트 신청 버튼이 없습니다.** 할인을 받으려면 병원 상세로 넘어가 `병원 상담신청` 을 눌러야 하는 흐름입니다.
- **이벤트에 연결된 병원이 병원 목록에서 사라지면 그 카드도 아무 표시 없이 조용히 빠집니다.** 지금 샘플에서는 4개 모두 정상적으로 보입니다.
- **같은 이벤트 배지와 할인가가 다른 화면에도 나타납니다.** 홈·병원 탐색·찜 목록의 병원 카드 왼쪽 위 `🔥` 배지, 그리고 병원 상세의 `진행중인 이벤트` 영역이 모두 이 데이터를 씁니다. 여기를 바꾸면 그쪽도 함께 바뀝니다.
- **카드 폭이 고정(약 256px)입니다.** 넓은 화면에서는 오른쪽에 빈 공간이 남고, 줄이 바뀌는 자리에서 위아래 카드가 붙어 보일 수 있습니다. 의도한 모양인지는 아직 확정되지 않았습니다.
- **한 병원에 이벤트는 하나까지만 연결됩니다.** 같은 병원에 이벤트를 두 개 넣으면 병원 카드에는 그중 하나만 붙습니다. **(확인 필요 — 지금 샘플에는 병원마다 하나씩만 있어서 실제로 겹친 경우가 없습니다)**
- 로그인하지 않아도 전부 볼 수 있습니다.

## 이 화면을 바꾸고 싶을 때

`docs/features/requests/_TEMPLATE.md` 를 복사해서 `docs/features/requests/` 에 요청서를 만들거나,
채팅창에 `/feature-request` 를 입력하세요.

이 화면에서 손대면 함께 확인해야 하는 것:

- **홈 화면 `지금 진행중인 이벤트`** 와 같은 이벤트 데이터를 씁니다.
- **병원 카드(홈·병원 탐색·마이페이지 찜 목록)의 `🔥` 배지와 할인가**도 같은 데이터에서 나옵니다.
- **병원 상세의 가격 영역과 `진행중인 이벤트` 영역**도 같은 데이터를 씁니다. 이벤트를 지우면 병원 상세의 할인 가격 표시가 `가격대` 로 바뀝니다.
- **이벤트에 기간(시작일·마감일)을 넣고 싶다면** 이벤트 데이터 자체에 항목을 추가해야 하고, 위에 적은 모든 화면에서 "기간이 지난 이벤트를 어떻게 보여줄지" 를 함께 정해야 합니다.
