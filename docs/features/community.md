# 커뮤니티

> 치과 시술에 대해 궁금한 점을 질문으로 올리고, 다른 사람들이 올린 질문과 답변을 읽어보는 화면입니다.

| | |
|---|---|
| **주소** | `/community` |
| **누가 보나요** | 누구나 (질문 쓰기도 로그인 없이 됩니다) |
| **어디서 들어오나요** | 아래 탭바의 `커뮤니티`, 넓은 화면(PC)의 위쪽 메뉴 `커뮤니티` |
| **소스 파일** | `frontend/src/screens/tabs/community.tsx` (목록) + `frontend/src/screens/community/new.tsx` (질문 작성) + `frontend/src/screens/community/[id].tsx` (질문 상세) |

## 여기서 할 수 있는 일

상태 표시: ✅ 실제로 동작함 · 🟡 화면은 되지만 데이터가 샘플 · 🚧 아직 아무 일도 안 일어남 · 🔒 로그인 필요

| 할 수 있는 일 | 상태 | 지금 어떻게 동작하나요 |
|---|---|---|
| 질문 목록 훑어보기 | 🟡 | 질문 4건이 최신 순으로 보입니다. 전부 샘플 글입니다 |
| 질문 하나 열어보기 | ✅ | 카드를 누르면 질문 상세 화면으로 이동하고, **조회 수가 1 올라가서 저장됩니다** |
| `질문하기` 로 작성 화면 열기 | ✅ | 오른쪽 위 초록 버튼. **로그인하지 않아도 눌립니다** |
| 질문 등록하기 | ✅ | 작성 화면에서 관련 시술을 고르고 제목·내용을 쓴 뒤 `질문 등록하기`. 제목과 내용이 **둘 다** 채워지기 전까지는 버튼이 회색으로 눌리지 않습니다. 등록하면 목록 맨 위에 바로 나타나고 브라우저에 저장되어 새로고침해도 남아 있습니다 |
| 질문에 답변 달기 | 🚧 | **답변을 쓰는 버튼이나 입력칸이 아예 없습니다.** 지금은 이미 들어 있는 샘플 답변을 읽는 것만 됩니다 |
| 내가 쓴 질문 수정·삭제 | 🚧 | 수정·삭제 기능이 없습니다. 한 번 올린 질문은 그대로 남습니다 |
| 질문 검색 / 시술별로 걸러보기 / 정렬 바꾸기 | 🚧 | 검색창, 필터 칩, 정렬 버튼이 하나도 없습니다. 목록 전체가 최신 순으로 한 번에 나옵니다 |
| 좋아요 · 신고 · 스크랩 | 🚧 | 없습니다 |

## 화면에 보이는 정보

- **제목 영역** — `커뮤니티` 와 그 아래 안내 문구 `궁금한 점을 물어보고 답변을 받아보세요`
- **`질문하기` 버튼** — 오른쪽 위 초록 알약 버튼
- **질문 카드** — 각 카드에 이렇게 표시됩니다
  - 관련 시술 배지 (초록색, 예: `임플란트`)
  - 작성일 (예: `2026-07-20`)
  - 제목 — 한 줄까지만, 길면 잘립니다
  - 내용 미리보기 — 두 줄까지만
  - `답변 3` · `조회 312`

### 질문 작성 화면 (`질문하기` 를 눌렀을 때)

- **`관련 시술`** — 시술 13종 칩 중 하나 선택 (이모지 + 이름). 처음에는 `🦷 임플란트` 가 선택돼 있습니다
- **`제목`** — 안내 문구 `궁금한 점을 한 줄로 요약해주세요`
- **`내용`** — 안내 문구 `상황을 자세히 설명할수록 더 정확한 답변을 받을 수 있어요`
- **`질문 등록하기`** 버튼 — 제목·내용이 비어 있으면 눌리지 않습니다

### 질문 상세 화면 (카드를 눌렀을 때)

- 시술 배지 · 작성일 · 제목 · `익명 · 조회 312` · 본문
- `답변 N` 과 답변 목록. 병원/의사가 쓴 답변에는 `치과의사 답변` 배지가 붙고 연한 초록 배경으로 구분됩니다
- 답변이 없으면 `아직 답변이 없어요. 조금만 기다려주세요!`

## 알아두실 것

- **들어 있는 질문 4건과 답변은 모두 샘플입니다.** 실제 사용자가 쓴 글이 아닙니다.
- **내가 쓴 질문은 지금 쓰고 있는 브라우저에만 저장됩니다.** 다른 컴퓨터나 다른 브라우저, 시크릿 창에서는 보이지 않고, 브라우저 데이터를 지우면 함께 사라집니다. 아직 서버가 없기 때문입니다.
- **로그인하지 않아도 질문을 쓸 수 있고, 작성자는 항상 `익명` 으로 고정됩니다.** 로그인한 상태로 써도 이름이 표시되지 않습니다.
- **답변을 달 수 있는 방법이 없습니다.** 그래서 `아직 답변이 없어요. 조금만 기다려주세요!` 라고 나와도 기다려서 답변이 달리지는 않습니다. 새로 쓴 질문은 답변 0건 상태로 계속 남습니다.
- **조회 수는 상세 화면을 열 때마다 계속 1씩 올라갑니다.** 같은 사람이 같은 글을 열 때도 올라가므로 실제 방문자 수와 다릅니다.
- **목록에 따로 정렬 기준은 없습니다.** 새로 쓴 글이 맨 위에 붙는 방식이고, 샘플 4건은 등록된 순서 그대로입니다.
- **질문이 하나도 없을 때 보여줄 안내 문구가 준비되어 있지 않습니다.** 다만 샘플 4건이 항상 들어 있고 삭제 기능도 없어서, 목록이 완전히 비는 상황은 지금은 생기지 않습니다.
- 목록을 아래로 당겨 새로 고치거나, 더 보기로 다음 페이지를 불러오는 기능은 없습니다. (글이 많아지면 한 번에 다 그려집니다)

## 이 화면을 바꾸고 싶을 때

`docs/features/requests/_TEMPLATE.md` 를 복사해서 `docs/features/requests/` 에 요청서를 만들거나,
채팅창에 `/feature-request` 를 입력하세요.

이 화면에서 손대면 함께 확인해야 하는 것:

- **질문 목록과 질문 상세는 같은 데이터**를 씁니다. 목록 카드에 새 정보를 넣으려면 그 정보가 질문 데이터에 있어야 합니다.
- **작성 화면의 시술 칩 13종**은 홈의 `시술로 찾기` 격자, 병원 탐색의 시술 칩과 **같은 목록**입니다. 시술을 추가·삭제하면 세 화면이 함께 바뀝니다.
- **답변 기능을 추가하려면** 질문 상세 화면과 질문 데이터 구조를 함께 손봐야 합니다. 지금은 답변을 저장할 방법 자체가 없습니다.
- **작성자 이름을 실제 로그인 이름으로 바꾸려면** 로그인 기능(마이페이지·로그인 화면)과 연결해야 합니다. 지금은 아무 연결 없이 `익명` 으로 고정입니다.
