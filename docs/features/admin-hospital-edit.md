# 병원 정보 수정

> 이미 등록된 병원 한 곳의 정보를 고치는 화면입니다. 입력 폼은 `병원 등록` 화면과 같고, 맨 위에 그 병원의 광고 진행 현황이 읽기 전용으로 붙습니다.

| | |
|---|---|
| **주소** | `/admin/hospital/:id` (예: `/admin/hospital/h1`) |
| **누가 보나요** | 병원 관리자용 화면입니다. 다만 **지금은 로그인 검사가 없어서 주소만 알면 누구나 들어와 아무 병원이나 고칠 수 있습니다** |
| **어디서 들어오나요** | 병원 관리자 홈(`/admin`)의 병원 카드를 누르면 들어옵니다 |
| **소스 파일** | `frontend/src/screens/admin/hospital/[id].tsx` + 입력 폼은 `frontend/src/components/admin/HospitalForm.tsx` (병원 등록 화면과 같은 폼) |

## 여기서 할 수 있는 일

상태 표시: ✅ 실제로 동작함 · 🟡 화면은 되지만 데이터가 샘플 · 🚧 아직 아무 일도 안 일어남 · 🔒 로그인 필요

| 할 수 있는 일 | 상태 | 지금 어떻게 동작하나요 |
|---|---|---|
| 광고 현황 확인 | 🟡 | 맨 위 `광고 현황 (읽기 전용)` 카드. 여기서 바꿀 수는 없습니다 |
| 병원 정보 고치기 | ✅ | 기존 값이 미리 채워진 상태로 열립니다. 항목은 아래 `입력 항목 전체` 참고 |
| 주소 바꾸기 | 🟡 | 이미 확정된 주소가 보이고, 오른쪽 `변경` 을 눌러야 검색창으로 바뀝니다. **카카오 주소 검색 키가 없으면 가짜 검색 결과가 나옵니다** |
| 요일별 진료시간 고치기 | ✅ | 저장된 진료시간이 채워져 있습니다. 저장된 값이 없으면 기본 스케줄(월~금 `09:30 - 18:30`, 토 `09:30 - 14:00`, 일 `휴진`)이 들어갑니다 |
| 특정 요일 휴진으로 바꾸기 | ✅ | 요일 줄 오른쪽 `휴진` 버튼 |
| 소속 전문의 정보 고치기 | ✅ | 이 병원에 등록된 전문의가 순서대로 채워져 있습니다. 이름·직함·전문 분야·자격증 URL을 고칠 수 있습니다 |
| 전문의 추가하기 | ✅ | `+ 전문의 추가`. 새로 추가한 사람은 `대기` 상태로 등록됩니다 |
| 전문의 삭제하기 | ✅ | 각 칸 오른쪽 위 `삭제` → 그 칸이 즉시 사라지고, **`저장하기` 를 누르면 그 전문의는 데이터에서 완전히 지워집니다.** 확인창이 없습니다 |
| 저장하기 | ✅ | `저장하기` 를 누르면 병원 정보와 전문의 변경이 모두 반영되고 **직전 화면으로 돌아갑니다.** 저장됐다는 안내 문구는 없습니다 |
| 광고 신청·기간 변경 | 🚧 | **없습니다.** 카드에 `광고 신청·결제 기능은 아직 준비중이에요. 변경이 필요하면 담당팀에 문의해주세요.` 라고 적혀 있습니다 |
| 병원 삭제하기 | 🚧 | **없습니다** |
| 사진 파일 올리기 | 🚧 | **없습니다.** 이미지 URL 입력만 가능 |

## 화면에 보이는 정보

- **`광고 현황 (읽기 전용)`** — 상황에 따라 세 가지 문구가 나옵니다.

  | 상황 | 보이는 문구 |
  |---|---|
  | 광고 계약이 없음 | `현재 진행중인 광고가 없어요` |
  | 광고 기간 중 | `임플란트 카테고리 광고 중 · 2026-08-31까지` 처럼 (카테고리 이름 + 종료일) |
  | 광고 기간이 끝남 | `임플란트 카테고리 광고 (기간 종료: 2026-06-30)` 처럼 |

  카드 아래에는 항상 `광고 신청·결제 기능은 아직 준비중이에요. 변경이 필요하면 담당팀에 문의해주세요.` 가 붙습니다.

- **입력 폼** — 병원 등록 화면과 같은 항목. 저장된 값이 미리 채워져 있습니다
- **하단 버튼** — `저장하기`
- **없는 병원 주소로 들어왔을 때** — `병원 정보를 찾을 수 없어요` 만 보입니다

## 입력 항목 전체

`병원 등록` 화면과 **완전히 같은 폼**입니다. 필수 항목이 하나라도 비면 `저장하기` 가 흐리게 표시되고 눌리지 않습니다.

| 항목 이름 (화면 문구) | 필수 | 형태 |
|---|---|---|
| `병원명` | **필수** | 한 줄 입력 |
| `전문 분야 (예: 임플란트 전문의원)` | 선택 | 한 줄 입력 |
| `지역` | **필수** | 한 줄 입력 |
| `주소` | **필수** | 확정된 주소 표시 + `변경` 버튼 → 검색해서 고르기 |
| `대표 이미지 URL (선택)` | 선택 | 한 줄 입력 (비우면 샘플 이미지로 대체) |
| `병원 소개` | 선택 | 여러 줄 입력 |
| `가격대 (원)` — `최소` / `최대` | **필수** | 숫자 입력 두 칸 |
| `태그 (쉼표로 구분)` | 선택 | 한 줄 입력, 쉼표로 나눠 여러 개 |
| `취급 시술 (1개 이상 선택)` | **필수** | 칩 13개 중 여러 개 선택 |
| `실시간 상담 가능` | 선택 | 체크박스 |
| `원데이 진료 가능 여부 (당일 보철 등)` | 선택 | 체크박스 |
| `추천 병원으로 노출 (에디터 추천)` | 선택 | 체크박스 |
| `진료시간 (요일별)` | 선택 | 요일 7줄 × (시간 입력 + `휴진` 버튼) |
| `찾아오시는 길` | 선택 | 여러 줄 입력 |
| `병원 특징` | 선택 | 체크박스 6개 |
| `전문의` | 선택 | 반복 추가 (이름 / 직함 / 전문 분야 칩 8개 / 자격증·인증서 이미지 URL) |

- 취급 시술 13종: `임플란트` `교정` `라미네이트` `인레이` `크라운` `치아미백` `사랑니` `충치치료` `잇몸치료` `스플린트` `코골이장치` `턱관절` `보톡스`
- 병원 특징 6개: `전담코디네이터` `무통마취` `디지털진료` `주차가능` `야간상담` `CCTV설치`
- 전문 분야 8개: `치과보철전문의` `치과교정전문의` `구강악안면외과전문의` `치주과전문의` `소아치과전문의` `통합치의학과전문의` `구강악안면방사선과전문의` `일반의`

각 항목의 안내 문구·기본값은 `docs/features/admin-hospital-new.md` 의 표에 자세히 적어두었습니다.

### 이 화면에서 **고칠 수 없는** 것

- 광고 진행 여부·카테고리·기간 (읽기 전용)
- 평점 · 후기 수 · 상담 신청 수
- 병원 사진 **여러 장** (`대표 이미지 URL` 하나만 있습니다)
- 진행중인 이벤트 / 할인
- 병원 전화번호, 이메일, 홈페이지
- 전문의의 사진 · 연차 · 경력
- 전문의의 인증 상태 (`전문의 인증 검수` 화면에서만 바꿉니다)

## 저장을 누르면 실제로 무슨 일이 일어나나요

- 병원 정보가 즉시 바뀌고, **일반 사용자 화면(병원 상세·병원 카드)에 바로 반영됩니다.**
- 화면에 남겨둔 전문의 목록이 그대로 정답이 됩니다.
  - **기존 전문의** → 이름·직함·전문 분야·자격증 URL만 갱신됩니다. **인증 상태(`승인`/`대기`/`반려`)는 그대로 유지됩니다.**
  - **`삭제` 로 없앤 전문의** → 데이터에서 완전히 삭제됩니다.
  - **새로 추가한 전문의** → `대기` 상태로 등록됩니다.
  - **이름을 지운 전문의** → 이름이 빈 사람은 목록에서 빠진 것으로 처리되어 **삭제됩니다.** 이름만 비우고 저장하지 않도록 주의하세요.
- 저장이 끝나면 **직전 화면으로 돌아갑니다.**

## 알아두실 것

- **⚠️ 지금 관리자 화면에는 로그인 검사가 전혀 없습니다.** `/admin/hospital/h1` 처럼 주소만 알면 로그인하지 않은 누구나 들어와서 **어느 병원이든 정보를 고치고 소속 전문의를 지울 수 있습니다.** 이미 확인된 문제이고 리팩터링 계획 **8단계**에서 막을 예정입니다. 그때까지 **이 화면 주소를 외부에 공유하지 마세요.**
- **내 병원만 고칠 수 있는 구분이 없습니다.** 병원 id를 주소에 바꿔 넣으면 다른 병원 수정 화면이 열립니다.
- **전문의 `삭제` 는 확인창 없이 진행되고, 저장하면 되돌릴 수 없습니다.**
- **`대표 이미지 URL` 을 바꿔도 병원 상세 화면 맨 위의 사진 넘겨보기(캐러셀)는 바뀌지 않습니다.** 캐러셀에 쓰이는 사진 목록은 이 폼에서 건드리지 않습니다. 목록 카드의 대표 사진만 바뀝니다.
- **이미 `승인` 된 전문의의 전문 분야를 바꿔도 승인 상태가 그대로 남습니다.** 즉 검수를 다시 받지 않고 다른 전문의 배지가 사용자 화면에 노출될 수 있습니다.
- **자격증 URL을 바꿔도 다시 검수 대기로 돌아가지 않습니다.**
- **주소는 `변경` 을 누른 뒤 검색 결과를 골라야 바뀝니다.** 검색창에 글자만 남겨두고 저장하면 예전 주소가 그대로 유지됩니다.
- **저장 후 안내 문구가 없습니다.** 화면이 그냥 뒤로 넘어가면 저장된 것입니다.
- **광고 현황의 종료일이 지났어도 카드에는 계속 표시됩니다** (`기간 종료:` 문구로 바뀝니다).
- 데이터는 서버가 아니라 **보고 있는 브라우저에 저장**됩니다. 다른 컴퓨터에서는 수정 내용이 보이지 않습니다.

## 이 화면을 바꾸고 싶을 때

`docs/features/requests/_TEMPLATE.md` 를 복사해서 `docs/features/requests/` 에 요청서를 만들거나,
채팅창에 `/feature-request` 를 입력하세요.

이 화면에서 손대면 함께 확인해야 하는 것:

- **입력 폼은 `병원 등록` 화면과 같은 것입니다.** 한쪽만 바꿀 수 없습니다. (`docs/features/admin-hospital-new.md`)
- 여기서 고친 값은 **병원 상세 화면**과 병원 카드(홈·탐색·검색)에 바로 나타납니다. (`docs/features/hospital-detail.md`)
- 전문의를 추가/수정/삭제하면 **전문의 인증 검수** 목록과 **전문의 상세 화면**이 함께 달라집니다. (`docs/features/admin-specialists.md`)
- `추천 병원으로 노출` 체크는 사용자 화면의 `추천 병원` 배지·추천 목록에 영향을 줍니다.
