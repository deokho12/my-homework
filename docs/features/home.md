# 홈

> 앱을 열면 가장 먼저 보이는 화면입니다. 검색으로 시작하거나, 진행중인 이벤트·시술 종류·꿀팁을 둘러보며 병원을 찾아 들어가는 입구 역할을 합니다.

| | |
|---|---|
| **주소** | `/` |
| **누가 보나요** | 누구나 (로그인 필요 없음) |
| **어디서 들어오나요** | 앱/사이트를 열면 처음 보이는 화면. 아래 탭바의 `홈`, 넓은 화면(PC)에서는 왼쪽 위 `몰라몰라` 로고 또는 위쪽 메뉴의 `홈` |
| **소스 파일** | `frontend/src/screens/tabs/index.tsx` |

## 여기서 할 수 있는 일

상태 표시: ✅ 실제로 동작함 · 🟡 화면은 되지만 데이터가 샘플 · 🚧 아직 아무 일도 안 일어남 · 🔒 로그인 필요

| 할 수 있는 일 | 상태 | 지금 어떻게 동작하나요 |
|---|---|---|
| 검색창 누르기 | ✅ | 홈의 검색창은 **글자를 입력하는 칸이 아니라 버튼**입니다. `임플란트, 교정 같은 시술을 검색해보세요` 를 누르면 검색 화면으로 넘어가고, 입력은 거기서 합니다 |
| 인기 검색어 태그 누르기 | ✅ 🟡 | 검색창 아래 알약 모양 태그 6개. 누르면 검색 화면을 거쳐 **자동으로 검색이 실행**돼서, 시술 이름이면 병원 탐색(그 시술이 선택된 상태)으로, 병원 이름이면 그 병원 상세로 바로 넘어갑니다. 태그 목록은 고정된 샘플이라 실제 검색량과 관계없습니다 |
| 위쪽 큰 배너 넘겨보기 | ✅ | 좌우로 스와이프(또는 가로 스크롤)하면 3장이 넘어가고, 오른쪽 아래 숫자가 `1/3` → `2/3` 처럼 바뀝니다 |
| 배너 누르기 | 🚧 | 배너는 눌러도 아무 일도 일어나지 않습니다. 연결된 화면이 없습니다 |
| 이벤트 카드 누르기 | 🟡 | 그 이벤트를 진행하는 **병원 상세 화면**으로 이동합니다. 이벤트 상세 화면으로 가는 것이 아닙니다 |
| 이벤트 `전체보기` | ✅ | 이벤트 화면으로 이동합니다 |
| 시술 아이콘 누르기 (`시술로 찾기`) | ✅ | 병원 탐색 화면으로 이동하면서 **그 시술이 선택된 상태**로 병원 목록을 보여줍니다 |
| `시술로 찾기` 의 `전체보기` | ✅ | 병원 탐색 화면으로 이동합니다. 이때는 시술이 선택되지 않은 `기타` 상태(= 시술 필터 없음)로 열립니다 |
| 꿀팁 카드 누르기 | 🟡 | 시술 팁 상세 화면으로 이동합니다. 팁 8건은 모두 샘플 글입니다 |
| 앱 다운로드 QR | 🚧 | QR 이미지가 아직 등록되지 않아 회색 `QR` 상자만 보입니다. 눌러도 아무 일도 일어나지 않습니다 |
| 약관 링크 3개 | ✅ | `서비스 이용약관` · `개인정보 처리방침` · `위치기반 서비스 이용약관` 각 화면으로 이동합니다 |
| `몰라몰라 알아보기` | ✅ | 소개 화면으로 이동합니다. 다만 그 화면에는 아직 `준비중입니다` 한 줄만 있습니다 |
| `병원 입점 문의` | ✅ | 병원 입점 문의 화면으로 이동합니다 |

## 화면에 보이는 정보

위에서 아래 순서대로입니다.

- **검색창** — 회색 안내 문구 `임플란트, 교정 같은 시술을 검색해보세요` 와 🔍 아이콘
- **인기 검색어 태그** — 6개. 지금은 `임플란트` `강남 스마일 치과` `교정` `김민준 원장` `라미네이트` `더화이트 라미네이트클리닉`
- **큰 배너 3장** — 사진 위에 초록빛 반투명 막을 덮고 문구를 올린 형태. `병원명 말고, 시술로 찾아보세요` / `전문의가 검증된 병원만 모았어요` / `궁금한 건 커뮤니티에 물어보세요`. 오른쪽 아래에 몇 번째 장인지 표시
- **`지금 진행중인 이벤트`** — 할인 이벤트 카드 4개. 카드마다 병원 사진, 🔥 배지(`얼리버드` `첫방문 할인` `여름 프로모션` `인기`), 이벤트 이름, 병원 이름, 할인율·할인가, 취소선 원래 가격. 좁은 화면에서는 좌우 스크롤, 넓은 화면(1024px 이상)에서는 줄바꿈되어 한 번에 다 보입니다
- **`시술로 찾기`** — 시술 13종 아이콘 격자: 임플란트 · 교정 · 라미네이트 · 인레이 · 크라운 · 치아미백 · 사랑니 · 충치치료 · 잇몸치료 · 스플린트 · 코골이장치 · 턱관절 · 보톡스. 화면 폭에 따라 한 줄에 2개 / 3개 / 4개 / 6개로 자동 조정됩니다
- **`이런 꿀팁 어때요?`** — 팁 카드 8개, 좌우 스크롤. 이 영역에는 `전체보기`가 없습니다
- **앱 다운로드 배너** — `더 많은 시술정보, 앱에서 보기` / `QR을 스캔하여 다운받아보세요` + QR 자리
- **회사 정보 영역(맨 아래)** — 회사명·대표·개인정보관리책임자·사업자등록번호·통신판매업신고번호·주소·이메일, 통신판매 당사자가 아니라는 고지 문구, 약관 링크 3개, `몰라몰라 알아보기` / `병원 입점 문의` 버튼

## 이 화면에서 이동할 수 있는 곳

| 어디로 | 무엇을 눌렀을 때 |
|---|---|
| 검색 | 검색창 |
| 병원 탐색 (시술 선택됨) | 시술 아이콘, 또는 시술 이름 인기 검색어 태그 |
| 병원 탐색 (필터 없음) | `시술로 찾기` 의 `전체보기` |
| 병원 상세 | 이벤트 카드, 또는 병원 이름 인기 검색어 태그 |
| 이벤트 목록 | `지금 진행중인 이벤트` 의 `전체보기` |
| 시술 팁 상세 | 꿀팁 카드 |
| 이용약관 · 개인정보 처리방침 · 위치기반 서비스 이용약관 | 맨 아래 약관 링크 |
| 몰라몰라 알아보기 | `몰라몰라 알아보기` |
| 병원 입점 문의 | `병원 입점 문의` |

## 알아두실 것

- **이벤트·꿀팁·인기 검색어·병원 정보는 모두 샘플입니다.** 실제 병원이나 실제 진행중인 할인이 아니고, 서버도 아직 연결되지 않았습니다.
- **사진은 인터넷에서 불러옵니다.** 무료 사진 사이트(Unsplash)의 사진을 임시로 쓰고 있어서, 인터넷이 느리면 잠깐 회색 상자로 보이고, 사진을 못 불러오면 🦷 아이콘이 들어간 연한 초록 상자로 대체됩니다. 사진이 안 보이는 것은 앱 고장이 아닙니다.
- **인기 검색어 태그를 누르면 검색 화면이 잠깐 스쳐 지나갑니다.** 자동 검색이 곧바로 실행돼서 다른 화면으로 넘어가기 때문이고, 정상 동작입니다.
- **이벤트 카드는 이벤트 상세가 아니라 병원 상세로 갑니다.** 이벤트만 따로 보여주는 상세 화면은 아직 없습니다.
- **`지금 진행중인 이벤트` 영역은 등록된 이벤트가 하나도 없으면 영역 자체가 사라집니다.** 지금은 4개가 고정으로 들어 있어 항상 보입니다.
- **시술 격자의 한 줄 개수는 화면 폭에 따라 달라집니다** (2 → 3 → 4 → 6개). 창 크기를 바꿨을 때 배치가 달라 보이는 것은 의도된 동작입니다.
- **홈에는 알림 종 아이콘이 없습니다.** 좁은 화면(휴대폰)에서는 마이페이지의 `알림함`으로만 알림에 들어갈 수 있고, 넓은 화면(PC)에서는 위쪽 막대에 🔍 · 🔔 · 프로필이 나타납니다. 종 아이콘은 로그인한 경우에만 보입니다.
- **맨 아래 회사 정보는 전부 임시값입니다** (대표 `홍길동`, 사업자등록번호 `123-45-67890` 등). 실제 정보가 정해지면 교체해야 합니다.
- **회사 정보·약관 영역은 홈에만 있습니다.** 다른 탭(병원 탐색·커뮤니티·마이페이지)에는 없습니다.
- 앱 다운로드 QR과 앱스토어/플레이스토어 링크는 **아직 비어 있습니다.** 앱이 출시된 뒤에 채워야 합니다.

## 이 화면을 바꾸고 싶을 때

`docs/features/requests/_TEMPLATE.md` 를 복사해서 `docs/features/requests/` 에 요청서를 만들거나,
채팅창에 `/feature-request` 를 입력하세요.

이 화면에서 손대면 함께 확인해야 하는 것:

- **인기 검색어 태그**는 검색 화면의 인기 검색어 `전체` 1~6위와 **같은 목록**을 씁니다. 한쪽만 바꾸면 어긋납니다.
- **`시술로 찾기` 의 시술 13종**은 병원 탐색 화면의 시술 칩, 커뮤니티 질문하기의 시술 선택과 **같은 목록**입니다. 시술을 추가·삭제하면 세 화면이 함께 바뀝니다.
- **이벤트 카드**는 이벤트 화면, 그리고 병원 카드의 할인가 표시와 같은 데이터를 씁니다.
- **꿀팁 카드**는 시술 팁 상세 화면과 같은 데이터를 씁니다.
- 맨 아래 회사 정보를 고치려면 `frontend/src/mocks/fixtures/placeholder-company-info.ts` 를 확인해야 합니다.
