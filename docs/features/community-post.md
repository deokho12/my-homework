# 커뮤니티 질문 상세

> 커뮤니티에 올라온 질문 하나를 열어서 본문과 달린 답변들을 읽는 화면입니다.

| | |
|---|---|
| **주소** | `/community/:id` (예: `/community/q1`) |
| **누가 보나요** | 누구나 (로그인 필요 없음) |
| **어디서 들어오나요** | 커뮤니티 탭(`/community`)의 질문 카드를 눌렀을 때 |
| **소스 파일** | `frontend/src/screens/community/[id].tsx` |

---

## 여기서 할 수 있는 일

상태 표시: ✅ 실제로 동작함 · 🟡 화면은 되지만 데이터가 샘플 · 🚧 아직 아무 일도 안 일어남 · 🔒 로그인 필요

| 할 수 있는 일 | 상태 | 지금 어떻게 동작하나요 |
|---|---|---|
| 질문 본문 읽기 | 🟡 | 시술 배지·작성일·제목·작성자·조회수·본문이 순서대로 보입니다. 샘플 질문 4개가 미리 들어있습니다 |
| 답변 읽기 | 🟡 | 본문 아래에 `답변 1` 처럼 개수가 나오고 답변 카드가 이어집니다. 답변은 샘플 데이터에 들어있는 것만 보입니다 |
| 치과의사 답변 구분해서 보기 | 🟡 | 치과의사가 쓴 답변에는 `치과의사 답변` 배지가 붙고, 카드 배경이 연한 브랜드색으로 강조됩니다 |
| 조회수 올라가기 | ✅ | 이 화면을 열 때마다 조회수가 1 올라가고 그 값이 브라우저에 저장됩니다. 한 번 들어와 머무는 동안에는 중복으로 세지 않습니다 |
| 답변 쓰기 | 🚧 | 답변을 입력하는 칸이나 버튼이 화면에 아예 없습니다 |
| 좋아요 · 댓글 · 신고 | 🚧 | 없습니다 |
| 내 질문 수정 · 삭제 | 🚧 | 없습니다 |

---

## 화면에 보이는 정보

- **맨 위 줄** — 시술 배지(예: `임플란트`)와 작성일(예: `2026-07-20`). 시술 정보가 없는 질문이면 배지 없이 날짜만 나옵니다
- **제목** — 굵은 큰 글씨
- **작성자 · 조회수** — `익명 · 조회 312` 형태
- **본문** — 질문 내용
- **구분선**
- **`답변 N`** — 달린 답변 개수
- **답변 목록** — 답변마다 작성자 이름, `치과의사 답변` 배지(치과의사인 경우에만), 작성일, 답변 내용
- **답변이 없을 때** — `아직 답변이 없어요. 조금만 기다려주세요!`

### 없는 질문 주소로 들어왔을 때

| 상황 | 화면 |
|---|---|
| 없는 질문 주소 (예: `/community/없는번호`) | `질문을 찾을 수 없어요` 한 줄만 표시 |

### 미리 들어있는 샘플 질문 4개

| 제목 | 시술 | 답변 |
|---|---|---|
| `임플란트 뼈이식 꼭 해야 하나요?` | 임플란트 | 1개 (치과의사 답변) |
| `투명교정 vs 세라믹교정 통증 차이가 클까요?` | 교정 | 1개 (일반 사용자 답변) |
| `라미네이트 하면 나중에 무조건 크라운 해야 하나요?` | 라미네이트 | 0개 |
| `코골이장치 착용하면 턱관절 아플 수도 있나요?` | 코골이장치 | 1개 (치과의사 답변) |

| 어디로 | 무엇을 눌렀을 때 |
|---|---|
| 이전 화면 (보통 커뮤니티 목록) | 헤더 왼쪽 `‹` 뒤로 가기 화살표 |

이 화면 안에서 다른 화면으로 넘어가는 버튼이나 링크는 없습니다.

## 알아두실 것

- **질문과 답변은 모두 샘플 데이터입니다.** 실제 사용자가 쓴 글이 아니고, 서버도 아직 연결되지 않았습니다.
- **데이터가 브라우저에 저장됩니다.** 그래서 다른 컴퓨터나 시크릿 창에서 열면 내가 올린 질문은 보이지 않고 샘플 질문 4개만 보입니다. 브라우저 데이터를 지우면 올렸던 질문과 늘어난 조회수가 함께 사라집니다.
- **답변을 새로 쓸 방법이 없습니다.** 답변은 샘플 데이터에 미리 들어있는 것뿐이라서, 직접 올린 질문은 언제까지나 `아직 답변이 없어요. 조금만 기다려주세요!` 상태로 남습니다. 고장이 아닙니다.
- **`치과의사 답변` 배지는 실제 인증과 연결되어 있지 않습니다.** 샘플 데이터에 "치과의사가 쓴 답변"이라고 표시해둔 것을 그대로 보여줍니다.
- **조회수는 화면을 열 때마다 1씩 올라갑니다.** 본인이 여러 번 들어가도 계속 올라가고, 내 조회를 빼주는 처리는 없습니다. 그래서 숫자가 실제 관심도와는 다를 수 있습니다.
- **날짜는 `3시간 전` 같은 상대 시간이 아니라 `2026-07-20` 형태의 날짜로만 보입니다.** 시간(몇 시 몇 분)은 표시되지 않습니다.
- **작성자는 항상 `익명` 으로 보입니다.** 질문을 쓴 사람이 로그인해 있었는지와 무관합니다. (자세한 내용은 `docs/features/community-new.md`)
- 로그인하지 않아도 질문과 답변을 전부 볼 수 있습니다.

## 이 화면을 바꾸고 싶을 때

`docs/features/requests/_TEMPLATE.md` 를 복사해서 `docs/features/requests/` 에 요청서를 만들거나,
채팅창에 `/feature-request` 를 입력하세요.

이 화면에서 손대면 함께 확인해야 하는 것:

- **커뮤니티 목록(커뮤니티 탭)과 같은 질문 데이터**를 씁니다. 목록 카드에도 답변 수와 조회수가 함께 보이므로, 여기서 조회수 세는 방식을 바꾸면 목록의 숫자도 같이 바뀝니다.
- **질문 등록 화면**(`docs/features/community-new.md`)이 이 데이터에 새 질문을 넣습니다. 항목을 늘리거나 줄이면 양쪽을 함께 봐야 합니다.
- **시술 배지에 나오는 이름**은 앱 전체가 공유하는 시술 목록에서 옵니다. 시술 이름을 바꾸면 홈·탐색 화면의 배지도 함께 바뀝니다.
