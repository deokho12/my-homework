# chat — 채팅용 소켓 서버

몰라몰라의 실시간 채팅을 맡을 서버 자리다. **아직 코드가 없다** (2026-10-22 폴더만 만듦).

## 역할 나눔

| 폴더 | 역할 |
|---|---|
| `frontend/` | React 웹 화면 |
| `backend/` | NestJS REST API 서버 (`/api/v1/...`) — 회원·병원·상담·알림 |
| `chat/` | 채팅 전용 소켓 서버 — 연결 유지·메시지 실시간 전달 |

REST 로 충분한 일(목록 조회, 저장)은 `backend/` 에 두고, 연결을 붙잡고 있어야 하는 일만 여기로 온다.

## 시작할 때 정할 것

채팅 기능 요청서가 나오면 다른 서버 작업과 같은 순서(`CLAUDE.md` 의 "서버를 바꾸는 작업의 순서")로
간다 — `db-master` → `interface-master` → 구현 → `code-reviewer` → `qa-master`. 그때 답해야 할 질문:

- **인증** — `backend/` 가 발급한 JWT 액세스 토큰을 그대로 검증할지
- **저장** — 메시지를 어디에 남기는지 (`backend/` 의 DB 를 함께 쓸지, 따로 둘지)
- **계약 문서** — 소켓 이벤트 규약을 어디에 적을지 (`docs/api/` 아래)
- **포트** — `frontend` 5173, `backend` 3000 과 겹치지 않게
